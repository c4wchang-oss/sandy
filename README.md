# 挪威縮影 · Norway in a Nutshell

一個美觀的旅遊影片風格簡報，記錄挪威縮影（Norway in a Nutshell）的列車旅程。

## 快速開始

1. 用任意現代瀏覽器開啟 `index.html`（建議搭配本機伺服器，例如 VS Code Live Server）
2. 將旅途照片放入 `photos/` 資料夾並依命名規則重新命名（詳見 `photos/README.md`）
3. 重新整理瀏覽器即可看到照片

## 旅程介紹

| 站點 | 交通方式 | 亮點 |
|---|---|---|
| 奧斯陸 Oslo | — | 維格蘭公園、奧斯陸峽灣 |
| 米達爾 Myrdal | 🚂 Bergen Line（約 5 小時） | 高原雪景、海拔 1,237m |
| 弗拉姆 Flåm | 🚞 Flåm Railway（約 1 小時） | 世界最陡列車、Kjosfossen 瀑布 |
| 古德旺根 Gudvangen | ⛴ 納勒峽灣遊船（約 2 小時） | UNESCO 世界遺產峽灣 |
| 沃斯 Voss | 🚌 巴士（約 1.5 小時） | 極限運動勝地 |
| 卑爾根 Bergen | 🚂 火車（約 1 小時） | Bryggen 彩色碼頭、Fløibanen 纜車 |

## 操作說明

| 操作 | 功能 |
|---|---|
| `→` / `↓` / 滾輪向下 | 下一頁 |
| `←` / `↑` / 滾輪向上 | 上一頁 |
| `P` 鍵 / ▶ 按鈕 | 自動播放（每 8 秒換頁） |
| 右側點點 | 直接跳頁 |
| 觸控螢幕左滑 / 右滑 | 換頁 |

