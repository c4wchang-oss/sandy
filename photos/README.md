## 使用方式

1. 將照片放入 `photos/` 資料夾並依上表命名
2. 用瀏覽器開啟 `index.html`（建議用 Live Server 或本機伺服器）
3. 鍵盤 `→` 或 `↓` 切換下一頁，`←` 或 `↑` 返回上一頁
4. 按 `P` 鍵或點擊 ▶ 按鈕開啟自動播放（每 8 秒換頁）

> 照片支援 `.jpg`, `.jpeg`, `.png`, `.webp` 格式。
> 若照片未放入，頁面仍可正常顯示（背景為漸層色）。
