**正文：**

🛒 **這次上線了什麼：**

Shopify Horizon AI Studio 8 月 4 日開始對 Plus 商家開放。

它把 AI 版型生成器和原生 A/B 測試引擎放在**同一個 canvas 裡**——史上第一次。

---

🎯 **怎麼運作：**

**1. 在商店前台標記任何 section**
→ Hero banner、商品格、testimonial block、CTA section——都可以

**2. 用自然語言描述版型**
→「三欄式商品格，桌機等寬，手機堆疊，每個商品下面有獨立可編輯的 CTA」
→「全寬 hero，標題靠左，商品圖靠右，不要背景漸層」

**3. 取得完整程式碼 section**
→ JSON schema + Liquid markup + CSS，直接放進你的 Horizon 主題
→ 不需要 page builder，不需要懂 Liquid

**4. 對一定比例的流量上線你的版型變體**
→ 整合 Shopify 原生的分流測試框架
→ 設定你的信心門檻 → 勝者自動推出

---

💡 **為什麼這和以前的「AI 版型工具」不一樣：**

在這之前的每個 page builder，都把生成和測量分開了。

你在一個地方設計，在另一個地方測試，手動推出勝者。三個工具，三個步驟，一個斷掉的迴圈。

Horizon 把它接上了。**生成器和 A/B 測試是同一個動作。**

---

📐 **Brief 品質 = 輸出品質：**

AI 只能在你給它的詞彙範圍內生成。模糊的 prompt 得到模糊的版型。

你越精確地描述結構、響應式行為和可編輯元素，輸出品質越好，測試的變體也越有意義。

「讓它看起來漂亮」→ 結果難以預測
「三欄，24px gap，icon 在上，標題，2 行內文，CTA button，手機堆疊」→ 穩定可用

---

⚠️ **誠實的注意事項：**

- 不支援 JavaScript 互動
- 無法碰 Shopify Functions 或 Checkout Extensibility
- 需要 Horizon 主題（從高度客製化的 Dawn 遷移可能要 4 到 8 小時以上）
- Prompt 介面目前只支援英文
- 不支援第三方 app blocks

這是刻意設計得比較窄的範圍，專注做好一件事。

---

✅ **Senior UX 的觀察：**

這改變了電商設計工作的基本單位。

以前：一個版型決策要幾週（設計 → 開發 → 部署 → 量測 → 迭代）。
現在：生成變體 → 真實流量 → 自動推出勝者 → 下一輪迭代。

設計假設本身就是實驗，不需要 handoff。
