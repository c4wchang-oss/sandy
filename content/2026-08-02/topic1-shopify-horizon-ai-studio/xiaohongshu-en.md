**Post:**

🛒 **What just shipped:**

Shopify Horizon AI Studio starts rolling out August 4 (Plus merchants first).

It puts an AI layout generator and a native A/B testing engine in the **same canvas** — for the first time ever.

---

🎯 **How it works:**

**1. Highlight any section on your storefront**
→ Hero banner, product grid, testimonial block, CTA section — anything

**2. Describe the layout in plain language**
→ "A 3-column product grid, equal width desktop, stacked mobile, with an editable CTA below each item"
→ "A full-width hero with the headline left-aligned, product image right, no background gradient"

**3. Get a fully-coded section block**
→ JSON schema + Liquid markup + CSS — dropped directly into your Horizon theme
→ No page builder, no Liquid knowledge needed

**4. Ship the variant to a percentage of your traffic**
→ Integrates with Shopify's native split testing framework
→ Set your confidence threshold → winner gets promoted automatically

---

💡 **Why this is different from every other "AI layout tool":**

Every page builder before this separated generation from measurement.

You designed in one place. You validated in another. You manually promoted the winner. Three tools. Three steps. One broken loop.

Horizon closes it. **The generator and the A/B test are the same action.**

---

📐 **Brief quality = output quality:**

The AI works within the vocabulary you give it. A vague prompt gets a vague layout.

The more precisely you describe the structure, the responsive behavior, and the editable elements, the better the output — and the more testable the variant.

"Make it look nice" → unpredictable
"3 columns, 24px gap, icon on top, heading, 2-line body, CTA button, stacked on mobile" → reliable

---

⚠️ **Honest caveats:**

- No JavaScript interactions
- Can't touch Shopify Functions or Checkout Extensibility
- Requires Horizon theme (migration from Dawn can take 4–8+ hours on heavily customized stores)
- Prompt interface is English-only right now
- Third-party app blocks not supported

This is a narrow scope by design. It does one thing well.

---

✅ **Senior UX take:**

This changes the unit of design work in commerce.

Before: a layout decision took weeks (design → dev → deploy → measure → iterate).
After: generate a variant → live traffic → automated winner → next iteration.

The design hypothesis IS the experiment. No handoff required.
