### Topic 1: Shopify Horizon AI Studio — AI-Generated Layouts + Native A/B Testing
**Source:** https://ecommerce-times.com/shopifys-new-ai-native-theme-editor-is-rewriting-how-merchants-build-storefronts/
**Published:** July 28, 2026 (Plus merchants rolling out Aug 4, standard plans Q3 2026)
**Core Insight:** For the first time, the AI design generator and the performance validator live in the same canvas — generate a layout variant, A/B test it in production, and promote the winner without leaving the editor.

**Key points:**
- On-canvas AI layer inside Shopify's Online Store 2.0 editor (not a sidebar widget or third-party app)
- Highlight any section (hero, product grid, testimonial) → describe layout in natural language → get fully-coded section block (JSON schema, Liquid markup, CSS)
- Integrates with Shopify's native A/B testing framework (expanded May 2026)
- Generated variants go live for a percentage of traffic immediately; winner promoted at configurable confidence threshold
- Brief quality = output quality ceiling (precise structural descriptions generate reliably)
- Constraints: no JS interactions, no Shopify Functions, no third-party app blocks, English-only prompts, requires Horizon theme
- Horizon AI Studio: previously called AI Block Generator (Shopify Magic-powered)

### Topic 2: Notion Developer Platform 3.5/3.6 — Workspace as Agent Orchestration Layer
**Source:** https://www.notion.com/blog/introducing-developer-platform / https://www.notion.com/releases
**Published:** July 2026 (Notion 3.5 May 13, Notion 3.6 July 2026; AI Meeting Notes trigger July 31)
**Core Insight:** The project workspace is now the agent's context window — Notion became neutral infrastructure where any agent your team uses (Claude Code, Cursor, Codex, Decagon) operates as a native teammate. Your design brief, research, and meeting decisions are already the agent's inputs.

**Key points:**
- External Agents API (alpha): assign, chat with, track Claude Code, Cursor, Codex, Decagon as Notion teammates
- Notion Workers: hosted runtime for custom code — deploy to secure sandbox, no server management needed
- Workers free through August 11, then Notion credits
- AI Meeting Notes → Custom Agent triggers: post-meeting automation (update tracker, send recap, file tickets) runs automatically
- Design pattern: Custom Agent for judgment (AI reasoning), Worker for execution (deterministic code)
- Governance and audit built in — meaningful for design teams at scale
- Caveat: orchestration quality depends on workspace structure quality (garbage in, garbage out)
