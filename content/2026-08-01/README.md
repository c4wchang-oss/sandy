### Topic 1: Figma Make — Properties Panel + Annotations
**Source:** https://www.figma.com/blog/properties-panel-and-annotations-now-in-figma-make/
**Published:** July 30, 2026
**Core Insight:** AI design editing just went spatial. The era of text-only editing is ending — you now point at the thing and say what's wrong.

**Key points:**
- Properties panel: familiar Figma controls (spacing, typography, layout, z-index, opacity) directly in Make
- Annotations: draw areas on canvas → describe change in plain language; model reads location + instruction together
- Edits stage credit-free in the prompt box until you commit
- Uses existing codebase tokens (constraint architecture maintained)
- DOM tree visible as you work
- Code Connect integration coming (Figma Design ↔ Make component parity)

### Topic 2: Claude Design — Design System as Platform
**Source:** https://claude.com/blog/claude-design-stays-on-brand-for-daily-work
**Published:** July/August 2026
**Core Insight:** Claude Design stopped being a demo tool and became a design system compliance layer. Your design system is now the quality ceiling on everything Claude generates — for design and code.

**Key points:**
- Import design systems from GitHub / design files / uploads — persistent across all projects
- Claude validates output against your system before you see it (self-QA pass)
- Enterprise admin can lock one org-wide design system
- /design-sync: pull codebase design system into Claude Design; hand off to Claude Code with full component context
- /design terminal command: designers and devs access without context-switching
- Connectors: Adobe, Base44, Canva, Gamma, Lovable, Miro, Replit, Vercel, Wix
- Export to PDF and PowerPoint
- Shared usage limits with chat/Cowork/Code
