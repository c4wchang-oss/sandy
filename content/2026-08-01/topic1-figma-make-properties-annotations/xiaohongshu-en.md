**Title:** Figma Make just changed how you edit AI-generated UI (no more wall-of-text prompts)

**Cover text:** Point. Annotate. Ship.

---

**Body:**

🎯 **The old way of editing in Make:**
Write a 3-sentence prompt describing which element, what property, and what value. Watch the model interpret it wrong. Undo. Try again.

Now there's a better way.

---

✏️ **What just shipped in Figma Make:**

**1. Properties Panel**
Select any element → adjust spacing, typography, layout, z-index, opacity directly with visual controls — the same ones you know from Figma Design.
→ All edits stage in the prompt box first (zero credits until you commit)
→ Uses your existing codebase tokens — color, spacing, typography
→ Full DOM tree visible (a layers panel for your code)

**2. Annotations**
Toolbar → "Annotate for agent" → draw a box around the area → describe the change in plain language
→ "Zoom this thumbnail slightly on hover"
→ "Fade this button in after 300ms"
→ "Add a press effect when tapped"
Location = precise. Instruction = flexible.

---

💡 **Why the credit mechanic matters:**

Direct manipulation stages every edit before consuming tokens.
Test 5 padding values. Try 3 font weights. Drag to reorder.
Zero credits. Commit only when it's right.

AI handles execution. You handle exploration.
That's the correct division of labor.

---

🔗 **What's coming:**

Code Connect integration → Make will link directly to your Figma Design components.
When that lands, an edit in Make = an edit to the same component on your design canvas.
The handoff gap closes.

---

📌 **Senior designer takeaway:**

The model's job just narrowed. Before: "interpret everything." Now: "fill gaps in a defined context."

Spatial prompting + visual controls = faster, tighter edit loops.
The era of text-only AI editing is ending.
