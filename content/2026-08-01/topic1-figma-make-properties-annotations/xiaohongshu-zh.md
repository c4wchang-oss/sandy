**標題：** Figma Make 改了！AI 生成的 UI 終於不用靠文字 prompt 慢慢改了

**封面文字：** 指、標、改，就這樣

---

**正文：**

🎯 **以前在 Make 裡編輯的樣子：**
寫一段話描述是哪個元素、什麼屬性、什麼數值
→ 模型理解錯了
→ undo
→ 重來

現在終於有更好的方式了。

---

✏️ **這次 Figma Make 上線了什麼：**

**1. Properties Panel（屬性面板）**
選任何元素 → 直接用視覺控制項調整 spacing、typography、layout、z-index、opacity
→ Figma Design 裡熟悉的那套操作，現在在 Make 裡也能用了
→ 所有編輯先暫存在 prompt box，零 credit，確認才 commit
→ 使用你現有 codebase 的 token（顏色、spacing、typography）
→ DOM tree 可見（你的 code 的 layers panel）

**2. Annotations（標記）**
工具列 → 「Annotate for agent」 → 在 canvas 上框出範圍 → 用自己的話描述要改什麼
→「滑鼠停在縮圖上時輕微放大」
→「這個 button 在 300ms delay 後淡入」
→「按下時加一個輕微的 press 效果」
位置：精準。指令：靈活。

---

💡 **為什麼 credit 機制很重要：**

直接操作的每個編輯都會先暫存，不消耗 token。
試 5 種 padding，測 3 個 font weight，拖拉重排
零 credit，確認了才 commit。

AI 負責執行，你負責探索。
這才是正確的分工。

---

🔗 **即將到來：**

Code Connect 整合 → Make 將直接連結你的 Figma Design components。
等這個上線，在 Make 裡編輯一個元素，就等於在 canvas 上編輯同一個 component。
handoff 的缺口就消失了。

---

📌 **Senior designer 的觀察：**

模型的工作範圍縮小了。以前是「詮釋所有事情」，現在是「在已定義的 context 裡填補缺口」。

空間感 prompt + 視覺控制 = 更快、更緊的 edit loop。
只用文字做 AI 編輯的時代正在結束。
