# Threads Post — English
## Topic: Gamma 5 — The self-review loop is what I'm watching
## Date: October 9, 2026
## Format: Long-form personal reflection

---

Shopify Canvas taught me to notice when AI tools design a self-review loop into their own behavior. Gamma 5 is the second major tool I've seen do this correctly.

Here's what I mean: before Gamma 5, you'd prompt for a deck, get a result, find text spilling off slides, images cropped awkwardly, layouts that fell apart. You'd fix it. The feedback loop was: generate → user discovers problem → user fixes.

Gamma 5's architecture is different. Agent generates → agent checks against its own plan → agent adjusts → agent presents. The automated checks catch text overflow, awkward image crops, layout failures before you see them. You're reviewing version N+1, not version 1.

This sounds small. It's not. Trust in AI tools comes from consistency of output quality at handoff. When an AI tool can't audit its own work, you can't delegate high-stakes presentations to it. When it can, you can.

The second piece I found more interesting than the visual style expansion: the back-and-forth before building anything. Agent asks about your goal, audience, visual direction. You approve a plan. Only then does it build. That sequence — clarify → plan → execute → review → handoff — is what design brief discipline looks like when it's baked into AI behavior, not left as a user habit.

The connectors (Notion, Slack, Linear, Granola) close the loop: you describe the project, agent pulls source material from where it already lives, builds from actual context rather than your attempt to summarize it in a prompt. Context assembly is still the real bottleneck; prompts summarizing real documents lose to real documents every time.

What I'm watching: whether the self-review loop holds at professional complexity. Text spill checks are automatable. "Does this Information Architecture actually serve the audience's real question" is not. That's still on you.

But the first layer being handled automatically is not nothing.
