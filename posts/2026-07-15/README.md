### Topic 1: Figma Make + GPT-5.6
> "Your design system quality IS your AI output quality."

Senior UX angle: The bottleneck has shifted from prompting to design file cleanliness.

Senior UX angle: Visual annotation > text description for directing agents. Cursor is learning to speak designer language.
