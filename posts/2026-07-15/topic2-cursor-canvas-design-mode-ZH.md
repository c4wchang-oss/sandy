## X 推文串 — 繁體中文

**[推文 1 — Hook]**
Cursor 剛推出 Canvas 的 Design Mode。

現在可以直接點擊 canvas 裡的 UI 元素，加上 annotation 來指導 agent。

不用再寫一段話來描述你要改什麼。你直接指給它看。

對 UX Designer 來說，這個更新很重要。為什麼 🧵

---

**[推文 2]**
快速背景說明：

Cursor Canvas 是 agent 在 Cursor 裡幫你建出來的互動產物——dashboard、UI mockup、內部工具都算。

Design Mode 是疊在上面的新視覺互動層。

---

**[推文 3]**
Design Mode 之前：
「在 card component 右上角，標題旁邊，那個藍色背景的按鈕，不是那個，是那個，需要……」

Design Mode 之後：
選元素。加 annotation。送出。

Agent 直接拿到視覺上下文，不需要翻譯這道工序。

---

**[推文 4]**
從 UX 的角度，這是對的互動模型。

我們在 Figma 標注設計稿好幾年了。紅色標記。便利貼。留言。
「指著說明」——這個腦袋裡習慣的模式，現在終於可以用來指導 AI agent 了。

終於。

---

**[推文 5]**
另一個值得你注意的功能：Context Usage Report。

你現在可以看到 agent 的 token 預算花去哪了——system prompt、tool 定義、rules、skills——全部視覺化在 canvas 裡。

然後你可以請 agent 自己去優化。

---

**[推文 6]**
UX Designer 為什麼要在意 token context？

因為你在用 canvas 建 design system 或 UI spec 的時候，context window 塞滿了，agent 就會開始忘記前面的限制，決策開始飄。

了解你的 context 預算 = 在長時間 agent run 裡維持設計一致性。

---

**[推文 7]**
實際的轉變：

Cursor 正在往「設計師已經熟悉的互動模式」靠攏。

點一下。加 annotation。iterate。
不再是「用文字仔細描述每一個你想改的東西」。

純文字 prompt 的摩擦感，正在被設計掉。

---

**[推文 8 — CTA]**
最被低估的部分：shared canvas 現在可以在瀏覽器全螢幕開啟。

對那些要向非技術 stakeholder 做簡報的 UX Designer 來說，這真的很重要。

你的 agent 做出來的東西，現在可以直接拿來簡報，不只是拿來開發。

↳ 來源：cursor.com/changelog/canvas-improvements

## Threads 貼文 — 繁體中文

Cursor 的 Canvas Design Mode 讓我眼睛一亮。

你現在可以在 canvas 裡直接點 UI 元素，加 annotation 來指導 agent 要改什麼。

如果你曾經花時間寫精確的文字描述，解釋「右邊那個按鈕，不是另一個，是在 header 下面那個」——你就知道這有多重要。

互動模型終於是設計師認識的那種：指、說明、iterate。不再是「文字描述然後祈禱」。

但我其實更在想的，是 Context Usage Report 這個功能。

當你用 agent 建複雜的 UI spec 或 design system 的時候，context window 會慢慢塞滿。Agent 開始忘記前面的約束。決策開始飄移。輸出慢慢失去一致性。

現在你可以看到 token 去哪了——然後請 agent 自己優化。這不是開發者功能，這是設計品質功能。

轉變：Cursor 正在用設計師已經懂的語言說話。這才是這次更新的真正新聞。

## 小紅書貼文 — 繁體中文

**標題：** Cursor 新功能 Design Mode，UX 設計師為什麼要在意

---

Cursor 上個月推出了 Canvas Design Mode，我覺得設計圈低估了這個更新。讓我拆開來說。

---

**是什麼東西：**

→ Cursor Canvas 是 agent 在 Cursor 裡幫你建出來的互動產物（dashboard、UI mockup、工具都算）
→ Design Mode 讓你直接在 canvas 裡點 UI 元素並加 annotation
→ 不用再打一段話描述要改什麼，直接指給它看

---

**為什麼重要：**

試過用文字 prompt 指導 AI agent 的人都懂那個痛苦。

「右上角那個按鈕，不是導覽列下面那個，是標題旁邊那個，藍色背景的，要……」

Design Mode 把這個壓縮成：點元素 → 加 annotation → agent 去改。

這個腦袋裡的模式和標注 Figma 設計稿一模一樣。指。說明。Iterate。

---

**更深層的轉變：**

Cursor 在學習說設計師已經在說的語言。

視覺 + annotation > 純文字描述。

---

**附贈功能：Context Usage Report**

在長時間 agent session 裡建複雜 UI spec 的時候，context window 會塞滿，然後一致性就掉了。

新的 report 讓你看到 token 花去哪，還可以請 agent 自己優化。對維持設計一致性來說，這功能比看起來重要很多。

---

**結論：**

Design Mode 讓 agent 互動對設計師來說更自然。
Context Report 讓長時間 design session 更可靠。

這兩個功能這週都值得去試。

→ 怎麼用：Cursor → 開 canvas → 開啟 Design Mode
