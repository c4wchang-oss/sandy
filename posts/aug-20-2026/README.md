# AI UX Post Batch — Aug 20, 2026

## Topics

### Topic 1: Hostinger AI Builder + Connector
**Date:** Aug 19–20, 2026  
**Source:** [Hostinger AI Builder Launch](https://www.hostinger.com/blog/ai-builder-launch/)  
**Key insight:** Hostinger launched AI Builder with "Connector" — an open API that lets Claude Code, Cursor, and VS Code operate against your hosting account directly. This extends the MCP/Connector pattern (Figma MCP, ProtoPie MCP) to deployment infrastructure. Every platform is becoming an agent endpoint.

**UX angle:** When design → deploy gaps collapse, the designer's value shifts from execution to writing agent-legible briefs. Brief quality, constraint architecture, and system legibility move upstream — not away.

### Topic 2: Canva AI 2.1 — The Free AI Floor Moved Up
**Date:** Aug 7–20, 2026 (rolling announcement)  
**Source:** [Canva founder says AI costs down 90%](https://www.forbes.com.au/news/uncategorized/canva-founder-says-ai-costs-down-90-per-cent/)  
**Key insight:** Canva paused their AI 2.0 rollout because frontier model API inference was economically unsustainable at 200M users. Spent 3 months rebuilding: image gen 30x cheaper, video 17x cheaper, style transfer 23x cheaper. Now rolling out AI 2.1 with sustainable economics. New $100/mo AI Pass tier.

**UX angle:** This is structural, not temporary. The free AI floor permanently moved up. The $100 AI Pass tier signals design team AI budget governance has arrived. And Canva's "prefer recombination over generation" strategy is constraint architecture as economic policy — which is also better design.
