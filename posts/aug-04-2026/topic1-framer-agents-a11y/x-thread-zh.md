# X Thread — 中文（繁體）
## 主題：Framer Agents 七月 2026 更新 — 無障礙設計進入工作流程
## 日期：2026 年 8 月 4 日

---

**推文 1/8**
Framer 剛把無障礙設計（accessibility）變成 agent 的工作項目之一。

不是 checklist，不是上線後的稽核。
是你在做東西的當下可以進行的對話。

---

**推文 2/8**
七月 2026 Agents 更新加入了 A11Y 圖層屬性的支援。

你現在可以跟 Framer agent 說：「對我的 nav 和主要 CTA 跑一次 accessibility check」——它會自動補上 alt text、icon-only button 的標籤、ARIA metadata。

不用一個一個改。全部一次。

---

**推文 3/8**
Page Effects 也進入了 Agent 的操作範圍。

捲動動畫、進場 transition、整頁 motion——現在都可以用 prompt 指定。指定一個區塊，描述行為，agent 幫你做。

為什麼重要？因為動態效果跟 accessibility，一直是最容易被說「之後再補」的兩件事。

---

**推文 4/8**
設計業講「accessibility 不是功能，是地基」講了二十年。

這句話在工作流程層面終於成真了。
當 agent 可以在你建頁面的同一個對話裡跑 accessibility pass，「沒時間」這個藉口就很難繼續說了。

---

**推文 5/8**
實際操作長什麼樣：

你用 Framer Agents 做一個首頁。同一個 chat 裡你說：「幫我確認所有 form 欄位都有 label，圖片都有 alt text。」

Agent 掃描、補上、回報。
你不用 export 到另一個稽核工具。稽核就在工作流程裡。

---

**推文 6/8**
這次更新還有幾個值得注意的：
– 更豐富的 Overlay：有 Enter/Exit backdrop transition、浮動 overlay 安全區
– CMS Rich Text Video：完整影片進入 Agent 操作範圍
– Text Shadow：終於可以用 prompt 調整了
– Draggable interaction：用描述，不用手動設定

清單讀下來就是：所有以前要在圖層面板手動操作的東西，現在都可以在對話層完成。

---

**推文 7/8**
GPT 5.6 Terra 和 Luna 打五折到八月十四號。Framer 想讓之前試過 Agents 但沒繼續的團隊再試一次。

值得說的是：模型定價的差別不只是預算問題。Terra = 速度加品質，Luna = 純速度。這是一個工作流程的選擇，不只是成本的選擇。

---

**推文 8/8**
真正的新聞不是「Framer Agents 變強了」。

而是：設計師最常拖延的兩件事——動態效果跟無障礙——現在當你用 AI agent 做設計的時候，它們是預設的工作步驟。

以後再說「沒時間處理」這句話，要說得更費力了。
