**Title:**
OpenAI DevDay 2026: Figma now lives inside ChatGPT — and that changes the design feedback loop

---

**Body:**

OpenAI's DevDay 2026 dropped 20+ announcements. Most coverage focuses on the model upgrades.

But the quiet shift that matters for UX designers? ChatGPT stopped being a chat window. It just became a design collaboration workspace.

Here's what actually changed — and what it means for your workflow:

**① Plugin Extensions: Figma inside ChatGPT**
Developers can now build full app-like experiences inside ChatGPT — sidebars, interactive panels, custom file viewers. The keynote demoed Figma designs and comments sitting next to your AI conversation, in one panel. No tab switching. No re-pasting screenshots. The design file IS the context now.

**② ChatGPT Dots: always-on agents across your whole toolchain**
Persistent agents connected to 4,000+ apps with their own cloud computers. Your AI assistant now has memory across Figma, Slack, Jira, and Notion. You don't start every session from scratch re-explaining what you're working on. This is what design teams have been duct-taping together manually with browser tabs.

**③ MCP Events: design actions trigger downstream automations**
Connected apps can now trigger workflows automatically when something changes. Figma status update → Jira ticket updates → team Slack notification. The handoff layer got automated, not eliminated.

**④ Pages: collaborative docs, AI + human in the same canvas**
Real-time co-authoring between you and the AI — not "generate a doc and paste it." For research synthesis, design rationale, and brief writing, the artifact IS the conversation now.

**The honest caveat:**
20 announcements in one day = rough edges everywhere. Plugin quality depends on who built it. ChatGPT Dots needs existing app connectors. MCP Events requires both ends to implement it. Nothing is plug-and-play on day one.

**The pattern to watch:**
Figma's own ecosystem (MCP server, Code Layers, Design Agent) is solving the same context organization problem from inside the design tool. ChatGPT is solving it from outside.

Same diagnosis: context assembly is the real AI design bottleneck. Different bets on where that context should live.

**The reframe:**
"AI needs more context" has been a workflow problem — we assemble it manually every session.

DevDay 2026 is OpenAI's answer: don't make users assemble context. Build the infrastructure that keeps it.

Whether this lands for designers depends on how good the Figma Plugin Extension actually is. That's a product design problem, not a model problem.
