**品牌角色的臉現在是可重複使用的素材——Luma Brand Kit + Character Library**

Luma 在 11 月 25 日推出了 Brand Kit 和 Character Library。實際細分如下：

**他們解決的核心問題：**
AI 即興發揮。100 個素材的活動後，你的 logo 偏移了，產品顏色不對，品牌吉祥物到了第三個場景看起來像不同的角色。這不是 prompt 問題——是約束架構問題。

**Brand Kit 做什麼：**
- 上傳 logo、字體、顏色、產品、參考、品牌規則一次
- 或放入你的網站 URL → Luma 為你起草品牌套件供審查
- 用 `#brandkit` 綁定到 board → 每次生成都自動讀取
- 不需要重新提示，不需要每批次後開漂移修正會議

**Character Library 做什麼：**
- 把臉、身體、服裝、表情、環境儲存為角色資源
- 在任何 board 用 `@character` 引用
- 角色演進了？更新資料庫 → 所有未來生成都使用更新版本
- 第一個把角色臉部一致性視為正式品牌素材類型的平台（和 logo 同等級）

**工作流程：**
1. 建立你的 Brand Kit（上傳指南文件或網站 URL）
2. 為每個品牌角色設定 Character Library
3. 打開 board → `#brandkit` + `@character` → 描述你的 brief
4. Agent 讀取兩個資源，生成一致的活動素材

**「評估對齊」實際上是什麼意思：**
Luma 說系統評估輸出是否符合你的品牌規則。這是監控，不是執行。Agent 標記漂移——它不會在架構上阻止它。在你讓 100 個素材無人監管地跑之前，了解這個區別。

**誠實的前提：**
- Brand Kit 在 research preview（beta）
- 基於 URL 的起草讀取你已部署的網站 = 當前狀態，不是已記錄的意圖；跑之前審計草稿
- 品牌角色的角色一致性 ≠ 寫實人類相似度——為你的具體使用案例驗證
- 公告中沒有定價詳情

**更大的模式：**
Brand Kit 跟隨 Stitch、Higgsfield、Automo——同樣的原則：品牌約束載入一次，自動應用。Character Library 是新的：臉 = 命名約束，不是你每次重新描述的圖像。那個區別在生產規模上很重要。
