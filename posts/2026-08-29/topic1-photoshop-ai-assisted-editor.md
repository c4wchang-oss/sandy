# Topic 1: Adobe Photoshop AI Assisted Editor (Aug 27, 2026)

**Source:** https://blog.adobe.com/en/publish/2026/08/27/new-photoshop-innovations-bring-you-more-choice-control-at-every-stage-of-your-creative-process

**Senior UX angle:**
Progressive disclosure applied to the tool itself, not the product you design with it. Photoshop split its editor into Pro Editor + AI Assisted Editor (beta). The most interesting piece is AI Markup — draw roughly on the image + add a text prompt = visual annotation beats text-only prompting. Non-destructive generative layers keep the existing layer mental model intact. Quality ceiling = Firefly Image 5. Pattern: "two modes, one file" is now consistent across Figma, Framer, and Photoshop.

## Threads Post (English)

Photoshop shipped AI Assisted Editor this week — a simplified, prompt-based mode that lives alongside the Pro Editor in the same file.

One toggle. You switch between them. Nothing's gone.

That's the exact same design principle we use when we design products: progressive disclosure. Expose complexity when you need it, simplify when you don't. Adobe just applied it to itself.

The part I find most interesting isn't the simplified mode. It's AI Markup.

Draw roughly on the region you want to change. Type a prompt. Firefly uses both. It's exactly the "visual annotation > text-only prompting" principle that keeps coming up in how agents understand intent — and now it's in the most mainstream image editing workflow in the world.

Every Prompt to Edit result becomes a generative layer. Non-destructive. Same layer stack logic as before. The mental model didn't change. The floor just got lower.

Honest take: the quality ceiling is Firefly Image 5. It's beta. There's a reason the Pro Editor is still called Pro.

But the pattern is worth watching. Figma, Framer, Photoshop — all shipped "two modes, one file" this year. When every major creative tool in your stack offers this split, you start to think about it as a design pattern for the whole team, not just a feature.

When was the last time you chose to work in a simpler mode on purpose? Not because you couldn't use the full tool — but because the full tool was getting in the way.
