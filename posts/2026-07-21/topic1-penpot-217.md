📌 Who this is for: design leads, enterprise UX teams, anyone frustrated with Figma pricing

I've been watching Penpot as a potential Figma alternative for a while — mostly as an experiment. 2.17 is the version that makes me take it seriously.

Here's what actually matters in this release:

🔷 MCP stability
First version where I'd actually trust an AI editor connection to Penpot. Concurrency control, stable sync, integration key surfaced properly. If you're connecting Cursor or Claude to your design files — this changes things.

🔷 Typography tokens in Design sidebar
Autocomplete when creating/editing tokens. Propagation performance improved significantly. Multi-select text and your token system shows up. Same workflow as Figma Variables — in open source.

🔷 Background blur (finally)
Frosted glass UI is now native. No more workarounds. Genuinely useful for mobile UI and glassmorphism layouts.

🔷 Comments while designing
No mode-switching to leave feedback. Read threads, reply, resolve — without leaving the canvas. Sprint review just got less friction.

⚠️ The real caveat:
Plugin ecosystem is still thin. If you're dependent on Figma-specific plugins, the migration cost is real. Day-to-day UX also has rough edges.

💡 The actual insight:
This release signals that open-source design tools can now support constrained, token-governed design workflows. Your design system is no longer locked to Figma. That's a strategic shift — even if you stay on Figma.

For enterprise teams: this is the version to test. Not because Penpot is better — but because the negotiating leverage just changed.
