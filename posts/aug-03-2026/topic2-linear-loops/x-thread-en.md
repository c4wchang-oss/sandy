# X Thread — EN
## Topic: Linear Loops — Recurring Agent Workflows
## Date: Aug 3, 2026

---

**Tweet 1/8**
Linear just shipped the best-designed agentic automation UX I've seen.

Not because of what it does. Because of what it shows you after it runs.

---

**Tweet 2/8**
It's called Loops.

Define a recurring job in plain language, set a trigger (schedule or event), and Linear Agent runs it autonomously — across your workspace, with full access to your issues, projects, and connected tools.

---

**Tweet 3/8**
What makes it different from every other "AI automation" feature: every Loop is an inspectable operating object.

Not a prompt that disappears. A team-owned thing with a trigger, instructions, permission scope, and a run history that any teammate can read.

---

**Tweet 4/8**
The run history view is the UX I want to study.

A narrow list of runs by date + time on the left. A master-detail panel showing: what the agent saw, what context it used, what actions it took, which issues it touched. After every run. While you were asleep.

---

**Tweet 5/8**
This solves the hardest design problem in agentic products.

Not "can the agent do the thing" — that gets easier every month. The hard problem is: "when I come back and something changed, can I understand why?" Linear answered that with a screen.

---

**Tweet 6/8**
The publish gate is the other smart UX call.

Edited loops are saved as drafts. Changes only go live after you click Publish. You can't accidentally push an in-progress instruction to a live automation. Autonomy with a confirmation step.

---

**Tweet 7/8**
Permissions are described by consequence, not capability.

Not "the agent can use the GitHub tool" — but "this loop can create issues, update specifications, assign work." You see the blast radius before you publish.

---

**Tweet 8/8**
Real headline: Linear didn't ship a "set-and-forget" automation feature.

It shipped an audit-first operating model for AI agents.

The test: can a teammate who wasn't there open the loop and explain what happened? If yes, you've solved agent trust.
