**Title:** Linear Loops: the best agentic UX design I've seen in 2026

**Body:**

Linear shipped recurring AI agent workflows. But the real story is how they designed for trust.

**What Loops does:**
① Define a recurring job in plain language
② Set a trigger: schedule or event-based
③ Linear Agent runs it autonomously with full workspace context
④ Every run is logged, timestamped, and readable by any teammate

**Why the design is exceptional — four UX decisions:**

1/ Every Loop is a team-owned operating object (not a disappearing prompt)

2/ Permissions described by consequence: "this loop can create issues, update specs, assign work" — you see the blast radius before you publish

3/ Publish gate: all edits are drafts until you explicitly go live — accidental automation pushes eliminated

4/ Run history = master-detail audit surface: select any run by timestamp, read what the agent saw, what context it used, what it changed

**The test for any agentic product:**
"Can a teammate who wasn't there open the automation and explain why it ran, what it touched, what it changed?"

No → you shipped autonomy without accountability
Yes → that's agent trust, solved with a UI

**For designers building products with AI agents:**
Design the audit trail before you design the feature. The agent's actions are only as trustworthy as the run history is readable.

Permission model > capability model. Always.
