## Topics Covered

### Topic 1: Figma Agent Skills Community (Aug 13, 2026)
Figma launched community skills for the agent. Skills are Markdown files that package repeatable workflows into slash commands. Now publishable to the Figma Community (50+ available).

**Angle:** Skills = encoded design judgment. The community library raises the floor. The value isn't running someone else's skill — it's authoring the one your team can't live without.

**Sources:**
- https://www.figma.com/blog/try-these-10-skills-and-show-off-your-own/
- https://www.figma.com/release-notes/ (Aug 13, 2026 entry)

### Topic 2: Cursor Design Mode (Aug 13, 2026)
Cursor Design Mode lets you click live UI elements in a running app, and the AI agent receives element identity (XPath, computed CSS, React fiber tree) + screenshot to translate visual intent into code edits.

**Angle:** Visual intent is finally legible to AI from the code side. Not pixels — live render state. The ask isn't "become an engineer." The ask is: be able to point at what you mean.

**Sources:**
- https://ultrathink.ai/news/cursor-design-mode-frontend-ai (Aug 13, 2026)
- https://cursor.com/docs/agent/design-mode
- https://cursor.com/changelog/design-mode-improvements
