**Title:**
Figma Agent Skills 社群上線了｜這是資深設計師的機會點

---

**Body:**

Figma 今天發布了 Agent Skills 社群功能。直接說重點：

**這次發布了什麼：**
Figma 社群裡現在有 50+ 個 slash 指令工作流程。設計系統審查、accessibility check、研究框架⋯⋯任何人點一下就能加到自己的 Figma agent。

**真正的核心：**
Skill 就是一個 Markdown 檔案。它把你的設計說明，打包成 agent 可以隨時執行的重複性工作流程。

想像它是設計系統，但針對的是你的判斷決策。

**三種看待 skills 的角度：**
① 減少重複勞動：讓 agent 跑例行工作
② 將品味編碼：把你的設計哲學變成可分享的東西
③ 跨平台判斷力：skills 可以跑在 Figma MCP server——在 Claude 或 Cursor 裡也能用

**真正的價值在哪裡：**
不是用社群裡的 skills。
是 author 出一個你的團隊離不開的 skill。

把你最常給的 critique 寫下來。那個你靠直覺做的 accessibility check。那個沒人用跟你一樣方式做的交付審查。

那就是你的 skill。那就是你的槓桿。

**從這裡開始：**
→ 打開 Figma agent
→ 請它根據你檔案裡的工作流程幫你建立一個 skill
→ 去 Figma Community 的 AI skills library 逛逛（50+ 個，持續增加中）

誠實的但書：一個平庸的 skill 會放大平庸的思維。這個工具獎勵那些說得清楚「為什麼」、而不只是「做什麼」的設計師。
