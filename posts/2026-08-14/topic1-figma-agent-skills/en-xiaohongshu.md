**Title:**
Figma Agent Skills Community Is Live — Here's the Senior Designer's Take

---

**Body:**

Figma launched community skills for the agent today. Here's the honest breakdown:

**What launched:**
50+ slash-command workflows in the Figma Community. Design systems audits, accessibility checks, research frameworks. Anyone can add them to their Figma agent with one click.

**The real angle:**
A skill is a Markdown file. It encodes your design instructions into a repeatable workflow the agent runs on demand.

Think of it like a design system — but for judgment calls.

**3 ways to think about skills:**
① Skills as labor reduction: let the agent handle the repeat work
② Skills as taste encoding: package your design philosophy into something shareable
③ Skills as cross-platform judgment: skills work with Figma's MCP server — use them in Claude or Cursor too

**Where the actual value is:**
Not in using the community skills.
In authoring the one your team can't replace.

Write down the critique you give most often. The accessibility check you do by instinct. The handoff review no one else does the same way.

That's your skill. That's your leverage.

**How to start:**
→ Open Figma agent
→ Ask it to help you create a skill based on a workflow in your file
→ Browse the AI skills library in Figma Community (50+ and growing)

Honest caveat: a mediocre skill scales mediocre thinking. This tool rewards designers who can articulate *why*, not just *what*.
