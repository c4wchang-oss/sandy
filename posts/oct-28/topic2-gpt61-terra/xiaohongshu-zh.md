---

**標題：**
GPT-6.1 Terra：便宜的電腦使用能力對設計工作意味著什麼

---

**內文：**

GPT-6.1 Terra（10 月 26 日）= 視覺推理 + 電腦使用能力 + 寫作，一個 model 搞定。比 GPT-6 Astra 快 3 倍，API 成本比 GPT-5.6 Terra 便宜 50%。在 ChatGPT Work 和 Codex 中可用。

這不只是一個更快的 model。這是讓 AI 輔助設計 QA 在例行上變得實際可行的效率點。

---

**它真正能做什麼：**

① 視覺推理：讀取產品照、行銷素材版面、建築圖
② 電腦使用：在 macOS + Windows 上點擊應用程式、瀏覽器和介面
③ 寫作：spec、摘要、結構化輸出——結果優先的風格

---

**設計 QA 使用案例：**

① 檢查行銷素材的裁切和文字排版問題
② 把產品照和 catalog 條目配對並更新清單
③ 點擊 prototype 驗證互動狀態行為
④ 標記設計 token 值和渲染 UI 輸出之間的不一致

---

**為什麼快 3 倍 + 便宜 50% 真的很重要：**

當成本下降：
- 每天例行執行這些檢查在經濟上變得合理
- 瓶頸從成本 → 轉移到 brief 品質
- Senior designer 的工作：寫一個精確的 brief，不是手動做檢查

---

**無障礙設計的連結（重要）：**

當 agents 例行使用你的產品 UI：
- 鍵盤快捷鍵 = agent 速度
- Focus ring = agent 導航
- ARIA 標籤 = agent context
- 缺少任何一個 = agent 錯誤

無障礙設計不只是合規。它是你的 agent 的可用性底線。

---

**設定方式：**

① ChatGPT 桌面 app → 切換到 Work 模式
② 安裝 Computer Use plugin
③ macOS：授予螢幕錄製和輔助功能權限
④ Windows：讓目標 app 在活動桌面保持可見
⑤ 從 Advanced 的 model 列表選擇 GPT-6.1 Terra

---

**誠實的限制：**

⚠️ 不在 Chat 中——只在 Work 和 Codex 中
⚠️ 不支援 UAE 推理駐留
⚠️ 視覺 QA 仍然需要精確的 brief——Terra 執行，不善於解讀模糊性
⚠️ 「看起來好不好」= 不是 brief。「檢查文字是否被裁切、行動裝置 CTA 可見、hex 符合 spec」= 才是 brief

---

**Senior Designer 觀點：**

問題不再是「AI 能不能檢查這個？」

而是「我的 brief 夠不夠精確，讓它能正確地檢查？」

Brief 品質現在是 AI 輔助設計 QA 的成本底線和品質上限。這是一個 DesignOps 治理問題，在它是工具問題之前。
