GPT-6.1 Terra landed on October 26th. Fast, cheap computer use. And it changes something specific about design work.

The performance profile first: Terra is 3x faster than GPT-6 Astra, 50% lower API price than GPT-5.6 Terra, and nearly matches GPT-6 Astra's benchmark scores at roughly one-tenth the token cost. For computer use specifically — operating GUIs, clicking through interfaces, running apps on macOS and Windows — this is the efficiency threshold that makes routine automation economically defensible.

The benchmark examples are worth reading carefully. "Match product photos from a supplier lookbook to catalog entries and update listings." "Check campaign assets for cropping and text placement and organize the edits." These aren't generic capability demonstrations. These are the tedious, structured, repetitive tasks sitting in the middle of actual DesignOps workflows. The tasks senior designers spend Friday afternoons on instead of the work they're actually paid to do.

At 50% lower cost and 3x faster, the economic case for automating those tasks just shifted. The bottleneck for AI-assisted design QA moves from cost to brief quality. If your brief for "check these assets" is precise enough, Terra can execute it routinely.

The accessibility tree frame I've been tracking all year is directly relevant here. When a computer use model routinely operates your product's UI to complete tasks, every inaccessible element is an agent error waiting to happen. No keyboard shortcut means the agent takes longer or fails. No focus ring means uncertain navigation. Missing label means ambiguous context. Your product's accessibility isn't a compliance checkbox. It's the quality floor for agent operability — which is now an efficiency question, not just an ethical one.

The visual reasoning side is where it gets interesting for senior designers specifically. Terra outperforms GPT-5.6 Terra on MMMU-Pro at every reasoning effort level. "Turning architectural drawings into a 3D model" is in the Agents' Last Exam benchmark. That's not pattern matching — it's spatial interpretation of visual structure. At max effort, Terra reaches near-frontier scores at one-tenth the price of GPT-6 Astra.

What that opens up practically: design validation workflows where the agent clicks through a prototype, checks copy against a spec, flags mismatches between design token values and rendered output. At a cost that makes running it daily defensible.

Available in ChatGPT Work and Codex for Plus, Pro, Business, Enterprise, Edu plans. Not in Chat — Work only. Computer Use requires the plugin plus Screen Recording and Accessibility permissions on macOS.

The honest limit: visual QA tasks still need precise briefs. Terra executes with precision; it doesn't interpret ambiguity well. "Check if the assets look good" is not a brief. "Check that no text is cropped, all CTAs are visible at mobile viewport, and brand colors match hex values in the attached spec" is a brief. Brief quality is now the cost floor and quality ceiling for this work.
