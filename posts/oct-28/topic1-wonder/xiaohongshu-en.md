**Title:**
Wonder: the AI design canvas that uses your own subscription

---

**Body:**

Wonder just released a major update (Oct 27). The key difference from every other AI design tool this year: you bring your own Claude Code or Codex subscription. Agents run locally on your machine. No extra credit meter on the Wonder side.

---

**What's New:**

① BYOA: connect Claude Code or Codex — your existing plan, your existing skills
② Live app preview on canvas: run your real app right next to your designs
③ Capture any screen as editable layers → explore in Wonder → agent applies back to code
④ Parallel agents in separate worktrees — each agent has its own project copy, no conflicts
⑤ Agent memory: remembers your project + design preferences, and you can edit what it knows
⑥ Second opinion: ask a different model to review before you ship

---

**Why BYOA Matters:**

① Wonder is the canvas — not the agent vendor
② Your existing skills, plugins, and tools travel with the agent
③ Switching agents = config change, not platform migration
④ No "AI credits" conversation with your team or finance

---

**The Canvas Story:**

Your PRD + designs + live app + code review — all on one canvas simultaneously.

Session boundary problem for AI design work? Solved from the canvas side. You never lose context between directions.

---

**Pricing:**

Free: $0 — 3,000 AI-generated layers/week, multiple parallel agents, live preview
Pro: $20/mo — unlimited layers, AI image + vector generation, publish + share with team

---

**Honest Limits:**

⚠️ Desktop only — Mac and Windows app (no browser version yet)
⚠️ Claude Code and Codex only now — Cursor + OpenCode coming soon
⚠️ Publishing and team sharing require Pro plan
⚠️ This is a canvas for your existing codebase — not a no-code generator

---

**Senior Designer Take:**

The interesting thing isn't the feature list.

It's that Wonder separated "the canvas" from "the agent relationship." Every other tool bundled them together. That separation means you can upgrade your agent independently of your design tool.

And when you can audit what the agent remembers about your project — you actually know what quality ceiling you're working with.
