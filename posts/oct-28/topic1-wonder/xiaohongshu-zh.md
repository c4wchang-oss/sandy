---

**標題：**
Wonder：用你自己 AI 訂閱的設計 canvas 來了

---

**內文：**

Wonder 剛發布了重大更新（10 月 27 日）。和今年其他 AI 設計工具最大的差別：你帶自己的 Claude Code 或 Codex 訂閱來。Agents 在本地跑。Wonder 這邊不需要額外的 credit 計費。

---

**新功能：**

① BYOA：連接 Claude Code 或 Codex——你現有的方案，你現有的 skills
② Canvas 上的 live app 預覽：你的真實 app 跑在設計旁邊
③ 把任何畫面捕捉成可編輯圖層 → 在 Wonder 裡探索 → agent 套回程式碼
④ 並行 agents 在獨立 worktree 裡——每個 agent 有自己的專案副本，不衝突
⑤ Agent 記憶：記得你的專案和設計偏好，而且你可以編輯它知道的東西
⑥ Second opinion：在出貨前讓另一個 model 來 review

---

**為什麼 BYOA 重要：**

① Wonder 是 canvas——不是 agent 供應商
② 你現有的 skills、plugins 和工具跟著 agent 走
③ 換 agent = 設定變更，不是平台遷移
④ 不需要和團隊或財務解釋「AI credits」費用

---

**Canvas 的故事：**

你的 PRD + 設計 + live app + code review——全部同時在一個 canvas 上。

AI 設計工作的 session boundary 問題？從 canvas 這側解決了。你再也不會在方向之間失去 context。

---

**定價：**

免費：$0 — 每週 3,000 個 AI 生成圖層、多個並行 agents、live 預覽
Pro：$20/月 — 無限圖層、AI image + vector 生成、發布和與團隊分享

---

**誠實的限制：**

⚠️ 只有桌面版——Mac 和 Windows app（目前沒有瀏覽器版本）
⚠️ 目前只有 Claude Code 和 Codex——Cursor + OpenCode 即將推出
⚠️ 發布和團隊分享需要 Pro 方案
⚠️ 這是針對你現有 codebase 的 canvas——不是無程式碼生成器

---

**Senior Designer 觀點：**

有趣的地方不是功能列表。

是 Wonder 把「canvas」和「agent 關係」分開了。其他所有工具都把它們綁在一起。這種分離讓你可以獨立升級 agent，不受設計工具限制。

而且當你可以審計 agent 對你專案的記憶——你才真正知道你在用什麼品質上限工作。
