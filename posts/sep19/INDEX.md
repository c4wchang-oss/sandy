### Topic 1: R/GA BRDNA Sequencer — Brand DNA as Machine-Writable Context
**Source:** https://mumbrella.com.au/r-ga-launches-ai-system-to-enhance-brand-design-application-937728

**Published:** Sep 18, 2026

**Angle:** R/GA launched BRDNA Sequencer: a product that converts a brand's existing design system (components, patterns, voice, rules) into structured, machine-readable context that coding agents like Claude Code can operate within. Mailchimp used it. The product is not self-serve — R/GA + Addition implement it — but the proof of concept at production scale is the signal. Core reframe: "AI outputs don't feel on-brand" is almost never a model problem. It's a design system legibility problem. Convergence pattern: v0 API → OUI-1 → GeekLego → Astryx → BRDNA Sequencer = constraint architecture escalating from component tokens to full brand DNA. New moat for agencies: translating design systems into agent training context. Quality ceiling = your existing DS legibility, not the model.

### Topic 2: Figma node for Weave — Your Design File Is Now a Generative AI Parameter
**Source:** https://www.figma.com/release-notes/ (Sep 17, 2026)

**Published:** Sep 17, 2026

**Angle:** Figma node lets designers copy a frame from Figma Design and paste it into a Weave generative workflow, where it becomes a live workflow parameter. You choose which layers can change (text, image fills) — everything else locks (fonts, spacing, layout, component structure). Key reframe: the Figma frame upgraded from handoff artifact → agent constraint → generative AI parameter. The design artifact now has two simultaneous roles. Quality ceiling = source frame fidelity (hardcoded hex values, inconsistent text styles, unlocked constraints all degrade generated outputs). Honest scope: this is production asset generation, not creative exploration. Role shift: senior designers design the source frame all variants inherit from; frame-level decisions are creative direction for the generative workflow downstream. Sync behavior: changes to the original Figma design propagate to all connected Weave-generated assets.
