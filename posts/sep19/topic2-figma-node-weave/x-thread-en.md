**Tweet 1 (hook — attach image)**
Figma just made your existing design file a generative AI input.

Not a reference. Not a handoff asset. Not a prompt attachment.

A live workflow parameter — with your brand's fonts, spacing, and layout locked, while text and images generate at scale.

The design artifact just got a new job description.

---

**Tweet 2**
What Figma node actually does:

Copy a frame from Figma Design → paste it into Figma Weave → it becomes a node in a generative workflow.

You choose which layers can change: text content, image fills.
Everything else — fonts, layout, spacing, component structure — stays intact.

The workflow generates variations at scale using your brand as the constraint.

---

**Tweet 3**
The mental model shift worth paying attention to:

Before: Figma frame = handoff artifact → dev builds from it
After: Figma frame = constraint parameter → agent generates within it

The same object you built for production handoff is now the quality ceiling for AI-generated campaign variations.

Two roles. One artifact.

---

**Tweet 4**
Why this works only because of design system fidelity:

If your Figma frame uses hardcoded hex values → generated outputs ignore your brand colors
If your text styles are inconsistent → generated copy doesn't inherit proper typographic hierarchy
If your layout uses unlocked constraints → variations break at different copy lengths

The sloppier the source frame, the sloppier the variations.

---

**Tweet 5**
The thing this does that's genuinely useful:

Brand-locked asset generation at scale.

Campaign localization (swap text inputs per market, lock layout).
A/B creative variants (swap image inputs, same template structure).
Content library population (generate at Weave speed, inherit brand from Figma).

The bottleneck shifts from "can we generate this?" to "is our source frame clean enough?"

---

**Tweet 6**
Sync behavior matters:

Changes to the original Figma design sync back into Weave → every connected asset updates.

This means your Figma file is no longer just the start of the workflow. It's the persistent constraint source across the entire production lifecycle.

Design change = all downstream generated assets regenerate from the same source.

---

**Tweet 7**
Honest scope check:

This is production asset generation, not ideation.
Weave workflows are systematic, not exploratory.

If you want to discover a new visual direction → AI image generation in ideation mode is the right tool.

If you want 200 on-brand campaign variations of a direction you've already designed → this is exactly right.

Different cognitive mode. Same toolchain.

---

**Tweet 8**
The role shift this creates:

Senior designers aren't generating the variants.
They're designing the source frame that all variants inherit from.

How you structure your Figma file is now creative direction for the generative workflow downstream.

Layer naming. Text style assignment. Component selection. Constraint locking.

Design quality decisions made at the frame level determine AI output quality at the campaign level.
