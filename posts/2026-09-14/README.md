## Topics

### Topic 1: Meta Astryx — Agent-Ready Open-Source Design System
**Source:** InfoQ, Sep 13, 2026
**Angle:** MIT-licensed, 8-year production-tested React design system with MCP endpoint built in. When Facebook-scale infrastructure becomes public domain, the gap that remains is your product's specific constraint intent — not the component library.

**Key points:**
- Behavior/accessibility decoupled from visual representation (correct architecture as starting point)
- `swizzle`/eject pattern: honest maintenance trade-off surfaced clearly
- MCP endpoint = component library becomes API at agent inference time
- Pattern: GeekLego → OUI-1 → Astryx = agent-ready DS infrastructure becoming public domain
- Floor moved. Ceiling is still yours.

### Topic 2: GenieUI — Constraint-First AI Mobile Interface Generation
**Source:** HN / Web Pulse, Sep 12, 2026
**Angle:** "A genie with rules is more useful than one with imagination." Inverts the typical AI design tool approach — register your design system first, AI selects only from your catalog. Quality ceiling is your component vocabulary specificity.

**Key points:**
- Constraint-first architecture (not: generate freely → constrain after)
- Output = editable component tree, not screenshot or arbitrary HTML
- Model-agnostic (Claude/Codex/Gemini/Grok/DeepSeek/Mistral)
- Quality ceiling = design system vocabulary specificity
- GenieUI makes design system debt visible in a new way
- Caveat: community v0.1, gap between component tree and deployed screen
