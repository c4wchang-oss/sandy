**Title: Figma Custom Skills: what it actually means for your design workflow**

---

Don't let the name fool you. Custom Skills isn't a "save your prompt" feature.

---

## What it actually is

Figma's Design Agent now supports Custom Skills. You describe a workflow you run repeatedly, and it becomes a reusable slash command your whole org can invoke.

For example:
- /apply-editorial-style → apply your team's editorial look
- /audit-ds-compliance → check against your design system
- /review-a11y → run an accessibility review pass

---

## Why it matters

Every workflow you repeat has a judgment logic behind it. Custom Skills encodes that logic into a reusable tool.

The same concept has appeared across:
- Cursor SKILL.md
- Cursor Projects Field Guide
- Notion Skills 3.7
- CLAUDE.md

The difference is Custom Skills is native to the Figma canvas — right where you made the judgment in the first place.

---

## The underrated additions

**File attachments**: attach references directly in agent chat

**GitHub context**: agent reads your component structure

Your brief is now multi-source:
attached refs + GitHub structure + custom skill + canvas selection = richer context

---

## Skill vs Plugin — understand this first

| | Skill | Plugin |
|---|---|---|
| Use for | Agent needs to interpret context + make judgment calls | Same input must always produce same output |
| Character | Adaptive | Deterministic |
| Example | Style consistency review | Batch layer rename |

This is a product design decision, not a preference.

---

## Honest assessment

✅ Open beta, available for Full seat users on Professional / Org / Enterprise
✅ Running skills is always free
⚠️ Skills capture what you DID, not what you INTENDED
⚠️ First session quality matters — sloppy session = sloppy skill
⚠️ Audit before publishing to your org

---

## A practical starting point

Ask yourself: what workflow do I run 10x a week without thinking?

That's your first Custom Skill prompt.

The brief that writes briefs compounds leverage across every team session.
