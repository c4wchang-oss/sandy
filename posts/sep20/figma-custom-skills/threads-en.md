Custom Skills changed what "using Figma's AI" means.

Until now, every agent session started from scratch. Same context setup. Same constraints re-explained. Same aesthetic reminders.

Custom Skills is Figma's answer. You describe a workflow you've already figured out—how to apply your editorial look, how to run a DS compliance review—and it becomes a slash command your whole team can invoke. /apply-aesthetic. /audit-ds. /check-accessibility.

This is not a new idea. SKILL.md in Cursor, Field Guide in Cursor Projects, Notion Skills in 3.7, CLAUDE.md—the same pattern keeps appearing across every major tool. Encode your judgment. Reuse it. The difference is that Custom Skills lives on the Figma canvas, inside the workflow where you made the judgment in the first place.

File attachments and GitHub context are the quieter additions. They mean the brief isn't a text box anymore. It's assembled from: reference files you attached, GitHub component patterns the agent read, your custom skill constraints, and whatever's selected on canvas. Multi-source briefs require a new kind of authoring clarity.

One distinction worth understanding before you build your first skill: a skill is adaptive—good when the agent needs to interpret context and make judgment calls. A plugin is deterministic—good when the same input should always produce the same output. Don't reach for a skill when you need a plugin, and vice versa. It's a product design decision, not a preference.

One honest caveat I keep coming back to: a skill captures what you did in a session, not what you intended. If the session that generated it was sloppy, the skill encodes that. Audit before publishing. The brief that writes briefs compounds what it inherits.

The role shift I've been tracking is now three steps deep: execution → orchestration → tool design. Custom Skills is tool design arriving on the canvas. You're no longer just a user of Figma's AI. You're authoring the AI your team uses.

What workflow do you run ten times a week without thinking? That's your first skill.
