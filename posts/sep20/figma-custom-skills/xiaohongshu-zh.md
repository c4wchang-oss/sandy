**標題：Figma Custom Skills 來了——設計師終於可以「編寫自己用的 AI」**

---

不要被「Custom Skills」這個名字騙了——這不是存 prompt 的功能。

---

## 它實際上是什麼

Figma Design Agent 現在支援 Custom Skills。你描述一個你反覆做的工作流程，它就變成一個可重複使用的斜線指令，整個組織都可以叫用。

例如：
- /apply-editorial-style → 套用你的編輯風格
- /audit-ds-compliance → 對照 design system 審查
- /review-a11y → 跑一次 accessibility 確認流程

---

## 為什麼這很重要

你每週重複的工作流程，背後都有一套判斷邏輯。Custom Skills 讓你把那套邏輯編碼成可重複使用的工具。

同一個概念在這些地方都出現了：
- Cursor SKILL.md
- Cursor Projects Field Guide
- Notion Skills 3.7
- CLAUDE.md

差別在於 Custom Skills 原生在 Figma 畫布上——就在你當初做判斷的地方。

---

## 同時推出的功能（被低估）

**檔案附件**：直接在 agent chat 裡附加參考資料

**GitHub context**：agent 可以讀你的 component 結構

這意味著你的 brief 現在是多來源的：
附加的參考 + GitHub 結構 + custom skill + canvas 選取 = 更完整的情境

---

## Skill vs Plugin：先搞清楚這個

| | Skill | Plugin |
|---|---|---|
| 適合用在 | 需要 agent 解讀情境、做判斷 | 相同輸入要永遠得到相同輸出 |
| 屬性 | 自適應 | 確定性 |
| 例子 | 審查風格一致性 | 批次重新命名圖層 |

這是產品設計決策，不是個人偏好。

---

## 我的誠實評估

✅ Open beta，Professional / Organization / Enterprise Full seat 適用
✅ 使用 skills 是免費的
⚠️ Skill 捕捉的是你「做了什麼」，不是你「想要什麼」
⚠️ 第一個 session 品質很關鍵——草率的 session 產生草率的 skill
⚠️ 發佈給組織前一定要審查

---

## 一個實用的起點

問問自己：我每週不假思索重複做 10 次的工作流程是什麼？

那就是你第一個 Custom Skill 的題目。

自己寫 brief 的 brief，會讓整個團隊每次 session 的效益複利累積。
