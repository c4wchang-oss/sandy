**標題：** Webflow 自動生成品牌指南了，但有個重要細節你要知道

---

📋 **什麼功能（9/2 上線）：**
Webflow Agent Instructions Generation
AI 讀取你的 live 網站 → 自動生成：
- 品牌指南（聲音、語氣、個性）
- 設計系統指南（元件、變數、使用規範）
- 圖片資產指南（媒體規範）
- CMS 指南（內容集合和欄位規則）

所有編輯你網站的 agent 都會把這些當作 context。
聽起來很方便，對嗎？

🤔 **令人不舒服的事實：**
它讀取的是你網站上實際存在的東西。
不是你的設計意圖，不是你的原始 brief。

開發者在 deadline 前一天晚上做的一次性修改。
沒人清理過的遺留元件。
三年來逐漸累積的所有設計不一致。

這些現在都成了你的「品牌標準」。
Agent 會忠實地遵循，包括你所有的技術負債。

🔍 **我實際上會怎麼用：**

1⃣ 生成指南
2⃣ 像讀審查報告一樣讀它 — 哪裡不對？
3⃣ 先修掉網站上最嚴重的不一致
4⃣ 用真實意圖編輯指南
5⃣ 然後才讓 agent 照著做

生成 → 審查 → 修正 → 信任。順序很重要。

⚠️ **大家都忽略的治理缺口：**
「AI 從我的網站生成的」≠「這是正確的」

在 agent 按照這些指南行動之前，誰來審查它們？

這個審查者現在是設計師的角色了。

💡 **資深 UX 設計師的觀察：**
這意外成為我見過最好的設計負債視覺化工具 — 不是因為它聰明，而是因為它誠實。它精確地告訴你 AI 會從你的出貨作品裡推論出什麼品牌形象。

出貨的和意圖的之間的落差？在 AI 繼承它之前，先由你來填補。
