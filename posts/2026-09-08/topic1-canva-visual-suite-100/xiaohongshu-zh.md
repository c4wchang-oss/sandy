**標題：** Canva 今年推出了 100 個功能 — 但沒人在討論的結構性位移

---

🎯 **發生了什麼：**
2026 年九月三日，Canva 完成了今年第 100 個 Visual Suite 功能發布的里程碑 — 從一月以來幾乎每兩天一個。

Docs、Sheets、Presentations、Whiteboards、Sites、Video。

100 個功能聽起來像產品更新。
實際上是類別宣告。

📌 **真正的位移：**
Canva 現在已經不是設計工具了。
它是工作的視覺作業系統。

全新的端到端工作流程：
1. 在 Whiteboard 開始（腦力激盪，沒有輸出格式壓力）
2. 在 Canva Docs 寫 brief
3. 資料進 Canva Sheets → AI 分析 → 自動生成圖表
4. 圖表推進 Presentations 和 Docs
5. 用自動生成演講稿 + 預估時間來 present
6. 發布到 Canva Sites 或用 Canva Code

這些步驟沒有一個需要設計師介入。

📊 **定義這個類別的數字：**
→ 每月超過十億件設計
→ 每分鐘一千份 Docs
→ 每分鐘三千份 Presentations
→ 每分鐘五千個社群貼文
→ 98% 的 Fortune 500 企業使用 Canva
→ Docs 三年採用率翻了三倍，現在是第三熱門設計類型
→ 每月超過一百萬個網站發布
→ Canva Code 超過六百萬個 coded 網站

✅ **這波更新裡真正新的東西：**
- Canva Sheets 的 AI 分析資料 → 為 Presentations 和 Docs 生成圖表
- 自動生成演講稿（投影片自動變成講稿）
- 一鍵 present、演講計時器
- Docs 支援全頁沉浸式版面和自動格式化
- 平台上超過兩億五千萬件多格式設計
- Sites：20 段導覽、更完整的 SEO 和網域控制

⚠️ **誠實的 caveat：**
「100 個功能」是行銷數字。很多都是漸進式的 — 計時器、row 分組、自動分頁、隱藏欄位。有些確實改變了工作流程。

真正重要的是戰略主張：Canva 想成為「專案生活的地方」，而不只是「圖形發生的地方」。

這從根本上是一個跟 2013 年不同的產品賭注。

💡 **資深 UX 角度：**

「地板模型」是正確的思考框架：

2013 — template 地板位移
2023 — AI 生成地板位移
2026 — productivity suite 地板位移

每一次，上一層都變成了基準假設。

你的 stakeholders 現在有了一個在每個階段都不需要設計團隊介入的完整端到端視覺溝通平台。

Brief、資料、簡報 — 沒有一樣必須走過你的 design system。

**地板上面 Canva 給不了的是什麼？**
→ 對「視覺工作是不是在問正確問題」的判斷
→ 不存在試算表裡的受眾理解
→ 需要文化脈絡的品牌決策，不只是元件庫
→ 高風險複雜工作流程的清晰設計

那是資深設計師價值濃縮的地方。
不是讓事情更快，是知道什麼值得做。
