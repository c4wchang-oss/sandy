**Title:** Stop prompting. Start building systems. Figma Weave on Community changes how AI creativity scales.

---

Most designers use AI image tools the same way: type a prompt, get an output, save it if it's good, start over tomorrow.

That process doesn't scale. Figma Weave on Community is the fix.

---

🔍 **What is Figma Weave?**

Figma Weave (built on the Weavy acquisition) is a node-based AI creative canvas. Instead of one prompt → one output, you chain AI models together in a visual workflow:

- Image Describer → reads the visual logic of a reference image
- Style Combiner → blends two visual attributes into a new definition
- Variation Generator → produces multiple options in one run
- Aspect Ratio Resizer → outputs all channel sizes automatically

The workflow has a shape. You can see every step, adjust any node, and re-run the whole sequence any time.

---

✨ **What's new: Weave on Figma Community**

Figma Weave workflows can now be published to Figma Community — the same place designers share files, UI kits, and plugins.

What this means in practice:
- Build a brand photography workflow once → publish it
- Your teammate (or anyone) opens it → swaps in their brand assets → runs it
- They get brand-consistent output without learning your prompt history

The workflow is now the shareable asset, not just the output.

---

🛠️ **5 Weave workflows worth building first**

1. **Brand style extractor** — Describe two existing brand images, combine them into a reusable style definition. Use it for all future image generation.

2. **Multi-aspect-ratio generator** — One image, automatically resized for Instagram (1:1), Stories (9:16), web hero (16:9), and more. On-brand every time.

3. **Effect variation explorer** — Run 8 different distortion effects on the same image simultaneously. Compare, pick, move on. No re-prompting.

4. **Image to 3D converter** — Turn any product reference image into a 3D model you can rotate to any angle. No product photography needed.

5. **Static to video pipeline** — Animate a hero section still image into cinematic motion using a motion reference clip.

---

💡 **The mindset shift**

The difference between a prompt and a Weave workflow is the difference between a meal and a recipe.

You can eat the meal once. You can cook the recipe forever.

When your visual system is in a workflow, it's teachable, repeatable, and doesn't live only in your head.

---

⚠️ **Honest caveats**

- Learning curve is real — node-based tools take time to internalize
- Deep Figma integration (paste Figma frames as live nodes in Weave) is still coming this summer
- Not every team needs this yet — if you're generating one-off images, a single prompt still works fine
