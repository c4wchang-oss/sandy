**Tweet 1 (hook)**
Something launched today with zero design coverage: Toolcraft — an open-source framework for AI agents to BUILD design applications.

Not AI inside a design tool. AI building the tool itself. That's a different category.

---

**Tweet 2**
What's in the box:
→ Functional canvas (not a mockup — a working one)
→ Toolbar + layer system
→ Timeline with keyframe workflows
→ Full UI component library: sliders, color pickers, font pickers

The complete application architecture of a professional creative tool, as scaffolding for an AI coding agent.

---

**Tweet 3**
The optimization detail that matters most: it ships with embedded AI skills, performance instructions, and visual testing rules.

"Visual testing rules" = agent-generated output gets checked for visual consistency before you see it. Not logic. Not functionality. Visual quality.

That's a quality gate at the tool-authorship level.

---

**Tweet 4**
The lineage here:

Voyager (Oct 10) → agents scripting EXISTING creative tools (Blender, DaVinci, Photoshop) via native APIs
Toolcraft → scaffolding for agents to CREATE new design tools from scratch

Skills convergence arc just extended to tool authorship itself.

---

**Tweet 5**
The open question nobody's asking yet: who does the taste audit for a tool nobody designed?

Toolcraft's architecture is sound. Canvas, layer system, keyframe workflows — these are correct.

But defaults, affordances, interaction discoverability — those are product design decisions. No framework can encode taste.

---

**Tweet 6**
I keep tracking the same pattern in trustworthy AI tools: constraint architecture as the signal.

Voyager: scripting API only, files stay editable, no lock-in
ProtoPie Code MCP: read-only, prototype is authoritative
Toolcraft: visual testing rules scope the agent's output quality

Constraints are what make the output trustworthy.

---

**Tweet 7**
The interesting use case isn't "coding agent builds a generic design tool."

It's: domain expert with a very specific workflow + coding agent + Toolcraft = specialized creative tool built for one exact job, with architecture that already passes visual QA.

That's a production mode that didn't exist before.
