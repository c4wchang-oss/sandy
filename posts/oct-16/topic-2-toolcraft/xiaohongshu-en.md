# Xiaohongshu Post — Toolcraft Open-Source Starter Kit (EN)

---

**Nobody in design is talking about this: Toolcraft**
**An open-source framework for AI agents to BUILD design applications — not use them**

Launched today (Oct 16), Apache-2.0. Zero design coverage. Early signal.

---

**What it includes:**

- Functional canvas (not a mockup — a working one)
- Toolbar + layer system
- Timeline with keyframe workflows
- Full UI component library: sliders, color pickers, font pickers
- Embedded AI skills for Claude, Cursor, Codex
- Performance instructions + visual testing rules for agent-generated output

---

**Why this matters more than it looks:**

The AI skills convergence arc I've been tracking is now complete: code editors → design tools → web CMSs → creative desktop apps (Voyager, Oct 10) → and now, tool authorship itself.

Toolcraft is the first framework where a coding agent doesn't operate INSIDE a creative tool — it CREATES one.

---

**What's architecturally new:**

Visual testing rules for generated output = quality gate at framework level, not prompt level.

The agent's creative output is checked for visual consistency before you interact with it. Same principle as "constraint architecture" — the constraints make the output trustworthy. Not just correct, trustworthy.

Compare:
- Voyager: agents constrained to scripting API → files stay editable, no lock-in
- ProtoPie Code MCP: read-only → prototype is authoritative, pipeline trustworthy
- Toolcraft: visual testing rules → tool-building quality is architectural, not hoped for

---

**The open question worth sitting with:**

Who does the taste audit?

Toolcraft provides sound architecture. But defaults, which interactions feel discoverable, what the affordance hierarchy communicates to users — those are product design decisions. No framework can encode taste.

This is the problem. "Absence of slop ≠ taste" (Paul Bakaus said it about Impeccable. Same applies here.)

---

**Best use case right now:**

Domain expert with a very specific creative workflow + coding agent + Toolcraft = specialized tool built for one exact job, with architecture that already passes visual QA.

That's a production mode that didn't exist before. Not "vibe-coded design app" but purpose-built tool with quality constraints baked in.

---

**Honest take:**

Zero social coverage today is exactly when these things are worth paying attention to. The tools that ended up mattering got there before the hype cycle.
