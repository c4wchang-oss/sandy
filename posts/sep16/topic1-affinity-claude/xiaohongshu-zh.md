# 小紅書貼文 — Affinity 3.3 + Claude AI Connector（中文版）
## Sep 16, 2026 | 圖片：topic1-xiaohongshu-zh.png（3:4）

---

**標題：** Affinity 現在可以和 Claude 說話了，這對你的設計生產流程代表什麼

---

Affinity 3.3 昨天更新，最值得注意的是 Claude AI Connector：一個讓 Claude 直接操作你的 Affinity 檔案的 MCP 整合。

**實際工作流程是這樣的：**

**1/ 設定方式**
開啟 Affinity 設定 → Model Context Protocol → 啟用 Affinity MCP → 重啟 Affinity → 在 Claude Desktop 安裝 Affinity Connector → 完成。

**2/ 用自然語言描述一件重複的工作**
「幫我把所有 layer 依照這個命名規則改名」
「把這個色彩填滿批次套用到所有 artboard」
「以這些尺寸和命名方式匯出所有頁面」

**3/ Claude 寫 script 並在你的 live 文件裡執行**

**4/ 把 script 存進 Scripts Panel，下次一個按鈕搞定**
可以分享給整個團隊。

---

**和一般 AI 工具的差別：**
✓ 直接讀寫你的 live 文件（不是 import/export）
✓ 同一個 script 跑在向量、像素、版面三個工作室
✓ Script 存在 app 裡面，不是消失在 chat 視窗裡

---

**誠實說明：**
→ AI 功能需要 Canva 付費方案
→ Connector 目前 beta 免費
→ 免費版只有 scripting，沒有 Claude（但 scripting 本身值得學）

---

**品質天花板在哪裡？**
不是 model — 是你的描述能不能清楚說明任務規則。
描述不清楚 → script 沒用 → 等於沒省時間。

---

**現在最值得試的場景：**
→ 品牌更新：批次改名 + 配色套用到幾百個 artboard
→ 印刷備稿：用一致命名法匯出所有版本
→ 產品圖生產：批次套用修片處理

---

**資深設計師的思考方式：**
不是「我要節省這次的時間」
而是「把這件重複的工作從我的工作描述裡面永久移除」
