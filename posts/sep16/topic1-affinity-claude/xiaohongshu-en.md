**Title:** Affinity now talks to Claude. Here's what that changes for production workflows.

---

Affinity 3.3 shipped yesterday, and the Claude AI Connector is the feature I've been waiting to see in a professional design tool.

Here's what the workflow actually looks like:

**1/ Connect Claude Desktop to Affinity via MCP**
Enable it in: Settings → Model Context Protocol → Affinity MCP → restart Affinity → install the Affinity Connector in Claude Desktop.

**2/ Describe your production task in plain language**
"Rename all layers using this naming convention..."
"Batch apply this color fill across all artboards..."
"Export all pages with these dimensions and naming..."

**3/ Claude writes a JavaScript script and executes it in your live document**

**4/ Save the script to the Scripts Panel for permanent reuse**
Next time = one click. Shareable with the whole team.

---

**What makes this different from a generic AI workflow:**
→ Read/write access to your live document (not import/export dance)
→ One script runs across vector, pixel, and layout
→ Scripts persist in-app, not trapped in a chat window

---

**Honest caveats:**
→ AI features require a Canva premium subscription
→ Connector is free in beta
→ Free tier: scripting only (still worth doing)

---

**Quality ceiling = how clearly you can describe the task.**
If you can't explain the production rule in words, Claude can't script it.

---

**Best use cases right now:**
→ Brand rollouts: batch rename + recolor across hundreds of artboards
→ Print prep: export variations with consistent naming
→ Production testing: apply treatments across a full photo library

---

**The senior move:**
Encode your most painful recurring production tasks this week. Not to save time now — to remove that class of work from your job description permanently.
