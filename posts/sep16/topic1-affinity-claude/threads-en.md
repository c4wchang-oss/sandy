Affinity shipped a Claude AI Connector yesterday. I've been thinking about what it signals more than what it does.

Their framing was: "AI that earns its place."

That's a product design decision. They're explicitly drawing the line. Production work: AI's territory. Creative decisions: yours.

Most tools blur that line because blurring it sells better. Affinity drew it because their audience — professional photographers, illustrators, designers — will notice if you don't.

What's interesting about the Scripts Panel is that it's a team knowledge artifact. Not a personal shortcut. You write a script (or Claude writes it), save it to the panel, share it with the team. That workflow gets encoded permanently.

This is the same principle as SKILL.md, design.md, CLAUDE.md. Describe the repeatable process once, in a form that machines can execute. The medium changed. The principle didn't.

Quality ceiling = your description precision. Claude builds what you ask for. If you can't describe the production task clearly, you won't get a useful script. That's not a limitation of the model. It's an argument for understanding your own workflow deeply enough to write it down.

One honest note: the AI features need a Canva subscription. The scripting itself is free. If you're on the free tier, start there. Learning to think in repeatable workflows is the skill. Claude is just one way to generate them.

The real shift: when production becomes a script, creative attention moves upstream. Not because the craft got easier — because the drag got lighter.
