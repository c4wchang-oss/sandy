## 長篇貼文

我追了一整年的 AI 設計工具發布。大部分都在加功能。Replit Design 做了不一樣的事。

他們移除了一個步驟。

以前的循環：在 Figma 設計 → 規格文件 → dev handoff → 用 code 重建 → 跟設計稿 QA → 上線。每一個步驟都是有損的翻譯。顏色偏了，間距跑掉了，最後上線的東西是你一開始設計的 80%。

Replit Design 的主張：把循環砍掉怎樣？

沒有 export，沒有重建，沒有「給 dev」。你在 canvas 上設計，準備好了，叫 agent 去 build。設計的 frame 直接變成跑起來的 app。你上傳或建的 design system，從 canvas 一路 enforce 到上線的網址。

Mobbin 整合很聰明：60 萬個真實 app 畫面，1,000+ 個 app，內建，不用帳號。把參考研究變成生成的輸入，這部分我覺得真的很有趣。

Ambient Intelligence 的說法是有野心的。在你開口問之前就建議方向，如果真的能做到，是一個真實的 UX 轉變。實際使用時，「ambient」的建議很容易變成噪音。我需要用一週才敢說這是淨正面效益。

我真正在觀察的：design system 有沒有撐得住。Constraint architecture 是過去 18 個月 AI 設計工具的核心故事。如果 Replit Design 的「一鍵對齊品牌」是真的——不只是 marketing 文案——這是這個想法第一次以 workflow-native 的方式實現。

短結論：這不是「給工程師的 Figma」。這是第一次有人誠實地嘗試讓設計和上線變成同一個步驟。

Replit Design 不是在跟 Figma 競爭。
它讓 Figma → code 的 gap 變得不重要。
Artifact 就是設計，設計就是 app。
