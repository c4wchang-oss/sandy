## Key Points
- Motion timeline is native to Figma canvas (alongside Design/Draw/Dev modes)
- Animate a component once → motion propagates everywhere, like fill styles do
- Dev Mode: inspect full timeline, copy as CSS / React / JSON
- MCP-compatible: pass animated frames directly to coding agents
- Still beta: strongest for component animations, micro-interactions, state changes (NOT screen-to-screen transitions yet)
