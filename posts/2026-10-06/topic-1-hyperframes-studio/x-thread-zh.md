**Tweet 1 — Hook**
所有 AI 影片工具都有同一個問題：
你下提示、它渲染，然後你卡在無止境的重新提示才能改任何東西。

HyperFrames Studio 上週給了一個不一樣的答案。

---

**Tweet 2**
架構很特別：

HyperFrames 的影片是一個 HTML 專案。
Agent 負責寫，Studio 負責開。
沒有匯出，沒有轉換，同一組檔案。

Agent 和人類永遠不會在兩份不同的版本上工作。

---

**Tweet 3**
任務切割是我在所有 AI 創作工具裡看過最清晰的：

→ 故事、結構、多個場景：讓 agent 處理
→ 時間點、版面、可見的動畫細節：在 Studio 裡直接編輯

介面強制這個邊界。你無法混淆它。

---

**Tweet 4**
在 Studio 這邊：中間是即時畫格，下方是時間軸，旁邊是圖層和檢查面板。

在預覽裡直接指著某個東西 → 留下備注 → agent 去處理。

跟 Shopify Sidekick 看自己輸出的截圖再調整是同一個空間標注原則。

---

**Tweet 5**
技能基礎建設的收斂剛剛到達影片製作層。

`npx skills add heygen-com/hyperframes --full-depth`

Figma Skills → Notion Skills → Framer Skills → Comfy Agent（圖像/影片工作流）→ HyperFrames。

每個創作層現在都有 agent skill 介面了。

---

**Tweet 6**
這跟我一直在追蹤的模式有關：

Ming-Image Layer（可編輯的 AI 圖像層）、Jitter AI（可編輯的動畫層）、Mirage Tesseract（關鍵幀存取）、HyperFrames Studio（共享影片時間軸）。

AI 輸出被設計成製作的起點，不是完成品。
這個類別現在完整了。

---

**Tweet 7**
誠實的注意事項：
- macOS + Linux 桌面應用程式（Windows 即將推出）
- 影片 = HTML/GSAP/CSS——不是每個製作流程的原生格式
- Agent 的第一個版本是草稿，不保證是最終成品
- Apache 2.0，免費開源（本地渲染不需要 HeyGen 點數）

早期階段，但架構方向是對的。

---

**Tweet 8 — CTA**
HyperFrames 的洞察不是「AI 可以製作影片」。

而是 AI 影片的正確協作模式是：同一組檔案、清晰的任務切割、細節精確時用空間標注。

這個模式適用於每個 AI 創作工具。
大多數工具還沒搞清楚這件事。
