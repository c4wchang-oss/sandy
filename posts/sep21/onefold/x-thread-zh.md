**Tweet 2**
Onefold 掃描你現有的網站，產生 DESIGN.md——一個放在程式碼旁邊的純 markdown 文件。

它告訴 coding agent：你的顏色、字型、深色模式邏輯、圓角半徑、陰影、component 函式庫、icon set、語氣指南，和要避免的 pattern。

跟 AGENTS.md 對程式碼的角色一樣。設計端現在也有了對應的東西。

**Tweet 4**
誠實的讀法：Onefold 萃取的是你部署了什麼，不是你想要什麼。

每個沒有文件記錄的例外。每個不一致的圓角半徑。每個從設計系統漂移出去的顏色。

AI agent 會把這些全部繼承為「你的品牌標準」。這才是讓人不舒服的發現。

**Tweet 5**
我真正會推薦的工作流程：

1. 對你的公開網站跑 Onefold
2. 讀它萃取了什麼
3. 決定：刻意為之，還是漂移累積的
4. 在你的實際設計系統裡修正漂移
5. 然後再讓 agent 指向清理過的 DESIGN.md

關鍵的工作發生在他們操作指南第六步之前。
