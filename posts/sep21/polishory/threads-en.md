The quality problem with AI-generated UIs was never generation. It was always review.

When someone uses an AI tool to build a website in 10 minutes, what framework do they have for evaluating what came back? Polishory launched September 19 as an answer: scan any public URL, get a design scorecard — visual feedback linked to screenshots, prioritized recommendations for spacing, layout, typography, hierarchy. No source code required.

The honest read: this is floor enforcement. Polishory flags the most obvious quality signals. Inconsistent spacing. Crowded layout. Weak typographic scale. Poor visual hierarchy. The same way an automated accessibility checker flags missing alt text and insufficient color contrast. It's genuinely useful. It's not sufficient.

The meta-layer worth sitting with: Polishory was built in 3 days using GPT-6 Astra. The tool diagnosing AI slop was built with the same class of tool that produces it. I'm not bringing this up as a gotcha — it's just the honest state of the industry. The constraint logic that makes an audit meaningful is still human-authored. "What does quality mean for this audience, this context, this interaction goal" is a judgment call no scorecard captures automatically.

Where this lands for senior UX practice: quality review is splitting into two tiers. Automated floor enforcement — mechanical checks: does spacing follow a rhythm, is contrast sufficient, is hierarchy legible, are elements aligned. And judgment-based ceiling work — does this earn trust for a first-time user, is this the right information hierarchy for someone who's already decided, does the visual personality fit or just look generically competent.

The first tier is being automated, and that's good. It catches the obvious failures before they ship. The second tier is what senior designers actually do. The uncomfortable version: most clients can't tell the difference between the two tiers. The floor is now automated for anyone with a URL. The ceiling is still what you're paid for — if you can articulate why.

AI slop isn't a generation problem. It's a review problem. And "review" is not one thing.
