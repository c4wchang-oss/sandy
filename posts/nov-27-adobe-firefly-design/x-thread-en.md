## X THREAD

**[Tweet 1 — Hook]**
Adobe just launched Firefly Design (beta).

One workspace: raster, vector, motion, 3D, print. No app switching. Creative Agent now lives in Photoshop, Premiere, Illustrator, InDesign, After Effects, Frame.io.

The interesting part isn't the feature list. It's what it signals about where the production pipeline is going.

🧵

---

**[Tweet 2]**
What Firefly Design actually is:

One workspace that combines raster editing + vector illustration + motion + 3D + print design. Previously these lived in 6 separate CC apps.

The Creative Agent runs inside each one, handling multi-step tasks. You remain in the director's chair. Layers, vectors, sequences stay fully editable throughout.

This is Adobe's first step toward collapsing the multi-app CC production stack into one surface.

---

**[Tweet 3]**
Plan mode is the design decision worth pausing on:

Before the agent starts executing, it shows you a plan. You can review, edit, approve — or switch to full autonomous mode and let it run.

This is the two-phase trust architecture pattern, applied at the platform layer. Pre-generate approval gate + post-execute result.

The honest version: plan mode is as useful as the brief quality going into it. A vague instruction produces a plan you'll still have to revise five times.

---

**[Tweet 4]**
The Creative Agent across all CC apps:

Premiere: apply an effect to every clip in a sequence, track a masked subject across a frame, adjust colour and exposure across a whole sequence at once.
Illustrator, InDesign, After Effects: multi-step tasks delegated, Creative Agent handles them.
Photoshop: batch retouch portraits, turn product shots into short-form social videos.

All in beta. Availability per app is uneven. "Beta across all CC" ≠ shipping everywhere at the same quality.

---

**[Tweet 5]**
Brand preferences as agent context:

You can now save preferred formats, colours, brand guidelines, characters and products inside Firefly.

The agent reads them on every generation without you re-prompting. This is the same pattern as Luma Brand Kit, Higgsfield, Automo — brand constraints loaded once and read automatically.

Same honest caveat: the brand context is only as good as what you upload. Undocumented visual decisions don't get captured just because there's a slot to upload guidelines.

---

**[Tweet 6]**
The most interesting thing in the announcement: local MCP integrations.

External agents (Claude, Cursor, any MCP client) will be able to connect directly to Photoshop, Illustrator, Premiere, After Effects — editing project files on your own computer. Layers, vectors, sequences stay editable. Human can step in at any moment.

This is in private beta, targeting early 2027. Web platform MCPs (Webflow → Elementor → Framer) closed in 46 days. Desktop creative production MCPs are the next arc.

---

**[Tweet 7]**
Honest caveats:

→ Firefly Design: beta, not GA — shipping timeline unclear
→ Creative Agent across CC: beta in most apps, Photoshop is a separate beta app
→ Local MCP integrations: private beta, targeting early 2027 — not available now
→ "AI Assistants" is Firefly rebranding, not all assistants use the Creative Agent yet
→ Preference saving: "saves brand guidelines" means as reference input, not as structural design constraint enforcement

---

**[Tweet 8]**
The reframe:

Adobe Firefly Design is not "AI tools in Photoshop."

It's Adobe's bet that the multi-app production stack collapses into a single workspace where the agent coordinates across media types — raster, vector, motion, 3D, print.

Plan mode + local MCP integrations + brand preferences = the architecture is constraint-first, not prompt-first. When local MCP ships, external agents will treat CC the same way they treat Figma files: read the production source, not a screenshot.
