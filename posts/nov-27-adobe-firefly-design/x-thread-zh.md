## X THREAD

**[Tweet 1 — Hook]**
Adobe 剛剛推出了 Firefly Design（beta）。

一個 workspace：點陣、向量、動態、3D、印刷。不用切換 app。Creative Agent 現在住在 Photoshop、Premiere、Illustrator、InDesign、After Effects、Frame.io 裡。

有趣的不是功能清單。是它對生產流程走向的暗示。

🧵

---

**[Tweet 2]**
Firefly Design 實際上是什麼：

一個合併了點陣編輯 + 向量插畫 + 動態 + 3D + 印刷設計的 workspace。以前這些分散在 6 個不同的 CC app。

Creative Agent 在每個裡面運行，處理多步驟任務。你留在導演椅上。圖層、向量、序列在整個過程中保持完全可編輯。

這是 Adobe 把多 app CC 生產堆疊折疊成一個表面的第一步。

---

**[Tweet 3]**
Plan mode 是值得停下來看的設計決策：

在 agent 開始執行之前，它先給你看一個計劃。你可以審查、編輯、批准——或切換到完全自主模式讓它自己跑。

這是兩階段信任架構模式，應用在平台層。生成前批准閘 + 執行後結果。

誠實的版本：plan mode 和進入它的 brief 品質一樣有用。模糊的指令產生一個你還是要修改五次的計劃。

---

**[Tweet 4]**
Creative Agent 在所有 CC app：

Premiere：把一個效果套用到序列中的每一個片段、跨影格追蹤遮罩主體、一次調整整個序列的色彩和曝光。
Illustrator、InDesign、After Effects：委派多步驟任務，Creative Agent 處理。
Photoshop：批量修圖人像、把產品照片轉成短影音。

全部在 beta。每個 app 的可用性不均。「beta 遍及所有 CC」≠ 以同樣品質到處出貨。

---

**[Tweet 5]**
品牌偏好設定作為 agent 上下文：

你現在可以在 Firefly 裡儲存偏好的格式、顏色、品牌指南、角色和產品。

Agent 在每次生成時都會讀取它們，不需要你重新提示。這和 Luma Brand Kit、Higgsfield、Automo 是同樣的模式——品牌約束載入一次，自動讀取。

同樣的誠實前提：品牌上下文和你上傳的一樣好。未記錄的視覺決策不會因為有一個欄位可以上傳指南就被捕捉到。

---

**[Tweet 6]**
公告中最有趣的東西：Local MCP 整合。

外部 agent（Claude、Cursor、任何 MCP 客戶端）將能直接連接到 Photoshop、Illustrator、Premiere、After Effects——在你自己的電腦上編輯專案檔案。圖層、向量、序列保持可編輯。人類可以隨時介入。

這在 private beta，目標是 2027 年初。Web 平台 MCP（Webflow → Elementor → Framer）在 46 天內完成。桌面創意生產 MCP 是下一個弧。

---

**[Tweet 7]**
誠實的前提：

→ Firefly Design：beta，不是 GA——出貨時間不明
→ CC 的 Creative Agent：在大多數 app 中是 beta，Photoshop 是獨立的 beta app
→ Local MCP 整合：private beta，目標是 2027 年初——現在還沒有
→「AI Assistants」是 Firefly 的重新品牌，不是所有助手都還在使用 Creative Agent
→ 偏好設定儲存：「儲存品牌指南」意思是作為參考輸入，不是結構性設計約束執行

---

**[Tweet 8]**
重新定框：

Adobe Firefly Design 不是「Photoshop 裡的 AI 工具」。

這是 Adobe 的賭注：多 app 生產堆疊折疊成一個單一 workspace，agent 在媒體類型之間協調——點陣、向量、動態、3D、印刷。

Plan mode + local MCP 整合 + 品牌偏好設定 = 架構是約束優先，不是提示優先。當 local MCP 出貨時，外部 agent 對待 CC 就像對待 Figma 檔案一樣：讀取生產來源，不是截圖。
