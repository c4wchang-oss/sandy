**Tweet 1 (hook)**
Wix 昨天推出了 Studio Two。

大家都在說「更好的 Wix 編輯器」。

它真正是什麼：第一個承認自己不是 agent 的 web CMS。

---

**Tweet 2**
Studio Two 把三種模式放進同一個編輯器：
AI 生成 → pixel 級精確的視覺畫布 → 標準 React 程式碼。

你在需要的時候自由切換。不需要 export，不需要 import，不需要另外的工具。

這是一個更誠實的模型，貼近專業 web 設計實際的工作方式。

---

**Tweet 3**
Aria 2.0 包含 Skills。

把你的標準儲存一次——命名規範、元件偏好、工作流程步驟。Aria 在每個專案自動套用。

和 Figma Skills、Framer Skills、Cursor Field Guide 一樣的模式——現在在 web CMS 的規模。

每個客戶少重新解釋一次。

---

**Tweet 4**
「開放性」的部分是真的有意思：

用任何 AI 工具構建。Import 到 Studio Two 做視覺精修。Export 成標準 React。在 Claude、Codex 或 Cursor 繼續做。再 bring back。

Web builder 終於停止和你的 agent 競爭。它成為你的 agent 工作的畫布。

---

**Tweet 5**
MCP 的延伸關閉了一個弧線：

Webflow（9/6）→ Elementor（9/23）→ Framer（10/22）→ Wix CMS 業務邏輯層（11/2）。

設計畫布層在 46 天內在三個平台上收斂。Wix 把它延伸到商店、預約——真實的業務資料，不只是版面。

---

**Tweet 6**
誠實的地方：

「標準 React export」在 frontend 是真實的。

Wix business solutions（商店、預約）不跟著 export 走。

如果你在做簡單的網站：很乾淨。如果你用了 Wix 的資料基礎設施：React 是你的，CMS 不是。

在向企業客戶推介之前，先搞清楚你到底從什麼解耦了。

---

**Tweet 7**
在為你的團隊設置 Aria 2.0 Skills 之前，資深設計師應該問的問題：

你到底在 encode 什麼？

命名規範和元件偏好 = 耐久。
六個月後你會重新審視的審美意見 = 小心。

Skills 儲存你的流程，不儲存你的判斷。

**Tweet 8 (CTA)**

這不只是行銷話術。

這是資深設計師在 AI 優先的 web builder 時代，agency 在哪裡的正確答案。
