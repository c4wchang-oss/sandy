**Title:** Wix Studio Two is the first web builder that admits it's not the agent

---

The update: Wix Studio Two (Nov 2, 2026) — an AI-native professional web editor combining AI generation, pixel-level canvas design, and standard React code in one surface. Built for agencies and professional web creators.

Why this matters for senior UX designers:

**01 THREE MODES, ONE EDITOR — NO HANDOFFS**
Generate with Aria 2.0 (AI). Switch to canvas for pixel-level visual control with drag-and-drop precision. Edit React code directly in the browser (VS Code environment). No export step. No re-import. You move between them based on what the project needs at that moment.

**02 SKILLS AT WEB CMS SCALE**
Save your standards once (naming conventions, component preferences, workflow steps) → Aria 2.0 applies them across every project automatically.
Same pattern as Figma Skills + Framer Skills + Cursor Field Guide.
One less re-explanation per client. Your workflow knowledge lives in the tool — not a Notion doc nobody finds.

**03 BYOA — BRING YOUR OWN AGENT**
Build with Claude, Codex, or Cursor externally. Import into Studio Two for visual refinement. Export as standard React. Continue in any IDE. Bring it back. The platform stopped competing with your agent and became the canvas your agent works on.

**04 MCP FOR BUSINESS LOGIC**
Agents can manage Wix Stores and Bookings via MCP. Web platform MCP arc: Webflow (Sep) → Elementor (Sep) → Framer (Oct) → now Wix CMS business layer (Nov). Design canvas + business data, both agent-accessible.

---

What Studio Two WON'T decouple:

✓ Frontend React code: genuinely portable
✗ Wix Stores, Bookings, business data: stays on Wix infrastructure
Know what you're actually decoupled from before pitching this as vendor-neutral to enterprise clients.

---

Skills governance moment:

Before you set up Aria 2.0 Skills for your team — document what you're encoding.

Naming conventions + component preferences = durable constraints.
Aesthetic opinions you'll revisit in 6 months = be careful. Skills encode your workflow logic, not your taste judgment.

---

The frame I'm keeping:

"AI accelerates the work, but the professional remains the creative director."

Not marketing. That's the right answer to where designer value sits in an AI-first web builder.
