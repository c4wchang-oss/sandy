**Tweet 1 (hook)**
Wix launched Studio Two yesterday.

Everyone's calling it "a better Wix editor."

What it actually is: the first web CMS that admitted it's not the agent.

---

**Tweet 2**
Studio Two puts three modes in one editor:
AI generation → pixel-level visual canvas → standard React code.

You switch between them as the project needs. No export. No import. No separate tools.

This is a more honest model of how professional web design actually works.

---

**Tweet 3**
Aria 2.0 includes Skills.

Save your standards once — naming conventions, component preferences, workflow steps. Aria applies them to every project automatically.

Same pattern as Figma Skills, Framer Skills, Cursor Field Guide — now at web CMS scale.

One less thing you re-explain per client.

---

**Tweet 4**
The "open" part is genuinely interesting:

Build with any AI tool. Import into Studio Two for visual refinement. Export as standard React. Continue in Claude, Codex, or Cursor. Bring it back.

The web builder finally stopped competing with your agent. It became the canvas your agent works on.

**Tweet 5**
The MCP extension closes an arc:

Webflow (Sep 6) → Elementor (Sep 23) → Framer (Oct 22) → Wix CMS business logic layer (Nov 2).

The design canvas layer took 46 days to converge across 3 platforms. Wix extends it to stores, bookings — actual business data, not just layout.

**Tweet 6**
The honest caveat:

"Standard React export" is real for the frontend.

Wix business solutions (Stores, Bookings) don't travel with the export.

If you're building a simple site: clean. If you're using Wix data infrastructure: the React is yours, the CMS isn't.

Know what you're actually decoupled from before pitching to enterprise clients.

**Tweet 7**
The senior question before setting up Aria 2.0 Skills for your team:

What are you actually encoding?

Naming conventions + component preferences = durable.
Aesthetic opinions you'll revisit in 6 months = be careful.

Skills save your workflow, not your judgment.
