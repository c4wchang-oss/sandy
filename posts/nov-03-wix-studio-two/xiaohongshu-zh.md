**標題：** Wix Studio Two 是第一個承認自己不是 agent 的 web builder

---

更新：Wix Studio Two（2026/11/2 發布）——一個 AI 原生的專業 web 編輯器，在同一個介面裡結合 AI 生成、pixel 級視覺畫布設計、標準 React 程式碼。為機構和專業 web 創作者設計。

為什麼這對資深 UX 設計師有意義：

**01 三種模式，同一個編輯器——不需要 handoff**
用 Aria 2.0（AI）生成。切換到畫布用拖放做 pixel 級精確的視覺控制。直接在瀏覽器裡編輯 React 程式碼（VS Code 環境）。不需要 export 步驟，不需要重新 import。根據專案當下的需求在三種模式之間切換。

**02 Skills 在 web CMS 規模**
把你的標準儲存一次（命名規範、元件偏好、工作流程步驟）→ Aria 2.0 在每個專案自動套用。
和 Figma Skills + Framer Skills + Cursor Field Guide 一樣的模式。
每次接案少一次重新解釋。你的 workflow 知識住在工具裡——不是在一個沒人找得到的 Notion 文件裡。

**03 BYOA——自帶 Agent**
用 Claude、Codex 或 Cursor 在外部構建。Import 到 Studio Two 做視覺精修。Export 成標準 React。在任何 IDE 繼續。再 bring back。這個平台停止和你的 agent 競爭，成為你的 agent 工作的畫布。

**04 業務邏輯層的 MCP**
Agent 可以透過 MCP 管理 Wix Stores 和 Bookings。Web platform MCP 弧線：Webflow（9 月）→ Elementor（9 月）→ Framer（10 月）→ 現在是 Wix CMS 業務邏輯層（11 月）。設計畫布加業務資料，都可以被 agent 存取。

---

Studio Two 不會幫你解耦的：

✓ Frontend React 程式碼：真的可攜帶
✗ Wix Stores、Bookings、業務資料：留在 Wix 基礎設施上
在向企業客戶把這個定位成廠商中立的選項之前，先搞清楚你到底從什麼解耦了。

---

Skills 治理時刻：

在你為你的團隊設置 Aria 2.0 Skills 之前——文件化你到底在 encode 什麼。

命名規範和元件偏好 = 耐久的 constraints。
六個月後你會重新審視的審美意見 = 小心。Skills encode 你的 workflow 邏輯，不是你的品味判斷。

---

我留下的框架：

「AI 加速工作，但專業人士依然是創意總監。」

不是行銷話術，這是資深設計師在 AI 優先的 web builder 時代，價值所在的正確答案。
