**[長文]**

Wix Studio Two 最有意思的地方不是功能，是它的架構承認了什麼。

多年來，web builder 互相競爭「誰最聰明」。在這裡生成、在這裡編輯、在這裡 host，不要離開。每一次發布都是讓 AI 更大，而不是讓流程更誠實。

Studio Two 刻意打破了這個模型。

同一個編輯器裡有三種模式：AI 生成、pixel 級精確的視覺畫布、在瀏覽器裡直接寫 React 程式碼。你在需要的時候切換——不需要 export，不需要 import，不需要另外的工具。Aria 2.0 生成，你在畫布上精修，你直接編輯程式碼，你從任何外部 AI 工具 import 進來，你 export 成標準 React 然後在 Claude 或 Cursor 繼續，你再 bring back。

這個平台停止嘗試擁有你的 workflow，轉而成為你的 workflow 運作的畫布。

對資深設計師來說最值得仔細看的是 Skills。把你的標準儲存一次——命名規範、元件偏好、具體的工作流程步驟——Aria 在每個專案自動套用。和 Figma Skills、Framer Skills、Cursor Field Guide 一樣的模式。每次接案少一次說明。Constraint document 現在住在工具裡，不是在一個你希望大家找得到的 Notion 文件裡。

MCP 的延伸關閉了我一直在追蹤的弧線：Webflow（9/6）→ Elementor（9/23）→ Framer（10/22）→ 現在是 Wix CMS 業務邏輯——商店、預約——透過 MCP。三個平台在 46 天內各自跑了一樣的劇本。Wix 把它從設計層延伸到業務資料層。

誠實的地方：「標準 React export」在 frontend 是真實的。Wix business solutions 不跟著走。在你把這個定位成廠商中立的選項之前，先搞清楚你到底從什麼解耦了。

他們發布文案裡的這句話我留下了：「AI 加速工作，但專業人士依然是創意總監。」

這不是行銷話術。這是設計師的價值在這套系統裡真正所在的地方。而且比那些還在試圖取代設計師的工具，這是更好的賭注。

**[短版觀點]**

Web builder 花了多年嘗試取代設計師。

Studio Two 嘗試了不同的事：讓設計師在他們已經工作的每一層都更有能力。

這是更好的賭注。
