📦 **What Component AI Can Do**

① Convert existing layers → local components via natural language
② Swap component instances with text prompts
③ Override component variables (no manual inspector needed)
④ Studio AI reads scene structure, reuses existing variables — zero duplicates

⚠️ **One Constraint To Know**

Studio AI cannot "see" visual design on canvas
→ Reads layer structure + property data only

This is actually correct behavior
AI operates inside your architecture, not around it

Before → AI generates interactions, ignores component architecture
Now → AI has a working model of your component system, navigates inside it

The difference between an AI that generates and an AI that understands structure
