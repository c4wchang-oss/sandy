# v0 Design Systems 2.0
## 平台：小紅書
## 語言：繁體中文

---

**標題：** v0 Design Systems 2.0！AI 學會了你的團隊怎麼真正在用 component

---

🎯 **這次改變了什麼**

v0 不只是新增了 design system 支援，而是整個重寫了理解 design system 的方式——從你的真實 codebase 學習，不是從你的文件。

---

🔧 **可以 Import 的來源**

① GitHub repository（component 定義 + 真實使用模式）
② npm package（公開和私有）
③ Storybook 文件
④ Figma frame
⑤ 現有 UI 截圖
⑥ ZIP 壓縮包和已部署的 live app

把真實的東西交給它——它自己搞清楚剩下的。

---

🧠 **v0 實際學習了什麼**

不只是「哪些 component 存在」——而是：
→ 哪些 prop 常常一起被使用
→ 你的團隊怎麼組合 component
→ 哪些 pattern 在真實實作裡重複出現
→ Provider 設定、global styles、字型設定

使用智慧，不只是 component 清單。

---

✅ **每次 Build 都驗證**

v0 每次 build 都讀取你真實的 component source（read-only），確認：
→ 這個 prop 存在嗎？
→ 這個 token 名稱解得開嗎？
→ 這個 icon 有 export 嗎？

不會幻覺出不存在的 prop，不猜 hex 值，你的系統，已驗證。

---

🎨 **五個 Design System 的 Demo**

同一個 prompt：「做出 GitHub 的介面」
分別用 5 個 design system 跑：Fluent / Carbon / Polaris / Cloudscape / Primer

→ 5 個完全不同的輸出

你的 design system 是一個創意視角，不是一份約束文件。

---

💡 **從 Senior UX 角度看這件事**

如果你的 design system 是 AI 的約束層：
Design system 品質 ＝ AI 輸出的品質上限

Token 凌亂 → AI 輸出凌亂
Variant 沒有文件 → AI 選錯
文件和真實使用有落差 → AI 忠實地重現落差

維護 design system 已經是 AI 工作流的基礎設施了。

問問自己：你上次看你的 design system 是怎麼被「使用」的（不是怎麼被「記錄」的），是什麼時候？
