# X Thread — Figma Design Agent + Weave：免費 Beta 將在10月6日結束（繁體中文）
**主題：** Figma Design agent 和 Weave 工具在2026年10月6日正式 GA——從免費 beta 轉為消耗 AI credits，agent 採浮動費用模型，Weave 工具採固定費用
**角度：** 免費 beta 還剩四天。浮動 credit 費用意味著 brief 品質現在也是 credit 效率。這是治理時刻，不是產品公告。

---

**Tweet 1 / Hook**
Figma 的 Design agent 和 Weave 工具將在10月6日正式 GA。

免費 beta 還剩四天。

這不是產品公告。是一個治理時刻。

以下是在計費開始之前你需要知道的事。

---

**Tweet 2**
兩件事同時為真：

Design agent 現在對維護和審查複雜檔案確實有用。而且它的 credit 費用「會根據你 prompt 的複雜度、agent 採取的動作，以及你提供的脈絡而變化」。

浮動 credit 費用意味著你的 brief 品質現在也是你的 credit 效率。

一個描述不清的 prompt 不只是產出更差的結果。它在 agent 試圖搞清楚你意思的過程中燃燒更多 credits。

---

**Tweet 3**
Weave 工具有固定的每工具費用。Design agent 沒有。

當你在建立治理的時候，這個區別很重要。

固定費用 = 可預測的預算。浮動費用 = 需要使用監控。

對於同時運行兩者的組織，Design agent 的 credit 消耗會追蹤你的團隊 prompt 品質——不只是使用頻率。

---

**Tweet 4**
你附加的脈絡會改變費用。

「連接的 libraries 和附加的檔案」被明確列為 Design agent 的 credit 費用變數。

這是 Figma 第一次明確說明更好的 brief 需要更多 credits 來運行。

重新框架：優化你的脈絡現在是一個經濟決策，不只是品質決策。兩者同時。

---

**Tweet 5**
Figma 本週發布了一個 Workflow Lab 教學，值得在 credits 開始計費之前閱讀。

從設計系統在 Weave canvas 上做全套 campaign production：Figma 節點作為鎖定的設計約束 → 生成 → Any LLM 節點跨5個市場做在地化，每個節點配置了市場特定的文案指導原則 → 可編輯圖層回到 Figma。

這是 Weave 固定 credit 模型的高槓桿使用案例：帶有清晰 brief 的結構化、高量 production 工作。
