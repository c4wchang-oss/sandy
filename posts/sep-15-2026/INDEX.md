### Topic 2: Cursor Auto-review — Autonomy as a Dial, Not a Switch
**Source:** https://cursor.com/blog/agent-autonomy-auto-review
**Angle:** Classifier agent reviews actions in context before they run; blocks return explanation to parent agent (not user); parent agent recalibrates. The governance UX problem isn't confirmation dialogs — it's designing an agent that tells another agent when to slow down.
