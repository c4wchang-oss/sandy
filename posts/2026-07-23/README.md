## Topics

### Topic 1: Figma 2026 AI Report
**Source:** https://www.figma.com/blog/2026-ai-report/
**Core Angle:** "When AI can 10x anyone, personal productivity stops being the thing to optimize for."
**Key Stats:**
- 41% of designers now participate in development (doubled in 1 year)
- 60% of developers doing design work
- 50%+ teams abandoned linear handoffs
- 61% building interactive prototypes (was 10% last year)
- 70% say AI helps them do work they previously couldn't
- AI changed team collaboration: 7% → 41% in 3 years
- 76% do at least half their work on the canvas
- 90% say design is as/more important post-AI

**Senior UX Frame:** The design role didn't shrink — the design skillset got distributed. You're not designing pixels, you're designing decisions.

### Topic 2: Flowstep AI
**Source:** https://flowstep.ai / https://dev.to/hadil/top-5-ai-ui-design-tools-in-2026
**Core Angle:** "UI is code from the start — the first AI design tool that thinks in flows, not screens"
**Key Features:**
- Multi-screen user flow generation (not isolated screens)
- Canvas is built on code from start (React + TypeScript + Tailwind CSS)
- "Generate next step" — flow expansion from any screen
- DESIGN.md as context input (constraint architecture travels with prompt)
- MCP integration to Cursor, Claude Code, Windsurf
- Plugin-free ⌘C/⌘V paste into Figma
- PRD / reference image / URL as context

**Senior UX Frame:** Designing a full flow from one prompt forces you to validate UX logic upfront — the AI surfaces the missing states and dead ends you skipped.
