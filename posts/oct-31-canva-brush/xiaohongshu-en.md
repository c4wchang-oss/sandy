## Title
Canva Brush drops: the AI design model that edits, not generates

---

## Content

Not an image generator. Not a better prompt box. An editing model.

Canva Brush is a vision-language model built to edit existing designs — understanding structure, making targeted changes, leaving the rest intact.

**What makes it different from every other AI design tool:**

1. **Sees your design structure** — not just pixels. It understands how your layout is composed before touching anything.
2. **Agentic loop with self-review** — writes code → inspects result → continues. The review loop is baked into the model, not bolted on.
3. **Fully editable outputs** — text, layout, colors: everything stays yours to refine manually after Brush finishes.
4. **Two models, two jobs** — Craft generates new imagery. Brush edits existing designs. Clearly scoped, both built in-house by Canva Research.

**Why the RL training setup matters:**
The reward system was defined by professional designers, not pixel metrics. Quality is taste-defined. That's the right call — even if we don't yet know how well it scaled.

**Performance numbers:**
→ 69% faster for general editing tasks
→ 46% lower cost per edit vs. previous agent

**The honest caveats:**
- Canva Pro only at launch (no free tier)
- No public API yet
- The real test: brand-constrained multi-page enterprise editing — not in the announcement

**Senior UX read:**
The design model category is now confirmed: Linearity Vector → Vyb → Canva Craft (generation) → Canva Brush (editing). This is the first time we have a VLM specifically trained for editing the design layer at consumer scale.

The model being shaped by designer judgment, not just user volume, is the detail worth tracking long-term.
