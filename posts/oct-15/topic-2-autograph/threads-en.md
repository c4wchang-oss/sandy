# Threads Post — Autograph 2027 + MCP (English)

---

**Long-form version:**

Motion is the last uncodified design dimension in most organizations.

Color has named tokens. Typography has named scales. Spacing has named grid units. Components have documented variants with interaction states. Motion has... Notion docs. Slack threads. An easing curve in someone's head that gets lost when they leave.

Figma Motion added named publishable animation styles in October. For the first time, motion tokens exist in the design tool — something color and typography have had for a decade. That was a governance step.

Autograph 2027.0 shipped yesterday and it's a different kind of step.

Autograph is Maxon's free motion-graphics tool — logos, campaign graphics, promotional artwork, looping animations. In 2027.0 (released October 14), they added MCP support. Claude and ChatGPT can now build compositions directly inside the application, using Autograph's native Bounce and Elastic animation controls, constructing responsive layouts. The agent works inside the app, not in a prompt-to-export pipeline.

This closes another segment of the skills infrastructure arc I've been tracking: code editors → Figma agent skills → web CMSs → Comfy Agent for AI image/video workflows → Voyager for professional creative desktop apps (After Effects, Premiere, Ableton) → now Autograph for motion graphics. Every creative tool layer has agent access. The arc is complete.

What this means practically for motion designers and senior UX people who manage motion:

The execution bottleneck is gone. The agent can construct animations inside the tool. Which means the only remaining bottleneck is brief quality — and that gap has been growing. Jitter AI (October 3) already confirmed that AI motion model capability now exceeds most users' brief quality. What Autograph MCP does is extend that same dynamic to motion graphics tools.

You have to write like a motion director now. Not a prompt engineer.

The governance question this makes urgent: who owns the motion style library? In most organizations, color ownership is clear (brand team). Typography is clear (design systems). Motion lives in the gap between brand (personality, timing feel) and engineering (performance, accessibility). Figma Motion made this gap unavoidable by creating the infrastructure. Autograph MCP makes it consequential by giving agents execution access.

Honest caveat: this is a free motion-graphics app — not After Effects at production scale, not Cinema 4D. The MCP integration means an agent can construct a motion-graphics composition, not that it understands what the animation should feel like. The taste problem — emotional register, pacing, whether the easing feels like the brand — is still yours.

**Short punchy take:**

Motion has agent access now.

The governance question that follows: who owns the motion constraints the agent works from?

Brief quality is the bottleneck. Not tool access.
