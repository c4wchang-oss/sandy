**推文 1（Hook）**

這是一個免費的動態圖形工具。它現在有 MCP。Claude 和 ChatGPT 可以在實際的應用程式內建構 composition、應用 Bounce 和 Elastic 動畫控制，並建構響應式版面。🧵

---

**推文 2**
Autograph 是 Maxon 的免費動態圖形應用程式。在 2027.0（10 月 14 日發布）中，他們加入了內建的 MCP 連接。

這意味著什麼：相容的 AI 助理可以直接在工具內建構 composition、使用 Autograph 的原生動畫控制（Bounce、Elastic 曲線），並建構響應式版面。

沒有 prompt 到 export 的 pipeline。Agent 在應用程式內部工作。

---

**推文 3**
為什麼這比另一個「工具獲得 AI」更重要：

動態效果是大多數設計系統中最後一個未被編碼的設計維度。

顏色：命名的 token。字體：命名的比例。間距：命名的單位。動態效果：Notion 文件和 Slack 討論串。沒有任何地方強制執行。

Constraint stack 現在正直接延伸到動態工具中。

---

**推文 4**
收斂的弧線：

程式碼編輯器中的 skills → Figma agent skills → Framer skills → web CMS agent 存取 → Comfy Agent（圖片/影片工作流程）→ Voyager（After Effects、Premiere、Ableton）→ Autograph MCP（動態圖形，免費版）。

動態圖形工具現在有了 agent 存取。弧線完成了。

---

**推文 5**
這引發的開放治理問題：

Figma Motion（10/6）加入了命名的可發布動畫樣式——設計工具中第一次有動態 token 存在。Autograph 現在讓 agent 在工具內原生應用動態。

但誰擁有動態樣式庫？顏色 → 品牌團隊。字體 → 設計系統。動態效果 → 仍然沒有人。

---

**推文 6**
對資深設計師來說，什麼改變了：

你不再是「動態 brief」和「動態執行」之間的瓶頸。

Agent 可以在工具內執行。這意味著瓶頸完全移到 brief 品質上。

如果你像 prompt 工程師而不是動態導演那樣寫作，輸出結果會顯示出來。

---

**推文 7**
誠實的注意事項：

免費的動態圖形應用程式，不是生產規模的 After Effects 或 Cinema 4D。Maxon 脈絡：這與 Cinema 4D、ZBrush、Redshift 一起發布——你不需要整個套件來試用。

還有這個：agent 在 Autograph 內建構 composition ≠ agent 理解動態意圖。那個落差——動畫應該有什麼感覺——仍然是品味問題，不是模型問題。

---

**推文 8**
這個框架：

Motion DesignOps 現在是不可避免的。不是因為工具要求它——而是因為 agent 即使沒有治理也會執行動態效果。

「沒有時間約束 ≠ 好的動態效果。」與「沒有 slop ≠ 品味」是同樣的原則。

動態 brief 品質現在是關鍵約束。不是工具存取。

Autograph 2027.0——免費，macOS + Windows。
