# Threads 貼文 — Autograph 2027 + MCP（繁體中文）

---

**長文版：**

動態效果是大多數組織中最後一個未被編碼的設計維度。

顏色有命名的 token。字體有命名的比例。間距有命名的網格單位。元件有附帶互動狀態的文件化變體。動態效果有的是…Notion 文件。Slack 討論串。某個人腦子裡的緩動曲線，在他們離職時就消失了。

Figma Motion 在十月加入了命名的可發布動畫樣式。設計工具中第一次有動態 token 存在——顏色和字體十年前就有的東西。那是一個治理步驟。

Autograph 2027.0 昨天發布了，這是不同類型的步驟。

Autograph 是 Maxon 的免費動態圖形工具——標誌、活動圖形、促銷素材、循環動畫。在 2027.0（10 月 14 日發布）中，他們加入了 MCP 支援。Claude 和 ChatGPT 現在可以直接在應用程式內建構 composition，使用 Autograph 的原生 Bounce 和 Elastic 動畫控制，建構響應式版面。Agent 在應用程式內部工作，不是在 prompt 到 export 的 pipeline 中。

這關閉了我一直在追蹤的 skills 基礎設施弧線的另一個部分：程式碼編輯器 → Figma agent skills → web CMS → Comfy Agent（AI 圖片/影片工作流程）→ Voyager（After Effects、Premiere、Ableton 等專業創意桌面應用程式）→ 現在是 Autograph（動態圖形）。每一個創意工具層都有了 agent 存取。弧線完成了。

這對動態設計師和管理動態效果的資深 UX 人員意味著什麼：

執行瓶頸消失了。Agent 可以在工具內建構動畫。這意味著唯一剩下的瓶頸是 brief 品質——而那個落差一直在增大。Jitter AI（10 月 3 日）已經確認 AI 動態模型的能力現在超過了大多數用戶的 brief 品質。Autograph MCP 做的是把同樣的動態延伸到動態圖形工具。

你現在必須像動態導演而不是 prompt 工程師那樣寫作。

這讓治理問題變得緊迫：誰擁有動態樣式庫？在大多數組織中，顏色的所有權很清楚（品牌團隊）。字體很清楚（設計系統）。動態效果存在於品牌（個性、時間感）和工程（性能、無障礙）之間的空隙。Figma Motion 透過創建基礎設施讓這個空隙變得不可避免。Autograph MCP 透過給予 agent 執行存取讓它變得重要。

誠實的注意事項：這是一個免費的動態圖形應用程式——不是生產規模的 After Effects，不是 Cinema 4D。MCP 整合意味著 agent 可以建構動態圖形 composition，不代表它理解動畫應該有什麼感覺。品味問題——情感基調、節奏感、緩動是否感覺像品牌——仍然是你的。
