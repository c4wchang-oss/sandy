**Title:** Motion design gets AI agent access. The governance gap just became urgent.

**Body:**

Motion is the last uncodified dimension in most design systems.

Color has tokens. Typography has named scales. Spacing has units. Motion has Notion docs and vibes.

Autograph 2027.0 shipped October 14. Maxon's free motion-graphics tool now has MCP support — Claude and ChatGPT can build compositions directly inside it.

**What the MCP integration actually does:**

1️⃣ **Agents construct compositions inside the app** — Not a prompt-to-export workflow. The agent works inside Autograph using native Bounce and Elastic animation controls, builds responsive layouts, creates motion graphics directly.

2️⃣ **Claude + ChatGPT compatible** — Named as the two supported assistants. Standard MCP protocol means other compatible agents can connect too.

3️⃣ **Free tool, no suite required** — Autograph ships alongside Cinema 4D, ZBrush, Redshift. You don't need the whole Maxon suite. It runs on macOS + Windows.

4️⃣ **Completes the skills infrastructure arc** — Code editors → Figma agent skills → web CMSs → Comfy Agent (image/video) → Voyager (After Effects, Premiere, Ableton) → Autograph MCP. Every creative tool layer now has agent access.

**Why this matters more than "motion tool gets AI":**

The execution bottleneck just disappeared. Which means brief quality is now the only binding constraint.

Jitter AI (Oct 3) already confirmed that AI motion model capability exceeds most users' brief quality. Autograph MCP extends this to motion graphics. Writing a good motion brief now requires motion director thinking, not prompt engineer thinking.

**The governance question this makes urgent:**

In most organizations:
- Color → owned by brand team
- Typography → owned by design systems
- Motion → owned by nobody

Figma Motion (Oct 6) made this gap visible by creating publishable motion style tokens. Autograph MCP makes it consequential by giving agents execution access without governance.

Agents will execute motion without a style library. That's now a DesignOps problem, not a future-state consideration.

**Honest caveats:**

- Free motion-graphics tool, not After Effects or Cinema 4D at production scale
- Agent building compositions ≠ agent understanding motion intent
- Emotional register, pacing, whether easing feels like your brand — still your judgment
- Check permissions before testing in live production contexts

**What to do now if you're in a design leadership role:**

Don't wait for agents to start making motion decisions in your tools before you've defined what good motion means in your system.

The motion brief is now a design system governance document, not just a style reference.
