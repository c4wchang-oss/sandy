**Title:** This design tool has no export step. The canvas IS the code.

**Body:**

Every design tool I've used makes the same assumption: design is a picture of an interface that someone else rebuilds in code.

Plastic rejects this at the foundation.

**What Plastic actually is:**

The canvas is real HTML and CSS. You draw, lay out, style on a canvas — and the file you save is the interface itself. No export. No engineer rebuild. No translation step.

**How AI agents work inside it:**

1️⃣ **MCP-native connection** — Claude Code, Codex, Cursor, and Grok all connect directly. They read the actual design structure (not a screenshot), make changes live on the canvas while you watch.

2️⃣ **Every turn can be undone** — Agent edits are reversible. You can take back anything, in one step.

3️⃣ **Constrained by design** — Agents can read code to copy a look, but cannot edit files or run system commands. They work through Plastic's own tools only. This is constraint architecture that protects production files.

4️⃣ **Comments → agent resolves** — Leave a note on any frame or layer. Send threads to an agent. It makes each change and resolves the comment when done.

5️⃣ **Figma import** — Drop a .fig file into Plastic. Pages, frames, auto layout, text, images, variables → editable HTML/CSS. Keep your existing work.

**Why this matters for senior designers:**

Handoff becomes sharing a frame link. Engineers and coding agents start from real semantic HTML/CSS with tokens — not a screenshot requiring interpretation.

The design-to-code gap doesn't get bridged. It doesn't exist in the model.

**Where to be honest:**

- Invite-only preview (browser + Apple silicon Mac app; Windows coming)
- Optimized for web interfaces — not mobile-native, complex design systems, or motion libraries at Figma scale
- No public pricing yet
- The "no rebuild" promise depends entirely on your component and token fidelity

**The bigger pattern this fits:**

This is the third tool this year betting the binary design file format is the real problem, not just a constraint to work around.

Elyx (Sep 29) — new human-readable, AI-friendly file format
Timeful (Oct 5) — Vue/Tailwind canvas where edits write to real code
Plastic — HTML/CSS canvas where the design IS the interface

The constraint stack era (AGENTS.md, CLAUDE.md, design.md) builds bridges over the binary format. These tools are betting the format itself needs to go.

That's a much more fundamental claim.
