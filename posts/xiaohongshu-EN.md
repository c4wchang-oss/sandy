## Post #2 — Tutorial Format
### Title
> 🛠️ My Full AI Design Workflow in 2026 | Senior UX Lead Shares Everything

### Body

People keep asking about my current workflow — here's the full breakdown 👇

---

**🔄 The Complete AI Design Loop (What's Actually Working in 2026):**

**Step 1 → Design in Figma with the Agent**
- Generate initial directions and variants
- Pull context from Notion PRDs via MCP
- Bulk-organize component library

**Step 2 → Claude Code + Figma MCP for Code Generation**
Drop a Figma frame URL into Claude Code →
Claude reads actual design specs (not a screenshot!) →
Generates React + Tailwind components →
Layout, spacing, colors: all accurate

**Step 3 → Cursor Design Mode for Iteration**
Click UI elements directly in the browser
Tell the AI what to change via voice or text
Agent updates in real-time — no coding required

**Step 4 → Code to Canvas Back into Figma**
Claude Code captures the rendered browser UI
Sends it back to Figma as editable frames
Designers and engineers review in the same canvas

---

**⚡ Why This Loop Is Different:**

Design → Code → Refine → Back to Design. Fully bidirectional.
Not the old "design → handoff → hope engineers understand."

---

**🔑 What Makes This Actually Work:**

Design System Quality Is Everything

✅ Tokens named clearly (colors, spacing, type — all as variables)
✅ Component states complete (hover, active, disabled, error)
✅ Naming conventions consistent (so AI can read them correctly)
✅ Docs written clearly (so agents have proper context)

AI won't fix a bad design system. It just makes a bad design system fail faster.

---

**📊 How My Time Allocation Changed:**

| Work Type | Before | Now |
|---|---|---|
| Design admin (renaming, docs) | 40% | 10% |
| Code handoff overhead | 20% | 5% |
| Actual design thinking | 40% | 85% |

Real numbers. AI freed me from design admin.

## Post #3 — Opinion Format (Short)
### Title
> 💡 "Vibe Coding" is dead — a senior designer's honest take

### Body

The "Vibe Coding" era is officially ending 👇

**Old era (2024):**
Describe it → AI generates it → ship it → fix the mess 💀

**New era (2026):**
Lock constraints → define rules → set quality gates → THEN let AI execute ✅

---

**The tools are the same:**
Figma, Cursor, Claude, v0, GPT-5.6 in Figma Make

**The mindset is completely different.**

---

The best designers I know in 2026 define these BEFORE AI touches anything:

📐 Token system (spacing, colors, type — locked)
♿ Accessibility rules (non-negotiable)
🔴 Edge cases (how things should fail gracefully)
🎨 Brand behavior principles (not just a style guide)

**That's the brief AI actually understands.**

---

Your biggest superpower isn't learning to use AI tools.

**It's building a design system that AI can work within.**
