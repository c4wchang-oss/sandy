## Topic 1: Meta Astryx — The Agent-Ready Design System

**Source:** Meta open-sources Astryx (July 21, 2026) — MIT license, 8 years internal, 13,000+ apps

**Core Insight:** The design system now has to speak two languages: human and machine. Astryx separates behavior (system-owned) from brand (token-owned) and exposes docs over MCP — so agents and humans build from the same reference.

**Conceptual Frame:** Agent-fluency is the new quality bar for design systems.

## Topic 2: UserTesting MCP — Research as Context Window, Not Gate

**Source:** UserTesting July 2026 quarterly release — MCP Server, multi-task Figma plugin, advanced targeting

**Core Insight:** AI without user context is just pattern matching. UserTesting MCP makes research the starting condition (loaded before the first prompt) — not the validation step (done after the prototype).

**Conceptual Frame:** Research stops being the gate and becomes the context window.
