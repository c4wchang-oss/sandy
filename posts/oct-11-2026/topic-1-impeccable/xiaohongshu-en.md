**Title: Senior UX take | AI coding agents finally have a design quality floor**

---

Paul Bakaus (jQuery UI creator) shipped Impeccable: a design skill for AI coding agents.

`npx impeccable install` — that's the whole setup.

Works with Claude Code, Cursor, GitHub Copilot, Gemini, Codex.
Apache-2.0. Free.

---

**What your agent gets:**

① PRODUCT.md — persistent product truth: audience, purpose, constraints, voice (not a style guide — different)
② 24 shared commands — audit, polish, critique, bolder, quieter, animate, shape, distill...
③ 61 deterministic rules — Rust binary, local, no LLM, no API key
④ Live browser iteration — iterate on any element directly in the browser

---

**What the 61 rules catch:**

AI slop tells:
- Side-tab accent borders
- Purple / violet gradients
- Gradient text on headings
- Bounce / elastic easing
- Dark mode + glowing accents
- Hero eyebrow patterns
- Nested cards, radial glows

General quality:
- Low contrast
- Skipped heading levels
- Text overflow / clipped menus
- Small touch targets
- Cramped padding, long line lengths

---

**The constraint architecture loop this closes:**

Pre-generation:
→ Thanor: 30 values before the first prompt
→ Graphical: GUI.md for coding agents
→ Figma Library Guidelines: docs = constraint

Post-generation:
→ Impeccable: deterministic audit after agent ships code

Floor is now two-phase architecture. Not a prompt. Not a reminder.

---

**The honest limit (Paul's own words):**

"Absence of slop ≠ taste."

Impeccable removes AI tells + catches quality failures.
It doesn't fix wrong IA. It doesn't improve bad product decisions.

Two jobs. Impeccable does one.

---

**Also:** Now bundled with GitHub Copilot app by default.
Every developer who opens Copilot gets this quality layer.
