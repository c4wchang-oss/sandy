## POST TITLE
3 creative platforms, 15 days, same bet: the workflow canvas is the new creative production interface

---

## POST BODY

Adobe MAX happened Nov 10. Here's what actually matters for senior designers — and an honest read of what's usable today vs what's still on a waitlist.

**The convergence pattern first:**

Runway App Studio launched Oct 27. Figma Weave nodes launched Oct 30. Adobe Firefly Graph launched Nov 10. Three of the biggest creative platforms shipped a node-based workflow canvas in 15 days. All three are betting on the same thing: the domain expert encodes their process into a runnable system, then stops being the bottleneck.

**What Firefly Graph actually is:**

A visual node canvas for building repeatable creative production workflows. Connect AI models (Firefly, third-party), Creative Cloud tools, and asset inputs. Run them in sequence. Save and share with your team. The workflow IS the documentation — except it runs.

**5 things worth knowing about Firefly Graph:**

1. **Model comparison** — run the same inputs through multiple AI models side by side; best built-in AI quality governance I've seen in a tool
2. **Subgraphs** — group nodes, expose only the inputs/outputs you want; this is constraint architecture at the workflow layer, the team can't accidentally break what's inside
3. **AI Assistant** — build workflows using natural language; useful, but your process quality = your output quality
4. **Share workflows** — give colleagues view or edit access; institutional knowledge that runs, not just documents
5. **Currently public beta** — not GA, pricing not announced, feature changes expected

**What Firefly Builder is (private beta, waitlist):**

Natural language → on-brand interactive prototype. Upload brand guidelines → generates design system → build website/app/presentation → export HTML code bundles. Direct canvas editing. Shareable prototype links.

Honest read: the most interesting capability = the least accessible right now. This is a direction signal, not a tool you're using today.

**The bigger frame:**

What Builder confirms is the expected standard for AI-assisted prototyping: brand constraint infrastructure first, generation second. Not "generate, then try to make it on-brand." "Design system is the first input."

Firefly Graph is usable right now. Worth using just for model comparison + subgraphs.
