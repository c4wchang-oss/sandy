## Platform Strategy

### X (Twitter)
- **Best post type:** Thread format (8 tweets)
- **Hook tweet:** Strong opinion or surprising insight
- **Tone:** Confident, slightly provocative, data-informed
- **Pairing:** Use 16:9 image on first tweet of thread

### Threads
- **Best post type:** Long-form personal reflection OR punchy 3-paragraph take
- **Tone:** Personal, thoughtful, inviting conversation
- **Pairing:** Use 1:1 square image for visual impact in feed

### 小紅書 (Xiaohongshu)
- **Best post type:** Tutorial/tips ("干货") OR honest review
- **Tone:** Relatable, practical, slightly personal storytelling
- **Pairing:** Use 3:4 vertical cover image as first image
- **Tags:** Always include relevant hashtags (already included in posts)
- **Key formula:** Hook → Pain point → Solution/Insight → Takeaway → CTA
