**Title:**
Framer's new agent modes aren't just speed controls

---

**Body:**

Framer updated the Agent model picker with reasoning controls and Fast Mode.

Most people are calling this a speed setting. I think that misses the point.

**What it actually is: a task classification interface**

Before picking a mode, you have to ask yourself: how much planning does this task need?

📌 **Light Reasoning**
For: quick edits, copy tweaks, single-component changes
Best for: daily iteration, refinements — don't overthink it

📌 **Higher Reasoning**
For: multi-step flows, structural decisions that ripple across screens
Best for: when a wrong move cascades into three other places

📌 **Fast Mode** (currently Opus 5+)
For: client review cycles, launch-week polish
Note: costs more tokens per task — not a daily driver

**Why this matters to senior designers**

We've always adjusted our own thinking depth based on task weight. We just never named it.

Framer turned that mental model into a UI element.

If you're guessing which mode to pick every time: ask yourself how many places break if this goes wrong. More than two? Use higher reasoning.

**Honest note**

Framer is explicit that Fast Mode costs more. Don't ignore it. Treat it as a deadline lever, not a default.

If you can't decide which mode to pick, the problem isn't the tool — your task isn't defined enough yet.
