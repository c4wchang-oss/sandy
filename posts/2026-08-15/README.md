## Topics Covered

### Topic 1: Framer Agents: Reasoning + Fast Mode (Aug 12, 2026)
Framer added a reasoning depth selector and Fast Mode to the Agent model picker. Light reasoning for daily edits, higher reasoning for multi-step planning work, Fast Mode (Opus 5+) for deadline speed at a higher token cost.

**Angle:** Most people see this as a speed control. The real story is a task classification interface — Framer surfaced something designers have always done informally (adjusting thinking depth based on task weight) and made it an explicit UI step. If you can't pick a mode without guessing, the task isn't defined well enough.

**Sources:**
- https://www.framer.com/updates/agent-reasoning-and-fast-mode
- https://yoframer.com/framer-updates/framer-agents-reasoning-fast-mode-update/

### Topic 2: Figma AI Agent as Design System Maintainer (Aug 2026)
Real-world testing of the Figma AI agent (via Figma's AI DesignOps Agent and community testing) confirms a clear pattern: strong at structured maintenance tasks (audit, document, gap analysis, consistency checks), inconsistent at creating new components that faithfully match established patterns.

**Angle:** This isn't a model failure — it's a context problem. "Faithful to your system" requires accumulated judgment the agent can't learn from structure alone. The role shift for senior designers: stop doing the maintenance audit, start building a system legible enough for AI to maintain. Design system documentation and AI agent context parameters are now the same document.

**Sources:**
- https://www.figma.com/solutions/ai-design-ops-agent/
- https://www.designsystemscollective.com/figma-agent-review-real-world-testing-prompts-and-results-b32ea5804f49
- https://news.designrush.com/new-figma-ai-agent-challenges-design-system-consistency
- https://help.figma.com/hc/en-us/articles/41159677390999
