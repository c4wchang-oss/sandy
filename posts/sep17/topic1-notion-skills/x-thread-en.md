# X Thread — Notion 3.7 Agent Skills (EN)
## Sep 17, 2026 | Image: topic1-x-threads-en.png (16:9)

---

**Tweet 1 (hook — attach image)**
Every team has one person who writes the best AI prompts.

Notion 3.7 just made that person's knowledge a team asset, not a personal advantage.

---

**Tweet 2**
Skills are reusable instructions maintained as Notion pages.

One person builds a skill: "turn this draft into an exec brief in our format."
The whole team runs it from Notion Agent.

No more "can you share that prompt again?"

---

**Tweet 3**
The Skills Library is a single hub.

Browse team skills, Notion-published skills, your own.
Admin sets up to 50 workspace defaults.
Everyone stays on the same version.

Prompting knowledge went from chat history → shared infrastructure.

---

**Tweet 4**
SKILL.md portability is the real architectural move here.

Create skills in Notion → download to Claude Code, Cursor, Gemini, or Grok.
Same instructions. Multi-agent. One source of truth.

The skill you wrote once runs in every agent environment your team uses.

---

**Tweet 5**
Notion Agent auto-invokes skills when relevant.

It reads your description to decide when to apply.

Description quality = auto-invoke accuracy.
Write sloppy descriptions → wrong skill fires.

The brief is still the interface. Just written once.

---

**Tweet 6**
This pattern is now everywhere:

SKILL.md (Figma, Aug 13)
CLAUDE.md
design.md (Vercel, Sep 2)
Field Guide (Cursor Projects, Sep 15)
Skills (Notion 3.7, Sep 15)

The AI instruction file IS the team documentation. Same artifact, two audiences.

---

**Tweet 7**
Honest caveat:

Downloaded SKILL.md files don't auto-sync.
When a skill changes in Notion, you see a badge — but re-download manually.

That refresh loop will silently break in distributed teams. Someone is always running the stale version.

---

**Tweet 8**
New form of org debt nobody's naming yet:

Skills that encode outdated workflows, still auto-firing months later.

Same problem as documentation debt.
Harder to notice because the agent never complains — it just executes the wrong version confidently.

Role shift: stop hoarding good prompts. Start maintaining the skills library.
