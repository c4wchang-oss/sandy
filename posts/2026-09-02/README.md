## Topic 1: Vercel design.md — Teaching Agents Product Design

**What:** Vercel published their full system for getting AI agents to build on-brand pages: a design.md prose guidance file, a bounded CSS stylesheet, and a deterministic evaluation loop that converts human review feedback into durable encoded rules.

**Sources:**
- https://vercel.com/blog/how-our-agents-build-on-brand-pages-with-design-md
- https://vercel.com/blog/teaching-agents-product-design-at-vercel

**Angle:** "You can only teach an agent what you've already written down." 57% reduction in known failures, but every tested page still blocked — because the system prevents what you've already seen fail, not what you haven't. The three-part system (prose + stylesheet + eval loop) is actually a solid design review pattern that most teams run informally but never encode into durable rules. Senior UX role: documenting the reasoning behind decisions, not just the decisions themselves.

**Honest caveat:** The 57% improvement only applies to failures already identified and encoded. New page types, novel aesthetic calls, and judgment that's never been made explicit remain outside the system's reach.

## Topic 2: Google Pics GA — Google Enters the Creative Design Market

**What:** Google Pics went GA in Google Workspace on September 1, 2026. Powered by the Nano Banana image model. Integrated into Docs and Slides, and available at pics.new. Object-level editing, text translation inside images, collaborative sessions. Included in Workspace Business/Enterprise Standard+, Google AI Pro/Ultra, and AI Pro for Education.

**Source:** https://techcrunch.com/2026/09/01/googles-answer-to-canva-is-an-ai-tool-where-you-prompt-instead-of-design

**Angle:** This is not Canva, and the distinction matters. Canva gave non-designers composition tools; Google Pics gives non-designers AI image generation output. Different creative loops, different levels of compositional agency. With 3 billion Workspace users, functional AI image production inside Docs and Slides is now a zero-friction default — which raises the question of brand governance for any design team operating inside a Workspace org. Pattern recognition: Canva (2013) raised the template floor, AI image tools raised the generation floor. The question is always what's above it.

**Honest caveat:** No template marketplace, no from-scratch layout control, no brand governance built in. Brand coherence, culturally specific imagery, systematic visual identity, and purposeful narrative design remain human judgment work.
