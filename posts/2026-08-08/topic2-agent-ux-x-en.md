---

**Tweet 3:**
What's the bottleneck?
Not AI capability. That's solved.

It's verification UX.
The interface for checking what the agent did.

---

**Tweet 4:**
A UIST 2026 paper tested this directly.
30 users. Computer-use agents. Multi-step tasks.

Group A: standard scrolling chat transcript.
Group B: ambient status — color, thumbnail, visual replay, spoken summaries.

Result: 48% fewer agent errors.
Zero additional attention cost.

---

**Tweet 5:**
Read that again: zero additional attention cost.

Task switches: statistically identical (p=.080).
Time per check: 8.6s (ambient) vs. 12.8s (chat).

Better oversight. Same attention budget.
Just a different interface.

---

**Tweet 6:**
The chat transcript is the wrong monitoring interface for agents.
It wasn't designed for monitoring. It was designed for conversation.

Status needs to go ambient.
Color, thumbnail, periphery — not scrolling prose in a log.

---

**Tweet 7:**
Jakob Nielsen, Aug 2026:
"The companies that win the agent era may be those that make checking work 10x faster, not those that make doing work 10x faster."

This is the design problem of the decade.

---

**Tweet 8:**
AI also hides UX debt.
When an agent operates a confusing UI, the user pain disappears from view.
But the debt keeps accruing — paid out as agent errors nobody can diagnose.

We need to design for agent legibility too.
Not just human legibility.
