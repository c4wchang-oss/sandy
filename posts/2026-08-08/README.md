### Topic 1: Figma Code Layers — The Reversible Handoff
**Angle:** The handoff wasn't broken — the source of truth was. Code Layers makes the canvas the single place where design and code decisions happen. But the quality ceiling is still your design system.

**Sources:**
- Figma Config 2026 blog: figma.com/blog/code-on-the-figma-canvas/

### Topic 2: Glanceable Agent UX / Deep AI Integration Pays
**Angle:** We design what agents do. We forgot to design how you check them. Verification UX is the enterprise adoption bottleneck, not AI capability.

**Sources:**
- Jakob Nielsen UX Roundup, Aug 7, 2026 (jakobnielsenphd.substack.com)
- UIST 2026 paper: "Sidekick" ambient agent monitoring study
- S&P 500 deep AI integration net margin analysis (Aug 2026)

**Key stats/facts:**
- UIST 2026: 48% fewer agent errors with ambient monitoring; zero additional attention cost
- Check time: 8.6s (ambient) vs. 12.8s (chat transcript)
- S&P 500: deep AI integration firms → 4x+ net margins vs. 2022 baseline
- 45% of firms still in pilot mode with no financial consequences
- Nielsen quote: "companies that win the agent era may be those that make checking work 10x faster"
