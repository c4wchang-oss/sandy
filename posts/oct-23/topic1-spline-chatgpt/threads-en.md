Something about Spline for ChatGPT that I haven't seen anyone say clearly yet.

Everyone's talking about the 3D generation angle — ChatGPT can make interactive 3D scenes now. Sure. But the more interesting part is what happens when you step in after the AI does its work.

When ChatGPT creates or opens a Spline file, the real Spline editor opens in a panel next to the conversation. Not a preview. Not a screenshot. The actual editor, signed in as you. You can move objects, change materials, adjust lighting — any time, mid-conversation. And the key part: ChatGPT reads the file again before making its next change. It builds on your edits instead of undoing them.

That's a properly designed two-mode model: describe → AI executes, OR step in and edit manually. The handback is clean because the agent checks your current state first.

There's also agent self-review with screenshots before handing back. So the trust loop is: AI builds → screenshots own output → you can edit manually → AI reads your edits → continues. A four-step confirmation loop designed into v1. That's rare.

And it's not only 3D. Hana — Spline's 2D canvas — handles landing pages, app screens, and UI design too. So the more accurate framing is: design tool + conversation layer fused into one shared surface. Not "ChatGPT does 3D now."

Files save to your Spline account like any other file. No lock-in. Plugin lives in OpenAI's directory, so their algorithm controls discoverability. But the file format stays yours.

This is the fifth instance of canvas-as-context convergence I've tracked this year: Doop (Sep 4) → MagicPath (Oct 1) → Shopify Canvas (Oct 1) → MagicOS (Oct 13) → Spline for ChatGPT (Oct 21). Five in 47 days. The thesis is: AI conversation and design surface should be the same surface.

Honest limitation: getting quality 3D still requires precise scene description. Vague prompts produce generic geometry. The 2D and UI side (Hana) is immediately useful. 3D requires domain-level experience to brief well.

The question that stays with me: when your design tool lives inside a conversation, at what point does the conversation become the design file? Spline's answer is the correct one — the file is the file. The conversation shapes it.

Lock-in lives in file formats. This keeps yours intact.
