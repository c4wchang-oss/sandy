**Tweet 1 (Hook)**
Everyone's talking about the 3D generation. That's not the interesting part of Spline for ChatGPT.

---

**Tweet 2**
The interesting part: when ChatGPT opens a Spline file, the real Spline editor opens in a panel next to the conversation.

Not a screenshot. Not a rendered export. The actual editor, signed in as you.

You can step in at any point — move objects, change materials, adjust lighting. ChatGPT reads the file again before its next change, and builds on your edits instead of undoing them.

---

**Tweet 3**
That detail is more significant than the 3D headline.

"ChatGPT reads the file again before its next change."

This is agent self-awareness at the file level, not the screenshot level. The AI can't bulldoze your manual edits because it checks state first.

Every AI creative tool should be doing this. Very few are.

---

**Tweet 4**
The agent also screenshots its own work before handing back. So the full trust loop is:

→ AI builds
→ AI screenshots its output
→ You can step in and edit manually
→ AI reads your edits before continuing

Four-step confirmation loop designed in from v1. This is what agent interaction design looks like when it's taken seriously.

**Tweet 5**
And it's not only 3D.

Hana — Spline's 2D canvas — works too. Landing pages. App screens. UI components.

So the real framing isn't "3D in ChatGPT." It's: design tool + conversation layer fused into one shared surface. That's a bigger and different claim.

**Tweet 7**
Honest limits:

Getting useful 3D from a text conversation still requires precise scene description. Vague prompts produce generic geometry.

The plugin lives in OpenAI's directory — discoverability is OpenAI's to manage, not Spline's.

2D and UI design (Hana) is genuinely useful immediately. 3D requires domain-level experience to brief well.

The question this surfaces: when your design tool lives inside a conversation, at what point does the conversation become the design file?

Spline's answer is the right one — the file is the file. The conversation is how you shape it.

Lock-in lives in the file format. This keeps it in yours.
