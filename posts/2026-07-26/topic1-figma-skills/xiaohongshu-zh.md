# 小紅書貼文 — Figma Skills：終於有人讀你的設計文件了（但那個人是 AI）
**Platform:** 小紅書 | **Date:** 2026-07-26 | **Language:** 繁體中文

---

**標題：** Figma Skills 讓設計文件第一次真的有用了 📄🤖

---

📌 **先說結論**
Figma Custom Skills = 寫給 agent 看的設計文件，不是給人看的

不只是新功能——是一種完全不同的想法：設計知識是為誰存在的？

🔍 **什麼是 Figma Custom Skill？**
Skill 就是你自己寫的 Markdown 文件
Agent 在每個任務開始前都會讀——每次，沒有例外

你可以定義：
✅ 先搜尋哪個 library
✅ Variable 命名規則
✅ 優先使用哪些 component
✅ Auto layout 的結構邏輯
✅ 什麼時候要做 accessibility 檢查
✅ 品牌語調與審查標準

💡 **跟一般 prompt 有什麼不同？**
Prompt = 每次重寫，容易漂移，取決於當下在場的人
Skill = 寫一次，永久套用，擴展到整個團隊

🎯 **對資深設計師的真正意義**

設計知識過去住在：
- 沒人打開的 Notion 頁面
- 沒人往下滑的 Figma comment
- 你自己的腦袋裡（然後你離職就消失了）

Skills 把那些知識變成機構記憶——可執行、一致、永久存在

⚠️ **誠實說的部分**
寫好 Skill 比看起來難
含糊的 Skill → 含糊的輸出
通用的指令 → 通用的結果

如果你沒辦法把慣例寫得夠清楚讓機器跟隨
那就是你的設計思維有多系統化的重要資訊

🏆 **怎麼開始（實際步驟）**
① 找你最常重複跟 agent 解釋的事
② 用清楚、有順序的步驟寫出來——像是在跟一個超級字面意思的讀者解釋
③ 在 Figma 裡加入成 Custom Skill
④ 跑一個任務，看 agent 在哪裡偏離
⑤ 修改 Skill 直到它穩定

📌 **這對設計運營意味著什麼**

Skills 是設計治理的新格式：
- 可在團隊間分享
- 可組合（Skill 可以呼叫另一個 Skill）
- MCP 相容（未來可在 Figma 以外的任何 MCP 客戶端使用）

真正的標題：你現在寫的是課程大綱，不只是 spec。
