## Key Points
- Canva Code 2.0 opens to all 265M users including free tier — 75% faster code generation, 30% faster prompt-to-publish
- HTML import turns Canva into the "finishing layer" for any AI-generated code (ChatGPT, Claude, Lovable, Bolt)
- Direct click-to-edit on generated elements — drag images, change fonts, update colors without re-prompting
- Interactive elements can be embedded inside presentations and whiteboards
- Explicit limitations: front-end only, not for complex backends or high-traffic production apps
- Broader pattern: AI generation is commoditized; design-quality editing surface is the differentiator
