# Threads 貼文 — Canva Code 2.0（繁體中文）
**格式：** 長篇個人觀察，不加 hashtag

---

這週有件事靜悄悄地發生了，但它可能會改變 AI 工具和設計工具之後怎麼共存。就在 Canva Code 2.0 的發布裡。

我一直在想的是：

Canva 根本不是在和 Lovable 或 Bolt 競爭。他們定位的是這些工具*之後*的那個步驟。HTML 匯入功能讓你可以把任何 AI 工具生成的程式碼 — ChatGPT、Claude、Lovable、Bolt — 拉進 Canva，直接變成可以編輯的設計圖層。他們把自己定位成市場上所有 vibe coding 流程的收尾層了。

從產品設計的角度來看，這完全說得通。所有其他 vibe coding 工具都在優化「盡快做出能動的東西」。Canva 賭的是：能動還不夠，視覺品質和品牌一致性才是大多數用戶卡住的地方。他們先把編輯介面做好，然後把 AI 生成當作入口。這是一個和競爭對手根本不同的產品架構。

讓我一直回想的那個功能：你可以直接點進任何生成的元素改文字、從 Canva 的素材庫拖進圖片、用熟悉的工具列改顏色 — 完全不需要再回去跟 AI 說話。對比這個空間裡的所有其他工具，「讓這個看起來更像我的品牌」意味著重新 prompt。Canva 先解決了編輯問題。生成從來都只是第二步。

對 UX 設計師來說，值得觀察的轉變是：AI 生成正在變成商品。每個工具現在都能從文字 prompt 做出能動的 prototype。圍繞著這個生成的*編輯介面品質*，才是差異化開始發生的地方。Canva 比大部分人更早看到這件事。

值得誠實說出的限制：Canva Code 是前端工具，設計給中小規模使用。他們自己的團隊直接說了 — 不適合複雜後端或高流量生產應用。這個限制不是弱點，是對他們一直服務的那群人的刻意聚焦：老師、行銷人員、小企業主，需要看起來專業、在手機上能用的東西，而且不想花錢雇工程師。

這週真正的標題：Canva 讓設計品質成為 AI 建構流程裡不可跳過的步驟。給 2.65 億人，免費。

這個動作比看起來要大。
