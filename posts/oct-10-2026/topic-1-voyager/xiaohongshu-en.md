**Title: Senior UX take | Voyager = Agent harness for your existing creative apps**

---

Last week the Moda team (YC F26) shipped Voyager: a desktop agent harness for creative work.

Not a new app. Your existing creative apps — now agent-callable.

---

**Apps it drives:**

- Blender, DaVinci Resolve, After Effects, Premiere Pro
- Ableton Live, Final Cut Pro, Unity
- Photoshop, Illustrator
- Cinema 4D, Houdini, Descript (via skills)

All through their native scripting APIs. Not screen scraping.

---

**Why the scripting API choice matters:**

① Photoshop → Photoshop scripting
② DaVinci Resolve → scripting API
③ After Effects → AE scripts
④ Window control → fallback only, within macOS permissions you grant

Your project files stay as ordinary editable files.
No weird formats. No lock-in.

---

**What's included free:**

- Voyager Design engine (motion graphics)
- Voyager Video engine (editing)
- Voyager DAW engine (music)
- ~40 built-in skills
- MCP server support
- Reuses skills from Claude Code / Codex / Cursor

---

**Honest caveats:**

- macOS 15 + Apple Silicon required (Win/Linux alpha)
- Need your own Claude or Codex subscription
- Image / video / audio generation → provider cost
- Paid plans from $19/mo

---

**The frame I'm using:**

Skills convergence arc — now complete:
Code editors → Design tools → Web CMSs → AI creative tools → Professional creative desktop apps

Every creative environment is agent-callable.

But: a harness doesn't improve your brief. Motion direction still requires actual skill.
