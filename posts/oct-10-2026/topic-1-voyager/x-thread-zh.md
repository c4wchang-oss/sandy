---

**Tweet 2：**
Voyager（YC F26，Moda 團隊）於 10 月 8 日推出：一個桌面 agent harness，透過原生 scripting API 驅動 Blender、DaVinci Resolve、After Effects、Ableton、Photoshop、Illustrator。

不是新 app，是讓你現有的工具變得 agent 可呼叫。

---

**Tweet 3：**
「透過 scripting」這件事不是小細節。

Voyager 用 Photoshop scripting 控制 PS，用 DaVinci scripting API 控制 Resolve，用 AE scripts 控制 After Effects。視窗控制只作為 app 沒有透過 API 暴露的最後手段。

你的專案檔案維持普通可編輯格式。沒有 lock-in。

---

**Tweet 4：**
我追蹤 skills 基礎架構在各工具間的收斂已有好幾個月：

→ 程式編輯器（Cursor、Claude Code）
→ 設計工具（Figma、Framer）
→ 網頁 CMS（Webflow、Elementor）
→ AI 創意工具（Comfy Agent、HyperFrames）
→ 現在：專業創意桌面軟體（Voyager）

每個創意層都變成 agent 可呼叫。這個收斂弧完成了。

---

**Tweet 5：**
Voyager 可以重複使用已為 Claude Code、Codex、Cursor 安裝的 skills。

相同的 skills 格式，不同的創意領域。

但整個業界還沒有回答這個問題：當 skills 跨越程式編輯器、設計工具、現在又到了創意 app——誰來治理哪些 skills 才是權威的？
