**標題：Senior UX 觀點 | Voyager = 你現有創意 app 的 agent harness**

---

上週 Moda 團隊（YC F26）推出了 Voyager：一個用於創意工作的桌面 agent harness。

不是新 app，是讓你現有的創意工具變得 agent 可呼叫。

---

**它可以驅動的工具：**

- Blender、DaVinci Resolve、After Effects、Premiere Pro
- Ableton Live、Final Cut Pro、Unity
- Photoshop、Illustrator
- Cinema 4D、Houdini、Descript（透過 skills）

全都透過原生 scripting API，而非螢幕截圖模擬。

---

**為什麼 scripting API 的選擇很重要：**

① Photoshop → Photoshop scripting
② DaVinci Resolve → scripting API
③ After Effects → AE scripts
④ 視窗控制 → 僅作後備，在你授予的 macOS 權限內

你的專案檔案維持普通可編輯格式。
沒有奇怪的格式，沒有 lock-in。

---

**免費包含的內容：**

- Voyager Design 引擎（動態圖形）
- Voyager Video 引擎（剪輯）
- Voyager DAW 引擎（音樂）
- ~40 個內建 skills
- MCP server 支援
- 可重複使用 Claude Code / Codex / Cursor 的 skills

---

**需要誠實說明的限制：**

- 需要 macOS 15 + Apple Silicon（Win/Linux 是 alpha）
- 需要自備 Claude 或 Codex 訂閱
- 圖片／影片／音訊生成 → 按 provider 成本計費
- 付費方案從 $19/月起

---

**我使用的框架：**

Skills 收斂弧——現在完成了：
程式編輯器 → 設計工具 → 網頁 CMS → AI 創意工具 → 專業創意桌面軟體

每個創意環境現在都 agent 可呼叫了。

但：harness 改善不了你的 brief。動態方向感依然需要真正的技能。
