**Title: Senior UX take | OpenDesign = Open-source Claude Design for any agent (17 adapters)**

---

Claude Design went native in Claude last week. But what if your team runs Codex? Or Cursor?

OpenDesign launched its collaborative workspace this week. Here's what it is.

---

**Supported agents (17 BYOK adapters):**

- Claude Code, Codex, Cursor
- Gemini CLI, Grok, DeepSeek
- Kiro, Kilo, Qwen, OpenCode
- GitHub Copilot CLI, Mistral + more

Switching = config change, not a product change.

---

**The workflow:**

① Choose from 150+ open-source design systems
   (or generate from website / GitHub repo / Figma)
② Describe what you want to build
③ Agent writes working HTML prototype
④ Preview live — edit directly if needed
⑤ Share with team → they comment on the design
⑥ Agent revises from those comments
⑦ Export HTML/PDF or hand off to engineering

---

**New this week: Team workspace**

- Shared projects across the team
- Shared design systems + skills
- Comments on live prototype previews
- Workspace billing
- Apache-2.0, local-first, you own all files

---

**Honest comparison:**

| | Claude Design | OpenDesign |
|---|---|---|
| Setup | Zero friction | Need agent set up |
| Provider | Anthropic only | Any agent (17) |
| Files | Hosted | Yours locally |
| License | Proprietary | Apache-2.0 |
| DESIGN.md | ✓ | ✓ |
| Team WS | ✓ | ✓ (new) |

---

**The actual argument for OpenDesign:**

If your team has invested in Cursor or Codex workflows, you probably don't want your design workflow locked to a third provider.

BYOK design = portable workflow = future flexibility when AI providers change.

Design system quality still determines the output quality ceiling either way.
