# 小紅書 Post — Comfy Agent：ComfyUI 手藝的第一個 Agent（繁體中文）
**主題：** Comfy Agent 在 Comfy Cloud 上線——從文字建立、執行、迭代 ComfyUI 圖像/影片工作流，在同一個 canvas 上同時工作（2026年10月1日）

---

**標題：**
Comfy Agent：第一個讓 ComfyUI 變得可及卻沒有讓它變簡單的 AI agent

---

**內文：**

ComfyUI 一直是認真的 AI 圖像和影片工作發生的地方。而截至 2026 年 10 月 1 日，它有了一個 agent。

以下是為什麼這個產品決策很重要——以及它做對了大多數「AI 易用性」工具做錯的東西。

**Comfy Agent 實際上在做什麼：**

① 從文字描述建立 ComfyUI 工作流——規劃生成技術、連接 node、推薦模型、找到資產
② 在和你一樣的 canvas 上同時運行——你和 agent 都不等對方；你編輯 node，它建立工作流，兩個人都在即時工作
③ 在工作流中即時修復驗證錯誤和除錯
④ 處理最多 5 個並行對話且保留完整歷史——同時跑多種生成方式而不失去脈絡
⑤ Skills 系統：在工作時建立公開或私人 skills，編碼你的生成知識，和你的團隊分享
⑥ Agent 視覺性地讀取 graph——看到你拖入什麼，注意到你移動 node 的時候

**重要的產品決策：**

大多數「讓複雜工具變容易使用」的 AI 工具做了兩件事之一：
- 把工具簡化成對話介面 → 失去底層力量
- 在別的地方生成輸出然後交給你 → 失去工作流連續性

Comfy Agent 兩者都沒做。完整的 node graph 還在那裡。Agent 在裡面和你並肩工作。

這是取代你工作流的工具和參與你工作流的工具之間的差別。

**Agent-native 創意引擎模式：**

Mirage Tesseract（9月23日）為 agent 重建了影片製作——直接存取 layer、keyframe、mask、timing。

Comfy Agent 為 agent 重建了 ComfyUI 的工作流層。

不是給工具加上 AI。是為 agent 設計的新介面層，在一個已經為實踐者建立的工具裡運作。

**Skills 收斂：**

CapCut（8月11日）→ Divi（9月5日）→ Notion（9月17日）→ Figma（9月20日）→ Framer（9月22日）→ Comfy Agent（10月1日）

六週內每個主要創意工具都發展了 skills 層。你的編碼工作流知識正在成為跨工具的專業資產。

**誠實的注意事項：**

- 目前僅限 Cloud——本地 ComfyUI 支援即將推出
- Beta：團隊正在積極除錯
- 天花板還是你的 node 詞彙和 brief 品質
- Skills 捕捉你做了什麼，不是你的意圖——發布前要審查

**資深 UX 的收穫：**

「複雜工具 / 易用工具」的張力是一個設計問題，不只是產品定位問題。

Comfy Agent 的答案：agent 和你一起在複雜性裡面工作，而不是替你移除複雜性。

這是專業工具的正確架構。保留力量。減少使用它的摩擦。
