# Threads Post — Comfy Agent：ComfyUI 手藝的第一個 Agent（繁體中文）
**主題：** Comfy Agent 在 Comfy Cloud 上線——從 prompt 建立和執行 ComfyUI 圖像/影片工作流，在同一個 canvas 上同時與你並肩工作（2026年10月1日）

---

## 長文反思

ComfyUI 一直是 AI 圖像和影片生成的認真實踐者工具。基於 node 的工作流。每個模型參數都暴露出來。每個流程步驟都可見且可重新配置。創作社群用它建立了非凡的東西——但學習曲線是誠實的門檻。你需要了解模型、extensions、node 詞彙。

Comfy Agent 這週上線了。值得研究的產品決策是這個：它沒有把 node 抽象掉。它在同一個 canvas 上與你並肩工作。

這聽起來很明顯。它不是。今年大多數 AI 裡的「讓強大工具變容易使用」故事選擇了兩條路之一：要麼把工具簡化成一個對話介面（失去力量），要麼在別的地方生成輸出然後交給你（失去連續性）。Comfy Agent 兩者都沒做。Node graph 還在那裡，完全暴露，完全可配置。Agent 建立和編輯你正在看的同一個 graph，同時你也在編輯它。你們兩個都不等對方。Agent 視覺性地看到 graph——如果你從資源庫拖入一個資產，它注意到了。如果你移動 node，它調整。

這是一個有意義的協作模型。它比我今年看到的任何 AI 對話介面都更接近一個實踐者和一個理解工具的技術合作者實際上一起工作的方式。

Skills 架構是我一直在追蹤的同樣收斂模式。CapCut（8月11日）→ Divi（9月5日）→ Notion（9月17日）→ Figma（9月20日）→ Framer（9月22日）——六週內每個主要工具都發展了 skills 基礎設施。Comfy Agent 現在把這個模式帶到了 AI 圖像/影片生成的 layer。在工作時建立公開或私人的 skills。你內化的 node 詞彙——你發現的關於哪些模型適合哪些生成任務的模式——成為編碼的、可重複使用的、可分享的。

Agent-native 創意引擎的模式在這裡再次被確認。Mirage Tesseract（9月23日）為 agent 重建了影片製作引擎：直接存取 layer、keyframe、mask、timing 等基礎元素。Comfy Agent 在工作流層做了同樣的事。不是「給 ComfyUI 加上 AI。」一個為 agent 設計的新介面層，來理解和操作一個已經為實踐者設計的工具。

誠實的注意事項：本地 ComfyUI 支援即將推出但現在還沒有——目前僅限 Cloud。這是 beta，團隊正在積極除錯。Skills 審查原則在這裡也適用：skills 捕捉你做了什麼，不是你的意圖。天花板還是你的 node 詞彙、你的 brief 品質，以及你關於哪種生成方式適合哪個創意問題的知識。

## 短評（單獨發布）

ComfyUI 剛獲得了一個 agent。

它沒有把 node graph 簡化掉。它在和你一樣的 canvas 上同時工作。

你編輯 node。它建立工作流。兩個人都不等對方。

5 個並行對話。你可以發布的 skills。雙方都有完整的 graph 可見性。

第一次「強大但複雜」的創意工具問題在沒有移除力量的情況下被解決了。
