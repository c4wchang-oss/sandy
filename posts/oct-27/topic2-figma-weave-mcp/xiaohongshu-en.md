**Title:**
Figma Weave via MCP: what your coding agent can now do with your media

---

**Body:**

Figma shipped a small update on Oct 26 that changes the creative production stack. All Weave video and image models are now accessible through the Figma MCP. Your Claude Code or Cursor session can now generate production media alongside design work — without opening the Weave UI.

---

**What You Can Do Now:**

① Ask your coding agent to generate images using Nano Banana, Kling, Seedance — from within Claude Code or Cursor
② Generate product videos, campaign visuals, or brand imagery without switching to Weave
③ Confirm cost before each run — the agent shows you the bill first, then asks for go-ahead
④ The output is a Weave asset directly usable in your design workflow

---

**How It Works (3 MCP Tools):**

① weave_find_model — find the model by name
② weave_run_model — run the model, confirm cost, it generates
③ weave_get_model_run_output — check progress, get the output

Your agent handles all three. You just confirm the cost gate before each run.

---

**The Design Stack Now:**

- Figma MCP: design layer (visual specs, components, code layers) → agent-readable ✓
- Weave via Figma MCP: production media (video, image models) → agent-callable ✓ NEW

One Claude Code session: read the design → generate the asset. No extra tab needed.

---

**What to Know About Credits:**

⚠️ Weave runs use WEAVE credits — not Figma AI credits
⚠️ Two separate billing meters — keep both visible
⚠️ Requires a Figma account (with MCP) + a separate paid Weave account

---

**What's Not There Yet:**

Creating or editing Weave workflows via agent is not supported. Your agent can run models — it can't compose workflows yet. Workflow authoring still needs the Weave UI.

---

**Senior Designer Take:**

Your coding agent could read your design file.
Now it can also generate the production video to go with it.

That's the full brief — design and media — in one conversation.

The only question left: is your brief good enough for both?
