**Tweet 2**
10/26 發布了什麼：所有 Weave 的 video 和 image models 現在可以透過 Figma MCP 存取。

包括 Seedance、Kling、Nano Banana、Veo 3、Luma 等 models。

你在 Claude Code 裡。你說「用 Kling 幫這個元件生成產品影片」。它就執行了。

---

**Tweet 3**
你的 agent 處理的工作流程：

weave_find_model → weave_run_model → weave_get_model_run_output

三個 MCP tools。Agent 處理它們。每次執行前你確認 credit 費用。然後生成。

---

**Tweet 4**
這對設計 stack 的意義：

Figma MCP：你的視覺設計層對 agent 可讀。
Weave via MCP：你的製作媒體層現在對 agent 可呼叫。

同一個 Claude session。從設計到製作資產，不需要 export，不需要開 Weave 頁籤。

---

**Tweet 5**
信任架構做對了。每次付費執行前，agent 顯示費用並等待你確認。

Brief 品質 = credit 效率，不再只適用於 Figma AI 功能了。你 agent session 裡的每次 Weave model 執行，現在都有一個價格標籤。

---

**Tweet 6**
值得弄清楚的計費差異：

Weave 執行消耗 WEAVE credits。
Figma AI 功能消耗 FIGMA AI credits。
兩個獨立的計費表。同一個 Figma MCP 連線。

DesignOps 問題：你團隊裡誰負責管這兩個 credit 池？

---

**Tweet 7**
目前還不能做的事：透過 agent 建立或編輯 Weave workflow——還不支援。

你的 agent 可以呼叫 model，但不能撰寫 workflow。

Workflow 的製作仍然需要 Weave UI。這是不同的使用情境。
