**Title: This open-source tool changed how I think about prototypes**

As a senior UX designer with 10+ years in the field, I've spent a lot of time in the gap between "it looks right in Figma" and "it works in the browser."

Builder.io's Agent Native Design is closing that gap.

✦ **What it is**
A free, MIT-licensed HTML prototyping studio. No signup, no cost. The artifact you produce isn't a mockup — it's a real page running in a real browser.

✦ **How it works (4 steps)**
1. Describe the screen you need
2. Agent generates Alpine + Tailwind HTML from your actual design system
3. Refine by talking to it (natural language, like collaborating with AI)
4. Export HTML, ZIP, or Figma SVG

✦ **The key difference from Figma**
You attach your own design system (Figma file, repo, or package), and their Design System Intelligence generates FROM your tokens and components — not a generic AI house style. Yours.

✦ **What matters most for senior designers**
→ Responsive failures surface in week 1, not at staging
→ Interaction dead ends found before decisions are locked
→ Prototype IS the deliverable — same source hands off to coding agents

✦ **The honest caveat**
Not a Figma replacement. Enterprise-scale component systems and design system governance aren't there yet. This is for ideation-to-browser validation, not the full design lifecycle.

✦ **The question it raised for me**
When your prototype is real HTML running in a browser, the conversation shifts from "how should it look" to "does it work" — and that question belongs at the beginning, not the end.

Try it: design.agent-native.com (or self-host the MIT source at github.com/BuilderIO/agent-native)
