**標題：這個開源工具讓我重新思考 prototype 是什麼**

身為一個做了十幾年 UX 的 designer，我在「Figma 裡看起來對」和「在瀏覽器裡能用」之間的落差花了很多時間。

Builder.io 的 Agent Native Design 正在消除這個落差。

✦ **這是什麼**
免費的 MIT 授權 HTML prototyping 工具。不用註冊，不用付費。你產出的不是 mockup，是跑在真實瀏覽器裡的真實頁面。

✦ **怎麼用（四步）**
1. 描述你需要的畫面
2. Agent 從你的 design system 生成 Alpine + Tailwind HTML
3. 用對話精修（就像和 AI 協作一樣）
4. Export HTML、ZIP 或 Figma SVG

✦ **和 Figma 最關鍵的差異**
你掛上自己的 design system（Figma 檔、repo 或 package），DSI 從你的 token 和 component 生成——不是 AI 的通用風格，是你的風格。

✦ **對 Senior Designer 最重要的是**
→ Responsive 問題在第一週就浮現，不是在 staging
→ 互動死角在決策鎖定之前就找到
→ Prototype 就是交付物，同一份 source 直接給 coding agent

✦ **老實說的但書**
這不是 Figma 的替代品。Enterprise 規模的 component system 和 design system governance 還沒到位。它的定位是 ideation 到 browser 驗證，不是完整的設計生命週期。

✦ **真正讓我重新思考的問題**
當你的 prototype 是跑在瀏覽器裡的真實 HTML，對話就從「它應該長什麼樣」轉向「它能不能用」——這個問題應該在開始時問，不是在最後。
