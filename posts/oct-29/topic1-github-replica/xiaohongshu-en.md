**Title:**
GitHub Replica: the whole team prototypes with your design system now

---

**Content:**

GitHub open-sourced Replica on October 28. Unlike every other AI prototyping tool this year, it builds interactive prototypes guided by YOUR actual components, patterns, and documentation — not AI-invented defaults.

---

**What shipped:**

① Open-source (MIT license) — built by GitHub Design
② Runs inside GitHub Copilot app — PM, engineers, designers all can use it
③ Natural language → interactive prototype using your real design system
④ /setup-skills sets up the constraint layer (designers review and approve)
⑤ Local-first: no server required for local prototyping
⑥ Optional self-hosted Replica Hub for team feedback and comments

---

**How /setup-skills works:**

① Point at your design system docs + component packages
② Copilot checks sources, installs dependencies, drafts guidance
③ Designers review every guidance draft — only approved guidance activates
④ Approved guidance shapes every prototype the team creates going forward

---

**What changes for designers:**

① You're no longer the bottleneck for prototyping — but you ARE responsible for constraint quality
② Your design system docs become the team's prototyping brief
③ Shallow docs → AI produces off-system work that teammates trust and ship
④ Rigorous docs → whole team gets rigorous starting points every time

---

**Honest limits:**

⚠️ Requires GitHub Copilot plan for model access (or own provider, public preview)
⚠️ Replica Hub is self-hosted — your team deploys Docker, configures domain
⚠️ Not a standalone product — lives inside the Copilot + GitHub ecosystem
⚠️ Guidance quality = prototype output ceiling; test this before rolling out to team

---

**Senior Designer take:**

The best sentence in the docs: "Ask for existing approved components rather than visual lookalikes."

That IS the whole argument. Reference beats description. Your actual components ARE the brief.

The designer's new job in this workflow isn't to prototype faster. It's to write constraints precisely enough that others' prototypes are trustworthy.
