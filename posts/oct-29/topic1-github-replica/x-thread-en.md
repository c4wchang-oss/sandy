**Tweet 1 (Hook)**
Everyone keeps saying "AI can prototype now."

What they mean: AI can generate something that looks like a prototype.

GitHub Replica does something different.

It prototypes with your actual design system.

---

**Tweet 2**
What shipped Oct 28:
- Open-source, MIT license — built by GitHub Design
- Runs inside the GitHub Copilot app
- PMs, engineers, and designers all describe what they want in natural language
- Replica uses your real components, patterns, and documentation — not generic AI defaults

---

**Tweet 3**
The mechanism: /setup-skills

Point it at your design system docs, component packages, and documentation.
Copilot checks, installs, and drafts guidance.
Designers review and approve each draft.

Only after approval does it shape what Replica builds.

---

**Tweet 4**
Why this matters:

Every "AI prototyping" tool this year generated off-brand, off-system mockups that designers had to throw away.

Replica flips the order: constraint first, generation second.

Your design system IS the brief — not a description you type after the fact.

---

**Tweet 5**
The designer's job in this workflow:

Not doing the prototyping.

Defining the /setup-skills constraints that make others' prototyping trustworthy.

If your design system docs are shallow → Replica's output ceiling is shallow.
If they're rigorous → the whole team gets rigorous prototypes.

---

**Tweet 6**
Collaboration model:
- Prototype locally (no server, no Hub required)
- Publish to self-hosted Replica Hub for team feedback and comments
- GitHub build action handles the publishing pipeline

Engineering validates assumptions. PMs test ideas.
Designers own the guardrails — not the iteration queue.

---

**Tweet 7**
Honest limits:
- Requires GitHub Copilot plan (or your own model provider — public preview)
- Replica Hub is self-hosted: your team deploys Docker, configures domain
- Design guidance quality = prototype output quality ceiling
- Test early: "ask for existing approved components, not visual lookalikes"

---

**Tweet 8**
The frame worth keeping:

Prototype authorship → democratized.
Constraint authorship → still the designer's responsibility.

Replica makes the second job more consequential than the first.
