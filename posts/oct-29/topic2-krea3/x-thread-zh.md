**Tweet 6**
Brief 品質現在就是訓練品質：

用 4 張模糊的產品照訓練的 LoRA → 規模化時結果不一致。
用 40 張高品質、一致打光的照片訓練的 LoRA → 每次都有品牌準確的結果。

Brief 不再是你打的文字。
是你上傳去訓練的圖片。

**Tweet 7**
誠實的限制：
- 圖片編輯 model——輸出是像素，不是可編輯圖層
- LoRA = 視覺近似，不是結構性限制（對比：Linearity Vector 1.0、Ideogram Vector）
- 沒有 edit endpoint——迭代在你的工具裡，不在 Krea 裡
- CPI-Bench 第 2 名（4.81/5.0），不是第 1（GPT Image 2.5 領先）
- 2K 圖片 $0.06/張；規模化生產費用會累積

---

**Tweet 8**
值得記住的框架：

Prompt = 描述。
LoRA = 訓練過的限制。

對廣告規模的視覺製作，這兩件事的差別就是「看起來一致」和「真的一致」的差別。

Krea 3 讓第二個選項變得可及。
