Krea 3 這週發布了，LoRA 的部分值得比一般報導更多的關注。

標題是速度：2K 圖片編輯在 8 秒內完成，比 GPT Image 2 快 10 倍。CPI-Bench 排名第二，4.81 分，僅次於 GPT Image 2.5。區域編輯讓你可以框選一個邊界框，描述變更，其餘圖片保持不動。這些都很有用。但 LoRA 微調才是結構上不同的東西。

品牌 prompt 描述你想要的東西。LoRA 是你的品牌實際上長什麼樣子的訓練參數。

當你用 40 張一致的產品照片訓練 LoRA，你不是在 context window 裡加一段描述。你是把你特定產品的視覺特徵編碼進 model 的 weights。之後每一個使用那個 LoRA 的圖片編輯都從那些特徵開始——不是從它們的文字近似值開始。

這是 AI 圖片 model 目前接受的最強品牌視覺限制形式。比 prompt engineering 強。比 context 裡的參考圖更強（Krea 3 每次編輯最多支援 6 張）。比可編輯圖層或 design token 這種結構性設計限制弱——LoRA 在像素層面產生視覺一致性，不是在結構層面。但對廣告規模的圖片製作，像素層面的一致性通常才是你實際上在追求的。

區域編輯改變了一個特定的製作痛點。當你有一張 90% 正確的廣告圖——產品位置、打光、構圖都對——但背景需要為不同市場改變，傳統的答案是重新生成所有東西，然後希望對的地方能撐過來。區域編輯移除了這個稅。你只選擇需要改變的部分。其餘的保持原樣。

Brief 品質在這個工作流程裡變成了訓練品質。4 張模糊、打光不一致的產品照片產出一個在規模化時給你近似結果的 LoRA。40 張高品質、一致的照片在每個生成的變體中產出品牌準確的結果。Brief 不再是你打的文字。是你上傳去訓練的圖片。

誠實的限制：Krea 3 是圖片編輯 model，不是設計 model。輸出是像素——沒有可編輯圖層，沒有 design token，沒有活的文字。如果你需要那些，這不是對的工具（Linearity Vector 1.0 和 Ideogram Vector 更適合）。沒有 edit endpoint，迭代在你的設計工具裡進行，不在 Krea 裡面。在每張 2K 圖片 $0.06 的情況下，規模化生產費用會累積。要做好預算規劃。

這件事讓我浮現的分工問題：LoRA 視覺限制和 design system 結構限制是互補的，不是競爭的。你的 design system 管理結構、排版和 components。你的 LoRA 管理存在於那個結構裡的素材的視覺外觀。兩者都需要被當成品質基礎設施來對待——不是一次性設定。
