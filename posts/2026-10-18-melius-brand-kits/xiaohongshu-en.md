**Body:**

Melius launched Brand Kits. The mechanism is different from every "generate on-brand" tool I've seen.

**How it works:**

① Paste your website URL (or upload guidelines)
② Agent parses the brand → generates a "brand anchor" Markdown file
③ Drop anchor onto canvas as a text node
④ Drag edges from anchor to every image/video generation node
⑤ Every generation reads the anchor as context — automatically

**What's in a brand anchor:**
– Palette (hex codes + when to use each)
– Typography (actual font names + hierarchy rules)
– Photography style (studio vs lifestyle, warm vs cool, modeled vs product)
– Shape language and visual motifs
– Explicit do's and don'ts per use case
– Voice and tone with example phrases

**The MCP option:**
Connect Claude via MCP → point to brand.md in your project → Claude auto-injects brand context into every canvas. No manual copy-paste between sessions.

**The honest limitation:**
Brand anchors live at canvas level. New canvas = fresh context. You either copy-paste or rely on MCP. Cross-project brand consistency is still the designer's responsibility.

**The pattern I'm tracking:**
– Automo (Oct 13): brand kit travels to Claude via MCP
– Linearity AI (Oct 17): brand kit quality = the output ceiling
– Melius Brand Kits (Oct 17): URL → structured anchor → edge-connected constraints

Brand kit quality is the binding variable in AI creative production now. Not the model. Not the prompt.

Brand governance: review cycle → text block → canvas edge → MCP injection
