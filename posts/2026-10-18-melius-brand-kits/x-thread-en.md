---

**Tweet 2**
Most brand governance is cultural. Style guides written once and ignored immediately. Review cycles that rely on tribal knowledge to catch violations.

Brand anchor changes the enforcement model: encode the rules into a text block, connect it via canvas edges to every generation node. Constraints become structural.

---

**Tweet 3**
The brand anchor format is smart. Not a vague style guide.

Specific: palette hex codes, typography names, photography rules (studio vs lifestyle, warm vs cool, modeled vs product-only), shape language, explicit do's and don'ts.

Everything a freelance designer would need, compressed into one read.

---

**Tweet 4**
The canvas edge model is what makes it work.

Drop the brand anchor as a text node. Drag edges to your image and video generation nodes. The agent reads it as context for every call automatically.

Visual constraint routing. You can see exactly which generations are brand-constrained.

---

**Tweet 5**
The MCP integration is the governance answer.

If you drive Melius from Claude with the MCP set up, Claude reads brand.md from your project file and injects it into every canvas automatically. No copy-paste, no manual connection.

Brand constraints that travel with the AI assistant.

---

**Tweet 6**
The unresolved problem: brand anchors live at the canvas level.

They don't travel between canvases automatically. Every new canvas = start over, or copy-paste your anchor again.

This is the same session boundary problem every AI creative tool has. MCP is a workaround, not a solution.
