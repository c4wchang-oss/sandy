## What Tesseract is

**Mirage Tesseract** is a free local video creative suite launched September 22, 2026.

Not "AI in Premiere." A video engine whose native interface IS agent instructions.

Built by Mirage — the company behind Captions (250M+ videos produced).

Free to use. Your agent's subscription costs are separate. No Adobe subscription needed.

---

## What agents can do with it

Agents get direct access to:

**Video editing**
Edit footage, cuts, transitions, timing

**Motion graphics**
Keyframes, easing curves, animated text, vector graphics

**Compositing**
Layers, masks, mattes, blend modes, adjustment layers, effects

**Sound**
Audio levels, timing, fade in/out

All via natural language description. No GUI clicking required.

---

## The design insight worth understanding

The quality ceiling for agent-generated video isn't the agent's intelligence.

It's what the engine can represent.

If the engine understands keyframe easing → the agent can produce fluid motion.
If the engine has text-on-a-path → the agent can describe it into existence.
If the engine can't model a concept → no brief can produce it.

**The vocabulary the engine exposes = your creative ceiling.**

This is the same principle as design system tokens. The constraint scope determines the output range.

## How to get started

1. Requires Mac (Apple Silicon or Intel)
2. Need a compatible local agent environment (Claude Code, Codex, or similar)
3. Install via: `npx skills add mirage-hq/Tesseract` or use the ChatGPT plugin (coming soon)
4. Point agent at footage + give a creative brief
5. Agent builds, previews, revises, renders editable project
