**Tweet 3**
關鍵的設計決策：

Tesseract 沒有把 Premiere 包裝上一個 AI 助手讓它點擊菜單，而是直接讓 agent 存取真正重要的創意概念：

— 影片圖層和合成
— 關鍵影格和動態曲線
— 遮罩、遮板和調整圖層
— 時間軸和聲音

Agent 操作的是影片基本元素。不是為人類手部設計的 GUI。

---

**Tweet 4**
這跟九月的 OUI-1 是同一個模式。

OUI-1 不是「UI 建構器裡的 AI」。它是一個專門訓練來產生 UI 的模型，以元件庫的 TypeScript 簽名作為系統提示。

Tesseract 不是「Premiere 裡的 AI」。它是一個影片引擎，而它的主要介面是 agent 指令。

這個轉變：從工具裡的 AI，到原生為 agent 設計的工具。

---

**Tweet 5**
這對品質天花板意味著什麼：

當你跟 agent 描述你想要什麼，品質天花板不在於 agent 的智慧。在於引擎能表達的詞彙。

它理解關鍵影格的緩動嗎？圖層混合模式？路徑上的文字？遮罩羽化？

Tesseract 的引擎能呈現什麼 = 你的 brief 實際上能產出什麼。

這就是設計決策。選擇那些基本元素的人做了一個創意方向的決定。

只支援 Mac（Apple Silicon + Intel），需要本地端 agent 環境。

**Tweet 8（CTA）**
Premiere 教你用軌道、時間軸和關鍵影格思考。

Agent 不需要時間軸。它需要語言。

在這個層次進行創意方向的問題不是「我會用這個工具嗎？」而是「我能描述得夠精確，讓引擎的詞彙產出我想要的嗎？」

這是不同的技能。值得現在就開始建立。
