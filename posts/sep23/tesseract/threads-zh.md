Mirage Tesseract 讓一個值得命名的模式變得具體：我們正處於 AI 融入創意工具的第二個階段。第一個階段是把 AI 附加在既有工具上——Photoshop 裡的 Generative Fill 按鈕、Premiere 裡的 AI 圖層、在現有 GUI 旁邊運作的「讓它更好」功能。第二個階段不同了。是把 agent 基本元素當作原生介面來建立創意引擎，而傳統 GUI 是事後加上的選配層。

Tesseract 昨天推出：免費的本地端影片創意套件，不是為人類的手設計的，而是為 AI agent 設計的。定位：「把 Tesseract 想成 Premiere 和 After Effects，為 agent 重建的版本。」Agent 直接存取影片圖層、合成、關鍵影格、遮罩、調整圖層、時間軸和聲音——不是透過點擊螢幕，不是透過 HTML/React 的翻譯層，而是透過影片真正重要的概念，作為原生的 agent 工具暴露出來。在 Mac 本地端執行，由 Captions 和它的 2 億 5,000 萬個影片背後的同一個引擎驅動。

這背後的設計思維值得從產品公告中單獨拿出來看。當 Mirage 決定 agent 能存取哪些基本元素——關鍵影格、圖層類型、混合模式、遮罩形狀、音頻控制——他們做了創意方向的決定。引擎能呈現的 = brief 能產出的。如果引擎沒有關鍵影格緩動曲線的概念，agent 就無法產出流暢的動畫。如果它沒有暴露路徑上的文字，不管你描述得多好，那就不在選項裡。

這是限制架構應用在創意工具上。引擎暴露的詞彙就是天花板。設計 Tesseract API 的人做了跟決定把哪些 token 放進設計系統一樣的決定。限制的範圍形塑了每一個下游的創意決策。

如果你把九月的推出放在一起看，這個模式現在已經很清晰：OUI-1（一個專門訓練來產生 UI 的模型，以元件簽名作為系統提示）、Builder.io 的 HTML prototype 工作室（產出物本身就是可部署的）、現在的 Tesseract（以 agent 基本元素作為介面的影片引擎）。這些不是工具裡的 AI。它們是從基本元素開始建立的 agent 原生創意環境。

地板移動的故事也是真實的：Tesseract 是免費的。你不需要 Adobe 訂閱來使用它。你付 agent 的費用——你已經在付的 Claude 或 ChatGPT 費用。跟 2013 年的 Canva 和八月的 Wixel 一樣的地板轉移模式，現在到了影片製作。指揮一個專業影片製作被工具知識門檻卡了 35 年。Tesseract 移除了那個門檻——並用 brief 品質取代了它。

在你執行安裝之前的誠實注意事項：推出時只支援 Mac（Apple Silicon 和 Intel，不支援 Linux、WSL、雲端），需要本地端 agent 環境，ChatGPT 和 Claude 外掛標示「即將推出」尚未發布。引擎是經過驗證的。Agent 介面還在早期。在期望正式環境穩定性之前，先看 GitHub。

值得建立的技能：Premiere 教你用軌道、時間軸和關鍵影格思考。你在一個對應那些概念的 GUI 裡導航。Agent 不需要 GUI 導航——它需要那些概念。「慢動作廣角鏡頭切到特寫，標題卡以 200 毫秒緩動淡入，音頻降到 30% 後回升」比手動點擊二十個面板設定那些參數是更好的 brief。創意方向和精確描述現在是同一個技能。
