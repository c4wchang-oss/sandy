## What Pendo for Agents is

Pendo launched two products yesterday:

**Agent Analytics (GA)**
Measures whether your AI agent is actually helping users — conversation success rate, drop-off patterns, unhelpful resolution tracking.

**Agent Toolkit (open beta)**
Connects any AI agent to Pendo's behavioral data via MCP, so agents can act on what users are doing before they even type a message.

---

## What context agents get

Agent Toolkit gives agents real-time access to:

**Session context**
What the user just did in your product — which flows they completed, where they navigated, what they ignored.

**Frustration triggers**
Rage clicks. Dead clicks. U-turns. Error clicks. Sent directly to the agent so it can step in before someone opens a support ticket.

**Workflow nudges**
Where someone dropped off a defined flow. Agent re-engages them at the exact step they abandoned.

**Guide surfacing**
Points the agent to the exact Pendo guide that solves what the user is stuck on — no generic help center links.

---

## The UX insight hidden here

We've been collecting these signals for years. Heatmaps. Session recordings. Funnel analytics. Drop-off cohorts.

None of it was ever live agent context.

It was always retrospective reporting — for product teams to act on maybe next sprint.

Pendo for Agents turns behavioral history into real-time agent input.

---

## The design implication

Your agent inherits your product's behavioral history.

Every incomplete onboarding flow you never fixed → agent gets asked about it and doesn't have context.
Every dead end users rage-click through → agent now responds to that frustration signal.
Every workflow nobody finishes → agent now surfaces a nudge at that exact step.

**Your UX debt shows up directly in your agent's failure rate.**

---

## The senior UX role shift

You're not just designing the interface users click through.

You're architecting the behavioral context layer that agents inherit.

- IA quality → agent context quality
- Flow completion rate → agent workflow nudge accuracy
- Guide content depth → agent resolution rate

The quality ceiling for your AI agent = the quality of your UX work.
