4,700 萬次 agent 對話。Agent 通過評估。用戶還是覺得沒被幫到。

---

## Pendo for Agents 是什麼

Pendo 昨天推出了兩個產品：

**Agent Analytics（正式版）**
衡量你的 AI agent 是否真的在幫助用戶——對話成功率、中途放棄的模式、追蹤無效的解決方案。

**Agent Toolkit（公開測試版）**
透過 MCP 把任何 AI agent 連接到 Pendo 的行為數據，讓 agent 可以在用戶打字之前就根據他們的行為採取行動。

---

## Agent 取得什麼情境

Agent Toolkit 給 agent 即時存取：

**Session 情境**
用戶剛才在你的產品裡做了什麼——完成了哪些流程、導航到哪裡、忽略了什麼。

**挫敗觸發**
憤怒點擊。死點。U 型折返。錯誤點擊。直接送到 agent，讓它在有人開支援票之前介入。

**流程提醒**
有人在定義好的流程中途放棄的位置。Agent 在他們放棄的那個精確步驟重新接觸他們。

**導引浮現**
把 agent 指向那個解決用戶卡點的 Pendo 導引——不是泛型的說明中心連結。

---

## 隱藏在這裡的 UX 洞察

我們收集這些訊號已經好幾年了。熱力圖。Session 錄影。漏斗分析。流失群組。

這些從來都不是 agent 的即時情境。

一直都是回顧性的報告——給產品團隊可能下個 sprint 才會處理的。

Pendo for Agents 把行為歷史轉為即時的 agent 輸入。

---

## 設計上的影響

你的 agent 繼承了你產品的行為歷史。

你從未修復的每個不完整 onboarding 流程 → agent 被問到卻沒有情境。
用戶靠憤怒點擊硬撐過去的每個死胡同 → agent 現在回應那個挫敗訊號。
沒有人完成的每個流程 → agent 現在在那個精確步驟浮現提醒。

**你的 UX 債務直接反映在你的 agent 失敗率上。**

---

## 資深 UX 角色轉變

你不再只是設計用戶點擊的界面了。

你在架構 agent 繼承的行為情境層。

- IA 品質 → agent 情境品質
- 流程完成率 → agent 流程提醒準確度
- 導引內容深度 → agent 解決率

你的 AI agent 的天花板 = 你的 UX 工作品質。

## 誠實的評估

✅ Agent Analytics 已正式版——現在就可以用
✅ 支援 Intercom Fin + 透過 MCP 的自訂 agent
✅ 挫敗訊號自動化了以前需要看 session 錄影才能做的事
⚠️ Agent Toolkit 還是公開測試版
⚠️ 主動支援（提醒 + 挫敗訊號）在測試期間需要聯繫 Pendo 支援才能開啟
⚠️ 61% 提升數字來自 Pendo 自己的產品——單一內部數據點
⚠️ 自訂 agent 設定比 Fin 整合複雜

## 重新框架

「Agent 通過評估但使用者感覺沒被幫到」一直都是情境問題。

那個情境一直都存在於你的分析資料裡。

問題是你的 agent 能不能讀到它——以及你建立的行為歷史是否值得閱讀。
