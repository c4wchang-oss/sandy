**Title:**
ChatGPT just started doing IA work — here's the UX catch nobody's talking about

---

**Body:**

ChatGPT's new Visualize skill turns unstructured text (meeting notes, project docs, research summaries) into interactive visual interfaces — dashboards, timelines, calendars.

It sounds great. But here's what nobody's saying clearly:

**The format choice IS the design decision.**

When a human IA designer picks a format, they're answering a question first:
1. Timeline → "What happened and when?"
2. Calendar → "What do I need to act on next?"
3. Dashboard → "What's the state right now?"
4. Matrix → "How do these options compare?"

Each format carries a different mental model. AI picks one. It doesn't ask which fits your audience's actual question.

---

**The useful part:**

✅ Export or publish directly to a shareable URL — zero dev work
✅ Interactive views (tabs, calendar format) generated automatically
✅ Works for daily briefings, project summaries, team updates

**The honest part:**

⚠️ Interactive buttons = follow-up prompts, NOT live data
⚠️ Don't hand this to a stakeholder expecting a connected dashboard
⚠️ When AI guesses the wrong format, most people won't catch it

---

**The senior UX skill this unlocks:**

Evaluating AI's IA decisions — not just AI's visual output.

Not "does it look right?" but "does this format surface the right question for this specific audience?"

AI made information architecture invisible. Someone still has to check the work.
