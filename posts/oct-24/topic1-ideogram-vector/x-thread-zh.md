**Tweet 2**
Ideogram 的第一個 vector 模型提供兩種工作流程：

Text-to-vector：描述一個 logo、wordmark、標籤或平面插圖 → 得到乾淨可編輯的 SVG。

Image-to-vector：上傳 JPEG、PNG 或 WebP → 轉換成真正的 path、可編輯顏色、平滑漸層。

在 Figma、Illustrator 或 code 裡打開。不需要中間的描圖步驟。

---

**Tweet 3**
這比聽起來更重要。

AI 生成的品牌工作從第一天起就有一個根本問題：輸出格式。

你會生成一個有潛力的 logo 方向，得到一個平面點陣圖，然後手動重畫整件事，或花錢請人描圖。AI 做了快速的部分。你還是做了慢速的部分。

Vector 1.0 完全移除那個步驟。

**Tweet 4**

一次品牌概念探索的單位成本剛剛降到一杯咖啡以下。

**Tweet 7**
誠實的限制——在任何生產使用前這些都很重要：

輸出可能是外框而非活字——在假設可以重新輸入之前先點擊那個字。

Image-to-vector 的圖層分組「尚未提供」——你得到的是一堆 path，不是有結構的場景。

沒有編輯 endpoint——迭代在你的向量編輯器裡發生，不是在模型裡。

商業生產使用前需要商標查核。
