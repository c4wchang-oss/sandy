有一個正在形成的類別，我認為它被嚴重低估了。

Canva 剛推出他們第一個自研圖像模型——Canva Craft——讓它有趣的架構決策跟他們引用的品質排行榜毫無關係。那些排名都好。架構決策更有趣。

Craft 使用兩階段流水線：一個規劃模型讀取你的 prompt 並撰寫構圖計畫（元素、空間關係、比例、視覺層級、文字），以及一個渲染模型將那個計畫轉換成高保真最高 2K 的圖像。這種分離意味著模型在生成任何像素之前先推理版面結構。

對設計師來說，這是一個有意義的區別。大多數圖像模型把視覺層級當作自然湧現的——prompt → 像素，版面決策是隱含的。Craft 把版面結構變成生成過程中的一等公民步驟。當構圖失敗時，是因為計畫錯了。這意味著你實際上可以診斷它：brief 是模糊的嗎？層級意圖不清楚嗎？受眾背景缺失嗎？

訓練資料決策強化了這一點。Canva 沒有用照片訓練 Craft。他們用模板庫訓練——幾十年的人工設計海報、資訊圖表、簡報、菜單和文字密集的版面。設計素養烤進模型權重，不是靠 prompt 輸入。模型已經帶著關於標題應該放在哪裡、一則社群貼文需要多少呼吸空間、資訊圖表上的層級是什麼樣子的知識。

輸出連接到 Magic Layers，將生成的圖像轉換為可編輯元素。Canva MCP 列為即將到來——當它推出時，程式碼 agent 將能在更大的 agentic 工作流程中把生成品牌就緒圖像作為單一可呼叫步驟。

誠實的限制：50–60 秒的生成時間比競爭對手確實更慢，對迭代創意工作是真實的摩擦。目前還沒有品牌套件輸入——brief 品質仍然是文字 prompt 品質。而規劃階段意味著自信錯誤的計畫會產生精緻的、有結構的錯誤圖像。在各種規模的 AI IA 的相同失敗模式。

但類別訊號是我一直回頭看的。八天內三個工具都在押同一個賭注：

Linearity Vector 1.0（10/17）——生成可編輯的品牌設計結構，不是像素近似值。
Vyb / Coco Labs（10/21）——用你的實際品牌資產和字型檔案組合行銷版面。
Canva Craft（10/22）——生成在設計模板而非攝影上訓練的版面感知圖像。

八天內三個實例不是巧合。是一個類別在形成。

圖像模型產生像素。設計模型產生起始點。

對 senior 設計師的問題不是「哪個渲染出更好的質感」。而是「哪個在渲染任何東西之前就知道層級應該去哪裡。」
