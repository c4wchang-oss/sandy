**Tweet 1 (Hook)**
"Which image model looks best" is the wrong question.

Canva Craft is asking a different one.

---

**Tweet 2**
Canva's first in-house image generation model uses a two-stage architecture:

Stage 1 — a planning model that reads your prompt and writes a composition plan: which elements appear, spatial relationships, relative scale, visual hierarchy, any text.

Stage 2 — a rendering model that translates that plan into a high-fidelity image up to 2K.

The planning stage is doing IA before rendering pixels.

---

**Tweet 3**
That architectural distinction matters.

Most image models go prompt → pixels. The visual hierarchy decisions are implied, not deliberate.

Craft makes layout structure a first-class step. When the composition fails, it's because the plan was wrong. And when the plan is wrong, it's usually because the brief was wrong.

The failure mode is now traceable.

---

**Tweet 4**
And the training data is the other interesting decision.

Canva didn't train Craft on photographs. They trained it on their human-designed template library — posters, social posts, presentations, infographics, menus, typography-heavy layouts.

Design literacy is baked into model weights, not prompted in. The model already knows where the headline should go.

---

**Tweet 5**
This confirms a category that's been forming quietly.

Three confirmed instances of "design models" — models trained for design output rather than photographic realism:

→ Linearity Vector 1.0 (Oct 17): generates editable brand design structure
→ Vyb / Coco Labs (Oct 21): composes marketing layouts using your actual brand assets
→ Canva Craft (Oct 22): generates layout-aware images trained on design templates

Image models produce pixels. Design models produce starting positions.

---

**Tweet 6**
The output connects to Canva's Magic Layers, which converts the generated image into editable design elements.

When Canva MCP ships (listed as coming soon), coding agents will be able to generate brand-ready images as one step inside a larger campaign workflow.

The constraint pipeline: Claude + Figma + Payload + Canva Craft — one end to the other, agent-callable.

---

**Tweet 7**
Honest limits:

The planning stage means a wrong brief produces a confidently wrong composition. Polished, structurally organized, wrong. This is the same failure mode as AI IA at every scale.

Generation time is 50–60 seconds. Slower than competitors. Real friction for iterative workflows.

No brand kit constraint input yet. Brief quality is still text prompt quality until MCP ships.

**Tweet 8 (CTA)**
The question for senior designers is no longer "which model renders the best textures."

It's: "which model understands design well enough to know where the hierarchy should go before it renders anything."

Craft is the clearest answer to that question so far.

Three instances make a category. The design model is real.
