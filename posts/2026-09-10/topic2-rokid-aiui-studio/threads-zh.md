# Topic 2: Rokid AIUI Studio — 空間 AI 應用開發平台
# Platform: Threads | Language: Traditional Chinese
# Date: Sep 10, 2026 | Format: 長篇個人反思
# Source: https://www.prnewswire.com/news-releases/rokid-launches-aiui-studio-globally-at-ifa-berlin-2026 (Sep 9, 2026)

---

Rokid 本週在 IFA Berlin 推出了 AIUI Studio。打開瀏覽器，用自然語言描述你的空間 Agent，平台幫你建出 Rokid AI Glasses 上的 App。不需要設備，不需要本地開發環境，瀏覽器裡有手勢互動和光線環境的模擬測試。

我的第一個直覺反應：同樣的故事，新的介面表面。

Canva 讓平面設計變得平易近人。Wixel 讓網站設計變得平易近人。現在 AIUI Studio 讓空間 AI Agent 的創作變得平易近人。每次設計介面的開發門檻下降，同樣的問題就跟著出現：誰來確保品質？

空間 UX 有真實的限制，不會因為工具變簡單而消失。可瀏覽性 — 使用者透過半透明鏡片，在半秒內能解讀多少資訊？最小干擾 — Agent 什麼時候有權打斷使用者的實體注意力？漸進揭露 — 對一個在移動中的人，如何分層傳遞信息？

這些問題需要情境設計判斷力。在 AIUI Studio 裡，答案需要住在 AIUI Skills Library 裡 — 那個管理 Agent 如何使用硬體資源的約束框架。每個在那個 Library 裡撰寫 skills 的設計師，都在寫所有人遵循的品質底線。

Skills-as-governance 的模式今年一直在出現。Figma Agent Skills，Divi 的 22 個 purpose-built skills，CapCut Skills Ecosystem。這個模式一致：skill 的作者就是 constraint architect。

誠實地說：Rokid 不是 Meta 也不是 Apple，用戶基數有限。我們今天大多數人不是在為 Rokid Glasses 的使用者設計。但設計原則 — 可瀏覽性、環境感知、最小認知負擔 — 是可遷移的。不管哪款耳機最後勝出，這些判斷是一樣的。趁現在平台還夠簡單去實驗，比在生產壓力下才學要好。
