**Title:** You Can Now Design Spatial AI Experiences Without Smart Glasses — But the Hard Part Is Still Design

---

🎯 **What happened:**
Rokid launched AIUI Studio at IFA Berlin on September 9, 2026. Browser-based, all-in-one platform to design, build, and publish AI agents for Rokid AI Glasses.

No physical glasses needed. No local dev environment.
Describe your agent in plain language → AIUI Studio builds the app.
Test in browser simulation: gestures, lighting conditions, full interaction flow.
One-click publish to the Rokid AI App store.

📌 **What the AIUI Skills Library does:**
→ Optimizes latency for glasses hardware automatically
→ Manages memory constraints on-device
→ Balances power consumption

The platform encodes hardware constraints. You focus on the interaction.

📌 **Why this matters for UX designers:**

**The authoring barrier dropped. The design judgment barrier didn't.**

Spatial UX has constraints that don't get easier when the tool gets simpler:

1. **Glanceability**
   Semi-transparent display. Moving context. Ambient environment competing for attention.
   A user can't stop and read. What can be parsed in a half-second?

2. **Minimal interruption**
   When does the agent have permission to break the user's physical attention?
   Getting this wrong is worse than bad notification timing on a phone.

3. **Progressive disclosure**
   How do you layer information for someone who's physically moving?
   You can't dump a dashboard on a glasses overlay.

4. **Environment-aware design**
   Strong sunlight degrades overlay contrast. Indoor vs outdoor context changes everything.
   Design that ignores the environment degrades to unusable faster than expected.

✅ **How to use AIUI Studio now:**

1. **Use browser simulation as design research, not just testing**
   Lighting and gesture simulation surfaces assumptions you didn't know you were making.

2. **Author AIUI Skills with interaction quality constraints, not just hardware ones**
   The Library governs hardware. Your skill definitions can also govern interaction quality.
   Write glanceability rules. Write interruption thresholds. Encode spatial UX principles.

3. **Design for no-look interaction first**
   The most reliable spatial agent interaction is one the user doesn't have to look at.
   Voice + subtle visual confirmation > rich visual overlay.

4. **Design for forgettable experiences**
   Good spatial UX is invisible. User didn't notice the agent worked.
   Bad spatial UX is memorable. They felt interrupted, confused, or visually overwhelmed.

⚠️ **Honest caveat:**
Rokid's installed base is limited. You're not designing for large-scale spatial audiences yet.
Spatial UX principles are transferable across headsets — the platform implementation isn't.
The judgment you develop now applies when the winning platform ships.

💡 **The reframe:**
AIUI Studio is a browser-based design tool for a surface that barely exists yet.
That's exactly when design thinking matters most —
before the defaults get set, and before everyone else follows them.
