---

**標題：** Framer 不再是網站製作工具了 — 它變成了 Claude Code 的前端終端機 丨模型選對省 67% Credits

---

✦ 先說這次更新了什麼

Framer 3.0 核心更新（2026 年 6 月 16 日）：

① Agents 內建在畫布右側面板，可以即時共同編輯，完整 undo/redo，包含一鍵 Revert
② Branching：從你的 live 網站複製一個隔離版本安全實驗
③ External Agents：Claude Code 透過 Framer CLI 連進來，在 branch 上自動運作，用你自己的 LLM tokens，不消耗 Framer Credits

最新效率更新（7 月 21 日）：
・GPT 5.6 Terra 成為預設模型
・多步驟構建比 GPT 5.5 省 60-67% Credits
・整體省 ~25% Credits

---

✦ 三個模型，三種用途

GPT 5.6 Sol — 最強創意品質，Credits 成本和 GPT 5.5 相同
→ 首屏探索、品牌視覺方向、高判斷設計決策

GPT 5.6 Terra — 0.6x Credits，平衡品質與速度
→ 全站一致性稽核、響應式斷點調整、系統性工作

GPT 5.6 Luna — 0.4x Credits，速度快兩倍
→ 大量 CMS 更新、全站 find-and-replace、批量工作

選模型不是省錢問題，是任務分類問題。高判斷用 Sol，系統性用 Terra，批量用 Luna。

---

✦ 最大的架構轉變：External Agents

Claude Code → Framer CLI → 自動建立 branch → 生成/更新網站 → 你在畫布上審查 → merge

Framer 從「網站製作工具」變成了「AI coding agent 的部署目標」。設計工具不再是起點，而是 AI 落地後的審查介面。

---

✦ Senior Designer 的角色在哪

不是在點 Agent 面板的按鈕。

而是：
・模型分配政策（哪個任務用哪個模型）
・Branching 策略（哪些實驗需要 branch，哪些直接改 main）
・External Agent 的 review gate（Claude Code 可以改什麼，不能改什麼）

AI 做設計。設計師管 AI 的工作範圍和品質標準。

---

✦ 值不值得切換到 Framer 3.0

如果你已經在用 Claude Code 做前端：值得試 External Agents。直接把 Framer 當 Claude Code 的輸出目標。

如果你是純設計師：先試 Terra 模型的全站 consistency pass。最實用的功能，Credits 最省。
