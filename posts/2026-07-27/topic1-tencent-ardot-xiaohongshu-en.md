**Title:** Tencent Ardot Beta: PM + Designer + Dev on the Same Canvas — Senior UX Reality Check

---

✦ What it does

Tencent just launched Ardot in beta. Here's the actual product:

① PM types requirements in natural language → layout draft generated in ~5 minutes
② Designer refines on the same canvas — layer structure + component properties preserved
③ Developer previews and exports React/Vue code from the same file

Three roles, one canvas, simultaneous. Not sequential. Parallel.

---

✦ Why this matters beyond "AI generates UI"

Most "AI design" tools speed up one person's workflow.

Ardot's bet: eliminate the translation cost from the entire collaboration loop.

PM writes doc → designer interprets → designer builds → dev receives Figma → dev asks questions → designer re-explains.

That whole cycle disappears. Everyone's in the same room.

---

✦ The uncomfortable read for designers

"Designers can focus more on creativity and user experience" — that's only true if what's being automated is the low-judgment interpretive work.

If AI handles: interpreting PM requirements, matching components, generating layout structures — that's entry-level designer work.

The first thing to disappear isn't the design role. It's junior headcount.

---

✦ Current limitations (their own words)

・Standard pages: solid
・Data visualization, animation interactions, complex states: needs more iteration
・Component output token-compliance with external design systems: unknown

---

✦ The test that actually matters

Not generation speed.

Whether the one-click React/Vue export survives a real design system token audit.

Any tool can generate something that looks like your component library. Very few generate something that actually is.

---

✦ Worth trying?

Yes — 1,000 free credits in beta. Go test it.

But use your actual design specs, not a blank canvas. That's the real review.
