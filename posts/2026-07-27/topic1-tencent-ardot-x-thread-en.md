---

**Tweet 1 (hook)**
Tencent launched Ardot in beta.
The headline: "generate UI from natural language in 5 minutes."
That's not the story.

---

**Tweet 2**
The story: PM types requirements on the canvas. Designer refines it in the same file. Developer previews code — same canvas, same moment.
No Figma link in Slack.
No "can you re-export that?"
The handoff is gone because everyone is in the room.

---

**Tweet 3**
We've called this "collaboration" for a decade. What we meant: faster approval loops for a serial process.
PM writes doc → designer reads it → designer builds → developer receives Figma → dev asks questions → designer re-explains.
That's not collaboration. That's a relay race.

---

**Tweet 4**
Ardot proposes something different.
AI handles the translation layer: matching natural language to component libraries, generating the layout skeleton.
Then three roles refine simultaneously.
AI isn't replacing anyone. It's collapsing the gap where translation used to live.

---

**Tweet 5**
The uncomfortable read: that translation gap is where junior designers learned.
"Designers can focus on creativity and user experience" — true only if what's being automated is the low-judgment interpretive work.
Which is exactly where entry-level design careers start.

---

**Tweet 6**
What the tool currently can't do well: data visualization, animation interactions, advanced states.
Which is exactly where senior judgment lives.
Patterns → commoditized. Systems → still hard. For now.

---

**Tweet 7**
The real test isn't generation speed.
It's whether the one-click React/Vue export survives a design system token audit.
Any tool can generate something that looks like your component library.
Very few can generate something that actually is.
