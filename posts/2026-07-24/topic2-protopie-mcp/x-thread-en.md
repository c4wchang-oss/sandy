# X Thread — ProtoPie MCP (English)
**Topic:** ProtoPie MCP — AI agents can now read the actual interaction model behind a prototype
**Angle:** "The prototype was always supposed to be the spec. Now it finally is."
**Date:** July 24, 2026

---

**Tweet 1 (Hook)**
ProtoPie just launched MCP support.

The headline: "AI can now build prototypes from natural language."

That's the Studio MCP side.

The more important part is Code MCP.

🧵

---

**Tweet 2**
Code MCP gives AI coding agents access to the actual interaction model behind a prototype:

- Triggers and responses
- Variables and formulas
- States and transitions
- Layer and component structure

Not a screenshot. Not a video. The interaction logic itself.

---

**Tweet 3**
For context: how has AI been implementing prototypes until now?

From screenshots, exported videos, and written descriptions.

Which means every implementation involves interpretation — guessing interaction logic from a visual artifact.

"The button should animate when tapped" is different from the trigger → response chain that exists in ProtoPie.

---

**Tweet 4**
Code MCP changes the input from approximation to specification.

Your prototype — built with real trigger logic and state management — becomes a structured data source that AI agents can query.

They don't interpret what they see. They read what you specified.

---

**Tweet 5**
Dev View takes it further.

You can share context at any granularity:
- Full prototype
- One scene
- One component
- One layer

Smaller context = cleaner code output. The agent isn't reading your entire design system to implement one modal.

---

**Tweet 6**
Studio MCP is the creation side.

Natural language → interactions wired in ProtoPie. Trigger, response, formula — built by describing what you want.

Every generated interaction stays fully editable. AI handles the setup; you refine the precision.

---

**Tweet 7**
This fits a pattern I've been tracking:

Figma Code Layers, Flowstep AI, UserTesting MCP — tools converting design artifacts into machine-readable context for AI agents.

The prototype isn't just for humans to understand anymore. It's for agents to consume and implement from.

---

**Tweet 8**
Senior take:

The prototype was always supposed to be the spec.

In practice it was a human artifact that got translated — imperfectly — into code by developers who had to infer intent from a video.

Code MCP closes that gap. The inference step gets replaced by a query.

The intention gap between design and implementation just got measurably smaller.
