## Topic 1: Tencent Miora
**Angle:** "When AI gets a production team, the designer's job becomes creative direction — not prompting"

Tencent officially opened Miora to the general public (July 22, 2026). Miora is not a single AI model doing all creative work — it's an orchestration layer that routes tasks to specialist agents (brand design, 3D, video, UI) with persistent memory across sessions.

**Key insight:** Multi-agent orchestration shifts the designer's role from "operating a tool" to "directing a team." The brief quality, constraint template selection, and review gate design become the core design skill.

**Real headline:** Creative director used to be aspirational. Now it's operational.

## Topic 2: ProtoPie MCP
**Angle:** "The prototype was always supposed to be the spec. Now it finally is."

ProtoPie launched native MCP support (beta, July 20–23, 2026). Two modes: Studio MCP (natural language to create interactions) and Code MCP (AI coding agents get the actual interaction model — triggers, states, variables, formulas — not screenshots or videos).

**Key insight:** AI has been implementing from screenshots and videos — i.e., interpretation. Code MCP replaces interpretation with a query. The inference step between design intent and implementation gets eliminated.

**Real headline:** The prototype isn't just for humans to understand anymore. It's for agents to consume and implement from.
