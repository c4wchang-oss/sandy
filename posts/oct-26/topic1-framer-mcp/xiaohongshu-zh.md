**標題：**
Framer MCP 上線：Senior UX Designer 真正需要知道的事

---

**內文：**

你的 Claude 或 ChatGPT 現在可以直接編輯你的 Framer 網站了。不用終端機——在 Claude 的 connector 目錄一鍵連接就好。以下是真正值得在意的事。

---

**46 天弧線：**

① 9/6：Webflow 獲得 agent-native 存取
② 9/23：Elementor（WordPress）跟上
③ 10/22：Framer MCP 發布

每個主要 web CMS/builder 現在都有 agent-native 存取。相同路徑：constraint document → Skills → MCP。三個平台，各自獨立。

---

**Agent 可以做什麼：**

① 跨所有斷點建立和編輯頁面（桌機、平板、手機）
② 重用你現有的 Framer 樣式和元件
③ 建立 CMS collection，從你附的檔案匯入內容
④ SEO 審查：標題、alt text、metadata、頁面結構
⑤ 在 review branch 上工作——線上網站在你發布前完全不受影響

---

**費用的故事：**

Framer MCP 不從 Framer 扣費，計在你的 Claude/ChatGPT 方案。你的 Framer credits 不動。對於已有 AI 訂閱的團隊，這是支出整合，不是新的費用項目。

---

**信任架構（他們做對了）：**

→ 在你明確下「publish」指令前，什麼都不會上線
→ Claude 在每個動作前詢問確認
→ 把 publish 設成「Needs approval」——永遠不要改它

---

**要注意的事：**

⚠️ 目前不支援多語系——有 i18n 需求的團隊：先繼續用 local CLI
⚠️ 你需要明確的 prompt：說出頁面名稱、section、component
⚠️ 在 Framer 裡 review 後再信任——外部 agent 看到的上下文比內建工具少

---

**目前最佳使用場景：**

從 chat 管理 CMS。整理 case study → 準備 CMS schema → 匯入內容。全部在 Framer 關閉的情況下完成。把 Ahrefs 或 Notion 接到同一個 agent session。

---

**核心觀點：**

你 Framer 專案裡的 Skills 是 agent 一切輸出的品質上限。現在花時間寫好 Skills 文件，比學任何新的 prompt 技巧都更有價值。

預覽期間所有方案免費。
