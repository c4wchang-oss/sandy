**Title:**
Framer MCP: what a Senior UX Designer actually needs to know

---

**Body:**

Your Claude or ChatGPT can now edit your Framer site directly. No terminal setup — one click in Claude's connector directory or ChatGPT's plugin tab. Here's what actually matters.

---

**The 46-Day Arc:**

① Sep 6: Webflow ships agent-native access
② Sep 23: Elementor (WordPress) follows
③ Oct 22: Framer MCP launches

Every major web CMS/builder now has agent-native access. Same playbook: constraint document → Skills → MCP. All three, independently.

---

**What Your Agent Can Do:**

① Create + edit pages across all breakpoints (desktop, tablet, phone)
② Reuse your existing Framer styles and components
③ Create CMS collections + import content from files you attach
④ SEO audit: headings, alt text, metadata, page structure
⑤ Work on a review branch — live site untouched until you publish

---

**The Cost Story:**

Framer MCP is free on Framer's side. Billed to your Claude/ChatGPT plan. Your Framer credits don't move. For teams already paying for AI subscriptions, this is consolidation not a new line item.

---

**The Trust Architecture (They Got This Right):**

→ Nothing publishes without your explicit "publish" command
→ Claude asks for confirmation before every action
→ Set publishing to "Needs approval" — leave it there permanently

---

**What to Watch For:**

⚠️ No localization at launch — i18n teams: stick with local CLI for now
⚠️ You need specific prompts: name the page, section, and component
⚠️ Review in Framer before trusting — external agent sees less context than the built-in tool

---

**Best Use Case Right Now:**

CMS management from chat. Sort your case studies → prepare CMS schema → import content. All while Framer is closed. Connect Ahrefs or Notion to the same agent session.

---

**Bottom Line:**

The Skills in your Framer project are the quality ceiling for everything the agent does. Writing good Skills documentation now is more valuable than learning any new prompt technique.

Free during preview on every plan.
