**Tweet 1 (Hook)**

Changed.

---

**Tweet 2**
What's actually new:

Element-level editing controls.
- Select any element on the canvas
- Drag, resize, align directly
- Inline text editing
- Adjustment sliders Claude generates for spacing and color
- Undo/redo

This closes the "generate and lose control" problem.
You're not locked into what the model makes. You can refine it.

---

**Tweet 3**
The /design command in Claude Code is the part I'm watching most carefully.

You're working in the terminal. You type /design.
Claude generates artboards, publishes a canvas, you open it in the browser and edit with full element control.

Then you handoff directly back to Claude Code to implement.

Design happens inside the development workflow. Not before it.
