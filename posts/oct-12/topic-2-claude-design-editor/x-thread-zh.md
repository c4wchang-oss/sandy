# X Thread — Claude Design 編輯器控制 + 10/15（繁體中文）

**Tweet 1（開頭）**
Claude Design 剛做了改變。

不是「新增了一個功能」。
是改變了。

它現在可以在每一個 Claude 對話、每一個 Claude Code session 裡使用，而且 10 月 15 日起會對所有企業團隊預設啟用。

如果你上次看這個工具還是在 beta 公告的時候，你現在看到的是一個不同的產品了。🧵

---

**Tweet 2**
真正新增了什麼：

元素層級的編輯控制。
- 在畫布上選取任何元素
- 直接拖動、調整大小、對齊
- 行內文字編輯
- Claude 自動生成的間距和顏色調整滑桿
- 復原/重做

這解決了「生成之後就失去控制」的問題。
你不再被鎖死在模型產出的結果裡。你可以精修。

---

**Tweet 3**
Claude Code 裡的 /design 指令是我最在意的部分。

你在 terminal 裡工作。你輸入 /design。
Claude 生成 artboard，發布畫布，你在瀏覽器裡用完整的元素控制來編輯。

然後直接交回給 Claude Code 去實作。

設計在開發工作流程裡發生。不是在它之前。

**Tweet 4**

14 個連接的工具。一份設計。一個 design system。到處都能用。

---

**Tweet 5**
Design system 的部分是整件事情的核心。

你的品牌規範——顏色、字體、元件——存在你的 design system 裡。Claude Design 在每一個新的設計工作裡都會讀取它們。

這就是 constraint architecture 的實際運作：在上游定義一次，在下游每個地方都自動套用。

九月開始的 design.md 可攜性收斂？這就是它落地的位置。

Claude 不是在試著取代 Figma。
