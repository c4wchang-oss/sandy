【AI 工具觀察】Bubble AI Agent 可以幫你蓋 Native App 了，而且只需要丟一張截圖

---

**正文：**

8 月 4 日，Bubble AI Agent 正式支援 Native Mobile 全面建構。

作為 UX Designer，這件事對我來說有幾個值得注意的地方：

**① 截圖就是 Brief**
可以把你現有 Web Frontend 的截圖直接丟給 Agent，它讀取視覺設計，然後複製成 Native Mobile 版本。不需要 Figma 交接文件，不需要另外寫 Spec。你的截圖，直接就是 Brief。

**② 共用後端，不用重蓋**
Web App 和 Mobile App 共用同一個資料庫和 Workflow。Agent 是在你已有的基礎上擴展，不是從零重蓋。Web 上建立的邏輯，Mobile 直接繼承。

**③ Agent 會讀你的可複用元件**
Agent 現在會讀取你現有的 Reusable Components，在 Mobile 版本沿用，不會重複複製一份。你的 Component 命名和組織方式，直接影響 AI 輸出的品質。

**④ API 連接用說的**
以前要手動設定 API Connector，現在只要說「幫我連接 Stripe」，Agent 自動處理設定。

**⑤ 還在 Beta，這些要自己把關**
Native 互動設計（手勢導航、底部工作表、滑動操作）這些平台慣例，Agent 現在還不一定能處理得很精準。結構對，但 Feel 還要自己確認。

---

🎯 **Senior UX 視角：**
這不是「AI 取代設計師」的故事。這是「你的設計稿開始被 AI 直接執行」的故事。以前你的截圖是給其他人看的，現在它是給幫你蓋東西的系統看的。設計品質 = 蓋出來的品質，一模一樣的規律。
