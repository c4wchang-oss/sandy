# Threads Post — English
## Topic: Figma Detachable Agent Panel + Weave Going GA

---

**Long-form post:**

Something subtle happened in Figma's release notes this week that most people scrolled past.

They let you undock the agent chat panel into a floating window. Sounds like a minor QoL fix. It isn't.

The sidebar model always carried a hidden assumption: that you'd use the agent sequentially. Prompt, wait, review, repeat. That's how every assistant UI is designed — you finish one thing before starting the next.

A floating, detachable panel changes the assumption. Now the agent is something you run alongside your design work, not between design work. Parallel, not sequential.

Cursor's Design Mode got to the same place through a completely different decision: a persistent voice mic that stays live while an agent is executing. You can queue the next change before the first one finishes. Same mental model underneath — you and the agent work simultaneously, you don't take turns.

Two tools. Different paths. Same UX conclusion. When that happens, it's worth taking seriously.

And then this landed the same week: Figma confirmed Weave tools and the Design agent are moving to GA in "a few weeks." Once they're generally available, they start drawing from your AI credit pool. The free beta ends.

So in the same week, the interaction model got better and the pricing clock started.

That timing tells you something. You design the interaction pattern first — the one that makes the tool genuinely useful — and then you price it. The floating panel had to earn its keep before Figma could charge for it.

If you haven't audited what your team actually uses the Figma agent for, this is the moment. Not because credits are going to break your budget — but because "which agent tasks genuinely advance design decisions" vs. "which ones just save typing" is a question senior designers should have answered before someone in finance starts asking it.

---

**Short punchy take (for top of Threads):**

Figma made the agent chat panel a floating window this week.

That's not a UI update. It's an admission that agents aren't assistants. You don't take turns with them. You work alongside them.

And Weave + the Design agent are going GA soon — credits start counting. The governance question just became urgent.
