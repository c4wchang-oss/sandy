# Threads 貼文 — 繁體中文
## 主題：Figma Agent Chat 浮動視窗 + Weave 即將 GA

---

**長文：**

這週 Figma 的 release notes 裡有一件事我覺得大家沒有特別注意到。

他們讓 agent chat panel 可以從側邊欄分離，變成一個獨立浮動的視窗。聽起來像小幅改善。其實不然。

側邊欄的設計一直有個隱藏的假設：你跟 AI 是輪流工作的。你下指令、等待、審查、再來一輪。這是所有 assistant UI 的基本預設——你做完一件事，才開始下一件。

浮動視窗改變了這個假設。現在 agent 是在你設計的同時工作，不是在設計的間隙工作。平行，不是序列。

Cursor 的 Design Mode 從另一個方向走到了同樣的結論：麥克風在 agent 執行中保持開啟，你可以在第一個任務還在跑的時候就排好下一個指令。底層的心智模型一樣——你和 agent 同時工作，不是輪流。

兩個工具，不同的路，走到同一個 UX 結論。這種時候值得認真看待。

然後同一週還有這個：Figma 確認 Weave tools 和 Design agent 在「幾週內」就會正式 GA。GA 之後就會計入你的 AI credit pool。免費 beta 結束。

同一週，互動模式變好了，付費計時也開始了。

這個時機點本身就說明了一些事。你先設計好互動模式——那個讓工具真正好用的互動模式——然後才定價。浮動 panel 必須先證明自己的價值，Figma 才能開始收費。

如果你還沒有盤點過團隊實際上在用 Figma agent 做什麼，現在是對的時機。不是因為 credits 會讓預算吃不消——而是「哪些 agent 任務真的推進了設計決策」vs.「哪些只是省了打字」，是 senior designer 應該先於財務部門有答案的問題。

---

**簡短核心觀點（放在 Threads 最前面）：**

Figma 這週讓 agent chat panel 變成了浮動視窗。

這不是 UI 更新。這是一個承認：agent 不是助手。你不是跟它輪流工作。你跟它同時工作。

而且 Weave + Design agent 快要 GA 了——credits 開始計算。治理問題從現在起變得緊迫。
