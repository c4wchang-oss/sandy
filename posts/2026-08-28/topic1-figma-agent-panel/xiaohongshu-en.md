## Topic: Figma Detachable Agent Panel + Weave Going GA

---

**Title:** Figma's floating agent panel is a bigger UX signal than it looks

**Body:**

This week Figma let you undock the agent chat panel into its own window.

Most designers dismissed it as a minor QoL update. I think it's one of the more honest UX decisions Figma has made about agents.

Here's why:

**1. Sidebar = the sequential assumption**
The panel living in the sidebar implied you'd use the agent in turns: prompt → wait → review → repeat. Like texting. You finish, then they respond.

**2. Floating window = the parallel model**
You can now keep designing while the agent works alongside you. The window stays visible across tabs and tools. That's not a sidebar interaction — that's a collaborator sitting next to you.

**3. Cursor got here first, differently**
Cursor Design Mode's answer was a persistent voice mic that stays active while agents run. Queue your next edit before the first one finishes. Same underlying model: parallel, not turn-taking.

**4. Weave + Design agent are going GA soon**
Figma confirmed this the same week. Once they're generally available, they start consuming AI credits. The free beta window is closing.

**5. Now is the time for a credit audit**
Before GA lands, map your team's actual agent usage:
→ Which tasks genuinely advance design decisions?
→ Which tasks are just saving you typing?
→ Who's using the agent for what?

**The real takeaway:**
A floating panel isn't a convenience feature. It's Figma saying: agents are collaborators, not assistants. The mental model of the tool changed.

And when Weave goes GA, the question shifts from "should we use AI?" to "which AI usage is worth the cost?" That's a governance question. Have your answer ready.
