## 主題：Figma Agent Chat 浮動視窗 + Weave 即將 GA

---

**標題：** Figma Agent 浮動視窗：一個比看起來大的 UX 訊號

**正文：**

這週 Figma 讓 agent chat panel 可以從側邊欄分離，變成獨立浮動視窗。

大部分設計師把它當成小幅 UI 改善忽略掉了。我覺得它是 Figma 對 agent UX 做過的比較誠實的決策之一。

原因如下：

**1. 側邊欄 = 輪班制假設**
Panel 住在側邊欄的時候，隱含的預設是你和 agent 輪流工作：你下指令 → 等 → 審查 → 再來一輪。就像傳訊息——你說完，對方回應。

**2. 浮動視窗 = 平行協作模式**
現在你可以繼續設計，同時 agent 在旁邊跑。視窗跨分頁和工具保持可見。這不是側邊欄的互動——這是旁邊坐了一個協作者。

**3. Cursor 已經先到了，但用不同的方法**
Cursor Design Mode 的解法是：agent 執行中麥克風保持開啟。你在第一個任務還在跑的時候就可以排好下一個指令。底層模型一樣：平行，不是輪流。

**4. Weave + Design agent 快要 GA 了**
Figma 同一週確認這件事。正式上線之後就開始消耗 AI credits。Beta 的免費紅利快要結束了。

**5. 現在就做 credit audit**
GA 到來之前，盤點你的團隊實際的 agent 使用狀況：
→ 哪些任務真的在推進設計決策？
→ 哪些任務只是讓你少打幾行字？
→ 誰在用 agent 做什麼？

**核心結論：**
浮動 panel 不是便利性功能。這是 Figma 在說：agent 是協作者，不是助手。工具的心智模型改變了。

而當 Weave GA 之後，問題就從「我們應該用 AI 嗎？」變成「哪些 AI 使用值得那個成本？」那是治理問題。趁現在先想好答案。
