# Topic 2 — Aug 28, 2026
## Dscout MCP — Research Embedded in the AI Workflow

**Source news:**
- Dscout press release, Aug 26 2026: Dscout Model Context Protocol (MCP) — general availability
- Allows teams to draft, launch, and analyze user research studies from inside Claude, Codex, GitHub Copilot, VS Code, and Figma Make without switching tools
- Uses existing Dscout AI Studio permissions and governance

**Angle / POV:**
This isn't "faster research." It's a structural shift — research moving from a separate workflow layer into the same workspace where design and code decisions happen. Brief quality is now the only gate (the cost gate is essentially gone). Senior researcher role shifts upstream: from running studies and writing reports, to designing the research system that agents execute. Same pattern as ProtoPie MCP, Dovetail Channels, Usertour MCP. Risk: AI-embedded research produces confident answers to vague questions faster — a new failure mode.
