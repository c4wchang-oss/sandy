**標題：** Webflow 更新了：AI agent 現在可以幫你做動畫了

**正文：**

身為做過幾十個 Webflow 網站的 UX 設計師，我覺得上週這個更新是近半年最有意思的一個。

**Webflow MCP 2.0 到底更新了什麼**

在這之前，透過 MCP 工作的 AI agent 可以做到：
- 排版
- 管理內容
- 操作 CMS

現在多了：
✅ GSAP 動畫效果（scroll trigger、hover state、載入動畫、click）
✅ 多步驟動畫 timeline
✅ 更快的 CMS 查詢（排序、篩選、跨集合欄位一次完成）
✅ Webflow Cloud 應用部署與 debug
✅ 分支生命週期管理（Enterprise 方案）

**我覺得最重要的細節**

Agent 建的 interaction 會出現在 Interactions 面板裡，跟手動建的一模一樣。不是藏在自定義程式碼裡。你之後還是可以進去編輯所有 trigger、時間軸和 easing 曲線。

API 只能建 Interactions 面板本身就能建的東西。這是一個刻意的設計限制，而且是正確的決策。

⚠️ **但真正的天花板還是在你這邊**

「讓每張卡 scroll 時 fade in」→ agent 做得很好

「讓整個頁面感覺 premium」→ agent 沒辦法幫你

困難的動態決策是品味問題，不是指令問題。Brief 的品質還是你的責任。

這就是 AI 時代 senior designer 的工作：不是親自做 interaction，而是寫一份讓 agent 的動態效果不看起來像 generic 的 brief。
