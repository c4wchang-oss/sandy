**Title:** Webflow just gave AI agents the last thing they were missing

**Body:**

As a UX designer who's built dozens of Webflow sites, this update from last week is the most interesting thing I've seen in months.

**What changed in Webflow MCP 2.0**

Before this update, AI agents working through the MCP could:
- Layout pages
- Manage content
- Work with CMS data

Now they can also:
✅ Build GSAP-powered animations (scroll, hover, load, click triggers)
✅ Create multi-step animation timelines
✅ Query CMS data faster (filter + reference fields in one request)
✅ Deploy and debug Webflow Cloud apps
✅ Manage branch lifecycle (Enterprise plans)

**The detail that matters most**

Interactions built by the agent show up in the Interactions panel — just like anything you'd build by hand. Nothing is hidden in custom code. You can still go in and edit every trigger, timing, and easing curve.

The API can only build what the panel itself could build. That's a deliberate design constraint, and it's the right call.

**But the real ceiling is still on your side**

"Add a fade in on scroll to each card" → agent handles this perfectly

"Make the page feel premium" → agent can't help you here

The hard motion decisions are taste problems, not instruction problems. The brief quality is still on you.

That's the senior designer's job in the AI era: not building the interaction, but writing the brief that gives the agent enough context to not feel generic.
