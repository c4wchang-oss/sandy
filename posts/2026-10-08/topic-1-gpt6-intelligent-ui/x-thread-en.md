**Tweet 1 — Hook**
The model just took over format decisions too.

GPT-6 Intelligent UI rolled out today. The interface you get is no longer fixed. ChatGPT picks your response format — chart, interactive diagram, form, calculator, tool, or plain text — based on your question.

That's more fundamental than it sounds. Thread.

---

**Tweet 2**
What Intelligent UI generates:
- Interactive diagrams with tappable parts
- Adjustable widgets (change guest count, portions update live)
- Calculators and task-specific tools built inline
- Side-by-side comparisons, charts, checklists
- Plain text when that's genuinely cleaner

The model decides. You don't choose.

---

**Tweet 3**
Technically: a library of native streamable components + a compiler that renders the interface progressively while GPT-6 continues thinking.

This isn't a richer template with fields filled in. The model composes the interface from a component library at inference time.

Different category from anything before it.

---

**Tweet 4**
This extends AI IA decision-making to the conversation layer.

ChatGPT Visualize (Aug 26): model picks your chart type from data.
Basedash Dashboard (Oct 1): model structures your full product IA from one sentence.
GPT-6 Intelligent UI (Oct 8): model picks your response *format* from your question.

Same problem. Escalating scope.

---

**Tweet 5**
The failure mode is consistent at every scale:
polished, confident, wrong IA.

When a model presents its interface choice with authority, most users don't push back. They adapt their mental model to match whatever was presented.

This happens at the dashboard level. It happens at the conversation level.

---

**Tweet 6**
What this means for our work:
→ Interface composer → interface evaluator at the conversation layer
→ "Does this answer the question?" becomes "Does this *format* serve the actual goal?"
→ Recognizing AI-composed interface misdirection is now a distinct UX skill

None of these are smaller jobs. They're harder.

---

**Tweet 7**
Honest caveat: "rich chat responses" have existed before. Slack Canvases, Teams tabs, various widget hacks.

What's different: format selection happens from question semantics, not hardcoded rules. Compositional intelligence, not richer templates.

Whether that's genuinely better for users in practice — still an empirical question.

---

**Tweet 8 — CTA**
The research question nobody's running:

When AI picks the wrong response format — confidently, polished — do users catch it? Or do they reorganize their understanding to match whatever the model gave them?

At GPT-6 + conversational scale, that question matters a lot. Someone should study it.
