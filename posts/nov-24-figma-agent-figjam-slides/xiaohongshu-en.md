## POST BODY

Figma launched their agent in FigJam and Slides (Nov 23). Combined with Dev Mode agent (Nov 19), the design process pipeline is now fully covered.

Here's the complete picture:

**→ FigJam (research synthesis)** — Attach design files, transcripts, research notes → agent organizes them into a board, finds connections, pushes ideas further. The real bottleneck it addresses: the hour you spend just assembling context before synthesis can start.

**→ Design canvas** — Agent has been here for a while. Generate, refine, iterate.

**→ Dev Mode (engineering handoff)** — Inspect designs, compare versions, get code snippets, bulk download assets in one prompt.

**→ Slides (stakeholder communication)** — Turn material into a draft presentation, adapt a deck for a different audience, shorten copy across the whole deck, get feedback on your story arc.

**5 things worth knowing:**

1. **Available on all paid plans now** — both FigJam agent and Slides agent. No new subscription tier.

2. **Input quality = output quality** — The agent works from what you attach. Structured research notes → useful board. Scattered, untagged transcripts → organized scatter. This is not a synthesis shortcut. The brief is your artifact quality.

3. **Slides is doing real audience modeling** — "Adapt for a different audience" is not search-and-replace. The agent is restructuring what gets emphasized. Watch how it makes those decisions before you trust it at a high-stakes presentation.

4. **FigJam and Slides support specific connectors** — Design files, transcripts, research notes are listed explicitly. It's not "attach anything." Scoped intentionally. That scope is a quality decision, not a limitation.

5. **The error mode is different from Dev Mode** — Dev Mode is deterministic (design spec → code). FigJam/Slides is interpretive (scattered artifacts → constructed meaning). The failure mode in interpretive AI is subtle: everything looks organized but the wrong meaning was constructed. Build in a review step.

**The honest frame:**

If your research artifacts are already well-structured before this, Figma agent saves you meaningful hours.

If your research process is scattered, the agent gives you a faster version of your existing disorganization.

The bottleneck moved from context assembly to intake quality. That's on you to fix before the agent can help.
