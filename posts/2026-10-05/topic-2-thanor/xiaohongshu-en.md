**Title:** AI site looks like slop? You're missing 30 decisions.

**Body:**

Thanor launched this week. The core insight is brutal and true:

"Prompting harder does not work."

What actually works is writing down ~30 specific values BEFORE you touch a prompt.

The 30-value design spec format:
1. 6 type sizes (exact px values, not "large" or "small")
2. 5 colors with named roles (not a palette — a system with purpose)
3. 1 measure: max line length in ch or px
4. 1 spacing unit + allowed multiples only
5. 1 elevation rule (when shadow applies, when it doesn't)
6. 1 easing curve (cubic-bezier values + ms duration)
7. 1 section order for the page
8. A refusal list (what AI is NOT allowed to use)

When those ~30 values are locked, the model stops reaching for its defaults. No more centered hero + purple gradient + Inter. The spec makes the decisions the prompt left open.

What Thanor sells:
A library of these complete specifications, already written. You pick by watching screen recordings of actual output — not by reading names.

They also ship an MCP server: pull a direction directly into Claude Code or Cursor without switching windows.

Pricing: Free (select designs) / $89 for 3 months / $299 lifetime

My honest take:
This solves the floor problem — slop, generic defaults, "every AI site looks the same." The judgment ceiling — what design fits this product, this audience, this moment — is still yours. No library covers that.

But the 30-value format itself is worth knowing, even if you write your own.
