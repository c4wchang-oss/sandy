**Title:** The design-code gap just closed. Without AI.

**Body:**

Last week Timeful launched and nobody made enough noise about it.

It's a visual editor for Vue + Tailwind. No AI, no export, no tokens.

Here's what it actually does:

1. Open a real Vue project on a visual canvas
2. Edit visually → the .vue files update immediately
3. Someone edits the code → the canvas follows automatically
4. Your project lives as a normal Git repo you own

Why this matters for UX designers:
- The design file IS the code (not upstream of it)
- No translation layer, no interpretation, no hallucination risk
- AI agents can edit the same codebase — it's regular Vue + Tailwind
- Zero proprietary format, zero vendor lock-in

Honest caveats you should know:
- macOS only (no Windows or Linux yet)
- Vue + Tailwind only (no React)
- $19/month, solo developer building it
- Early stage — real gaps exist

But the principle is what matters: most AI design tools are bridging a gap that shouldn't exist. This closes the gap before AI even needs to enter.

If you're on a Vue team doing constant design handoff work, this is worth 10 minutes.
