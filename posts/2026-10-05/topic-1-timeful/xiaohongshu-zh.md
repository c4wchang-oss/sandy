**內容：**

上週 Timeful 上線，但沒有得到應有的關注。

這是一個 Vue + Tailwind 的視覺編輯器。沒有 AI，沒有匯出，不燒 token。

它實際上在做什麼：

1. 在視覺畫布上打開你的真實 Vue 專案
2. 在畫布上修改 → .vue 檔立即更新
3. 有人修改程式碼 → 畫布自動跟著動
4. 專案存在你自己的 Git repo 裡，完全歸你所有

對 UX 設計師來說，為什麼重要：
- 設計檔就是程式碼（不是程式碼的上游）
- 沒有翻譯層，沒有詮釋，沒有 AI 幻覺風險
- AI agent 可以直接編輯同一個 codebase——它就是一般的 Vue + Tailwind
- 零專有格式，零平台鎖定

你應該知道的誠實注意事項：
- 只支援 macOS（目前沒有 Windows 或 Linux）
- 只支援 Vue + Tailwind（沒有 React）
- $19/month，solo 開發者在做
- 仍在早期階段，有真實的不足

但重要的是原則：大多數 AI 設計工具在橋接一個本不應存在的落差。Timeful 是在 AI 進場之前就把那個缺口關上。

如果你在 Vue 團隊工作，一直在做設計交付，值得花 10 分鐘看一看。
