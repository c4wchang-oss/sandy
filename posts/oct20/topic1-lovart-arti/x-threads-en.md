## THREADS (long-form)

Ten years in UX, and I've never had a tool ask to learn who I am before doing the work.

Lovart 2.0 launched Arti yesterday. The headline is "personal design agent with memory." But the real thing happening is more specific than that.

Arti organizes memory into four buckets: basic information, collaboration style, aesthetic preferences, and frequently used assets. You can edit every entry, delete entries, and decide whether memory travels across projects or stays isolated. You can also upload your portfolio or a Markdown file from another AI tool to bootstrap it.

That's not a chat feature. That's constraint architecture applied to agent identity.

The more interesting part is design delegation. You describe a job in full, set a schedule, set a credit limit, test it on four items, then walk away. The example that stuck with me: 42 SKUs, four sizes, 168 images, started overnight. The designer came back to a canvas full of results.

That's job scheduler semantics. Design tools have never had that.

There's also a self-evolving skills feature I didn't expect: if you run the same workflow across three projects, Lovart extracts it as a reusable skill automatically. You didn't write a skill. The system inferred a pattern from your behavior.

The honest caveat I keep coming back to: your memory profile is now a quality ceiling. If the aesthetic preferences Arti learned about you six months ago are now outdated — the agent will apply them consistently, at scale, silently. The brief-quality problem didn't go away. It moved upstream, from per-task to per-identity.

Design Review, which catches consistency failures while you work, and the feedback commenting system (anchored to elements, not the canvas) are good execution on the "agent reviews before presenting" pattern that appeared in Shopify Canvas, Gamma 5, and Automo over the past three weeks.

None of this replaces creative direction. But it changes what "creative direction" means in daily practice: less generating, more stewarding the constraints you've set about yourself.
